### 基础术语
  - ISP 网络服务提供商 
    + Internet Service Provider
  - ICP 网络内容提供商 
    + Internet Content Provider
  - OSI/RM 开放系统互连参考模型（Reference Model） 
    + Open System Interconnect
  - PDU 电源分配单元 
    + Power Distribution Unit
    + bit 比特流
      * 物理层‌的 PDU
    + Frame 帧
      * 数据链路层‌的 PDU
    + Packet 包
      * 网络层‌的 PDU
    + Segment 段
      * ‌传输层‌的 PDU
    + Data 数据
      * 其他高层的 PDU
  - SDU 服务数据单元
    + Service Data Unit
  - SOA 起始授权机构
    + Start Of Authority

### 常用词汇
  - Source 源
  - Destination 目的
  - Selected 选中
  - Unselected 非选中
  - Active link 活动链路
  - Inactive link 非活动链路
  - Inbound 入站 
  - Outbound 出站 
  - Standard 标准
  - Ethernet 以太网
  - physical 物理
  - datalink 数据链路
  - transport 传输
  - session 会话
  - presentation 表示
  - application 应用
  - duplex 双工
  - channel 信道
  - bandwidth 带宽
  - delay 延迟
  - propagationdelay 传导延迟
  - switchingdelay 交换延迟
  - accessdelay 介质访问延迟
  - queuingdelay 队列延迟
  - topology 拓扑
  - fullmeshed 全网状

### 线缆类型
  - STP 屏蔽双绞线
    + Shielded Twisted Pair
  - UTP 非屏蔽双绞线
    + Unshielded Twisted Pair
  - SMF 单模光纤
    + Single Mode Fiber
  - MMF 多模光纤
    + multimode optical fiber

### 调制技术
  - ASK 调幅（幅移键控）
    + Amplitude Shift Keying
  - FSK 调频（频移键控）
    + Frequency-shift keying
  - PSK 调相（相移键控）
    + Phase-Shift Keying    
  - DPSK 2相键控（二相位差键控）
    + Differential Phase Shift Keying
  - QPSK 正交相移键控（四相相移键控）
    + Quadrature Phase Shift Keying
  - QAM 正交调幅
    + Quadrature Amplitude Modulation

### 信号编码（line code）方式
  - RZ 归零码
    + Return-to-Zero
  - NRZ 不归零编码
    + Non-Return-to-Zero

### 通信方式
  - CS 电路交换 
    + Circuit Switching 
  - PS 分组交换 
    + Packet Switching 
  - MS 报文交换 
    + Message Switching

### 多路复用技术
  - FDM 频分多路复用 
    + Frequency-division multiplexing 
  - TDM 时分多路复用 
    + Time-division multiplexing 
  - WDM 波分复用技术 
    + Wavelength Division Multiplexing

### 差错检测技术‌
  - CRC 循环冗余校验码 Cyclic Redundancy Check

### 传统广域网：
  - PSTN 公共交换电话网络 
    + Public Switched Telephone Network
  - X.25 公共数据网
  - FR 帧中继 
    + frame relay
  - ISDN 综合业务数字网 
    + Integrated Services Digital Network
  - ATM 异步传输模式 
    + Asynchronous Transfer Mode
  - VPN 虚拟专用网络 
    + Virtual Private Network

### 现代广域网：
  - DDN 数字数据网
    + Digital Data Network
  - SDH 同步数字体系 
    + Synchronous Digital Hierarchy
  - MSTP 多业务传输平台 
    + Multi-Service Transfer Platform
  - FTTx 光纤接入网 
    + Fiber To The x
  - PON 无源光纤网络 
    + Passive Optical Network
  - WiMAX 全球微波互联接入 
    + Worldwide Interoperability for Microwave Access
  - DTE 数据终端设备 
    + Data Terminal Equipment
  - DCE 数据通信设备 
    + Data Communications Equipment 
  - ARQ 自动重传请求 
    + Automatic Repeat-reQuest 
  - ACK 确认字符 
    + Acknowledgement 
  - NAK 没有应答 
    + Negative Acknowledgment 
  - PVC 永久性虚电路 
    + Permanent Virtual Circuit 
  - SVC 交换虚拟电路 
    + Switching Virtual Circuit 
  - VPI 虚拟通道标识 
    + Virtual Path Identifier
  - VCI 虚拟信道标识 
    + Virtual channel identifier

### 协议 Protocol
  - ARP 地址解析协议 
    + Address Resolution Protocol
  - RARP 反向地址转换协议 
    + Reverse Address Resolution Protocol 
  - IP 互联网协议地址/网际协议地址 
    + Internet Protocol Address 
  - TCP 传输控制协议 
    + Transmission Control Protocol 
  - UDP 用户数据报协议 
    + User Datagram Protocol 
  - SNMP 简单网络管理协议
    + Simple Network Management Protocol 
  - TFTP 简单文件传输协议
    + Trivial File Transfer Protocol 
  - DHCP 动态主机设置协议
    + Dynamic Host Configuration Protocol 
  - DNS 域名系统 
    + Domain Name System 
  - ICMP 因特网控制报文协议
    + Internet Control Message Protocol 
  - RIP 路由信息协议
    + Routing Information Protocol 
  - OSPF 开放式最短路径优先
    + Open Shortest Path First 
  - FTP 文件传输协议 
    + File Transfer Protocol 
  - Telnet 远程登录协议
    + Telecommunication Network 
  - HTTP 超文本传输协议
    + HyperText Transfer Protocol 
  - BGP 边界网关协议 
    + Border Gateway Protocol 
  - SMTP 简单邮件传输协议
    + Simple Mail Transfer Protocol 
  - HDLC 高级数据链路控制 
    + High-Level Data Link Control
  - PPP 点对点协议
    + Point-to-Point Protocol

### 子网划分技术
  - VLSM Variable Length Subnet Mask 可变长子网掩码 
  - CIDR lassless Inter-Domain Routing 无类别域间路由 

### OSPF 基于链路状态的路由协议

    + Fiber Distributed Data Interface
  - DR 指定路由器 
    + Designated Router
  - BDR 备份指定路由器 
    + Backup Designated Router
  - IR 内部路由器 
    + Internal Router
  - ABR 区域边界路由器 
    + Area Border Routers
  - BR 骨干路由器 
    + Backbong Routers
  - ASBR 自治系统边界路由器
    + Autonomous System Boundary Routers

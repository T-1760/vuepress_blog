# 宗旨

  • 基本原则：材料为王

    考官评分：1、踩点给分 2、（大作文）按档给分

  • 答案来源
    • 摘抄提炼

      直接抄材料

    • 归纳总结

      材料口语化，归纳结合性”抄“

    • 转化反推

      根据问题，给出相应方案、解决措施（没钱给钱、没人给人）

    • 分析推断

      言外之意

  • 语言表达：准确规范、简明畅达

# 题型

# 五大题型

  • 概括题：作答要素明确，“抄”
  • 对策题：作答要素明确，转化反推
  • 分析题：作答要素模糊，多角度综合分析
  • 应用文：格式 + 多要素 + 语言
  • 作文：观点 + 论证 + 结构 + 语言

# 四大要素【重点】

  • 问题
  • 原因
  • 影响（意义、危害）
  • 对策

# 作答步骤

  1. 全面审题（把握命题意图）
    • 作答范围：涉及哪一则或哪几则材料
    • 题型：确定作答方法和思路
    • 题干关键词：确定作答主体和方向
    • 作答要素：问题、原因、影响、对策等
    • 要求：调理、格式、语言、字数等
  2. 阅读材料（寻找答案要点）
    • 基本方法【重点】
      1. 摘抄、提炼
      2. 归纳、总结
      > 口语规范书面化
      1. 转化、反推
      2. 分析、推断
    • 常用技巧
      1. 首尾句原则
      + 多数情况下主旨句、中心句会出现在段落的首句或者尾句
      1. 观点句原则
      + **政府**、**专家学者**、**媒体**、百姓网友（需辨别）等的观点 
+ 常以 “**表示/认为/指出/说/称**......” 等标志性词汇
      1. 关联词原则
      + 表**转折**：虽然...但是...; ...却...; ...然而...
+ 表**并列**：既...又...; 一方面...另一方面...; ...和...
+ 表**因果**：因为...所以...; 之所以...是因为...; 由于...; 因此... 
+ 表**递进**：不光...也...; 不仅...还...; 不但...而且...
+ 表**假设**：如果...就...
+ 表**条件**：只要...就...; 只有...才...
      1. 高频词原则
      + 材料中反复出现相同的词语或意思相近的词语
    • 批注（试卷）方法
      1. 框圈：标记关键词、句，切记整行整段的划横线
      2. 批注：试卷空白处
  3. 整合要点
    • 并列关系（同一作答要素）

      题型：概括题、对策题

      • 同类合并、异类区分
    • 逻辑关系（多个作答要素）

      题型：分析题、应用文、大作文

    • 列提纲考前准备
  4. 下笔成文
    1. 不用书写“答”
    2. 小题一般不用空两格，若分段建议空两格
    3. 小题分条作答即可，特殊情况除外
    4. 小题序号使用一、/ 1. /（1）/ ①均可
    5. 标点符号尽量单独占一鸽
    6. 斜线划错字、“^”插入漏字
    7. 字迹清晰、卷面整洁

# 一、概括题 ⭐⭐⭐⭐⭐⭐

  • 命题特点
    • 关键词
      1. 概括
      2. 简述
      3. 如何
  • 答题要求——抄
    • 准确

      抄、纯客观题

    • 全面

      按点给分

    • 简洁

      关键词、短语

    • 有条理

      罗列序号，同类合并、异类区分

  • 作答（四大）要素 ⭐⭐⭐⭐⭐
    • 问题：反面现象
      • 常见问法：

        困难、困境、不足、缺失、挑战、弊端、劣势等

      • 作答技巧：寻找负面性词汇(贬义词、否定词)
        1. 不科学、不合理、不到位、不均衡、不完善、不健全、不足
        2. 缺乏、缺少、流失
        3. 差、弱、低
      • 作答结构：宾补、动宾

        例：交通欠发达，缺乏正确的价值观

    • 原因：造成某种结果或引起另一事情发生的条件
      • 常见问法

        理由、起因、动因、缘由等等

      • 作答技巧：寻找因果关系的标志词

        因为、由于、导致、造成等等

      • 原因分类
        1. 带来好结果的原因（正面信息）：做法、优势等
        2. 带来坏结果的原因（负面信息）：问题、劣势等
        3. 要做某事的原因：意义 + 问题
    • 影响：现象、做法代理的改变或作用
      • 积极影响（对策 <——> 意义）：意义、效果、成果、功能、积极作用等等
      • 消极影响（问题 <——> 危害）：危害、后果等等
      • 作答技巧：标志性词汇

        双生词：对策与意义、问题与危害：对策前后一般有意义，问题之后往往有危害。

        1. 意义：
        1. 促进/改善/增加/提高/减轻/实现/弘扬/节约/保护/方便（了）
        2. 有利于、有助于、倒逼
        3. 让、能、使
        1. 危害：
        1. 不利于
        2. 降低/减少/破坏/阻碍/加重/激化（了）
    • 对策
      • 常见问法：措施、做法、举措、建议、经验等等
      • 作答技巧：寻找积极的行为，标志性动词
      • 作答机构：动宾结构

        推动、建立、加强、完善、规范、加快、促进、提高、增强、转变、打造、开展、塑造、梳理等等

        1. 加强 + 资金投入
        2. 加快 + 人才建设步伐
        3. 转变 + 发展理念
        4. 树立 + 正确的价值观
  • 例题讲解

# 二、对策题

# 常规对策题 ⭐⭐⭐

  • 命题特点——题型特征
    • 常见问法：
      • 针对特定问题/原因，提出解决措施（对策、做法、建议、举措、意见、工作思路、如何、怎么办等等）
    • 常见要求：针对性、具体性、可行性等等
    • 身份限定
  • 答题要求
    • 总体要求
      • 针对性：针对材料中出现的问题或问题产生的原因
      • 具体性：符合角色身份和日常经验
      • 可行性：包括“做什么”和“怎么做”
    • 对策来源（直接和间接）
      • 直接摘抄（观点、案例中的正确做法）

        常见对策动词（动宾搭配）：推进、推动、建立、健全、统筹、转变、创新、加强、促进、巩固、完善、规范、整顿、打击等等

      • 对问题和原因，进行转化反推（可能通篇只有问题和原因，需转化）

        大多结构形式：对策动词 + 问题名词

        1. 缺少资金支持
        2. 专业知识欠缺
        3. 人才队伍建设不足
  • 作答步骤
    1. 审清答题要素
      • 对策
      • 问题/原因 + 对策
    2. 阅读和整合
      • 第一步：锁定问题和原因
      • 第二步：寻找材料已有对策（直接来源）
      • 第三步：针对问题或原因反推对策（间接来源）
    3. 下笔成文——答案呈现方式
      • 对策
        • 根据字数要求，写成一段式或多段式
      • 问题/原因 + 对策
        • 问题/原因 与 对策 各一段（N个问题一段，N个对策一段）
        • 一个 问题/原因 对应一个对策（一个问题 + 对策一段，N个N段）

# 启示启发题

  • 命题特点——题型特征
    • 以特定的案例材料为背景（正面或反面）
    • 作答任务：启示或教训
  • 答题要求
    • 正面案例谈启示
      • 作答思路：类似于归纳概括题，从正确的做法中寻找启示，注意体现普适性（归纳提炼，结合自身，应地制宜）
    • 反面案例谈启示/教训

      出题较少

      • 作答思路：类似于问题 + 对策题 （如无特殊要求，直接转化反推对策）

# 三、词句分析题

# 解释类分析

  • 题型特征
    • 常见问法：
      • 解释含义、谈理解、下定义等等
  • 作答结构
    • 内涵 + 外延
      • 内涵：解释名词或句子的本质含义
      • 外延：围绕名词或句子，材料如何展开论述
    • 具体结构：解释含义 + 相关（四大）要素 + 总结 ⭐⭐⭐⭐⭐ * 解释含义：就近寻找权威观点、总结句；（同义替换：根据材料归纳提炼） * 相关要素：问题、原因、危害、意义、对策、事例等等 * 总结（可有可无）
  • 作答步骤
    • 审题
      • 关注词句，根据感情色彩、词句层次（褒贬）、关键信息等进行预判
    • 阅读材料
      • 获取内涵（同义替换）、外延（问题、原因、影响、事例）
    • 下笔整合
      • 解释含义 + 相关要素 + 总结
  • 案例
    • 并列且对立

      社区“吹啥”

# 评价类分析

  • 作答结构：表态 + 论证/原因 + 总结 ⭐⭐⭐⭐⭐
    • 表明态度（来源于材料、作者观点）
      • 支持：正确、科学、合理、全面赞同
      • 反对：错误的、偏颇的、不科学、不合理、不正确
      • 辩证：一分为二、有待观察、客观理性
    • 分析论证
      • 为什么、这么看
    • 总结（可有可无）：提出对策

# 四、 作文

# 文章结构

  • 标题
  • 开头
    • 要求：简明扼要、开门见山、引出主体
    • 方法（铺垫）
      1. 正反对比式
      2. 原因分析式
        • 思路：反面案例 + 分析原因 + 主题句
      3. 引用名言式
        • 思路：引用名言 + 解释名言 + 案例 + 主题句
      4. 解释含义式
        • 思路：提出词句 + 解释词句（依据材料）+ 结合现状 + 主题句
    • 常见问题
      1. 过于简单
      2. 没有主题
      3. 严重抄袭（材料）
      4. 表达口语化
  • 主题——观点
    • 结构：论点 + 论据
    • 观点写法
      1. 紧扣主题
      2. 写作角度
      3. 一段一事
      4. 写作形式
        • 观点写在段首
        • 并列式观点

          弘扬黄河精神 共筑名族之魂

          观点 1：弘扬黄河精神，就是要有自强不息的抗争精神 观点 2：弘扬黄河精神，就是要有顺势而为的科学精神 观点 3：弘扬黄河精神，就是要有兼容并蓄的包容精神

        • 递进式观点

          推动中国企业“走出去”

          观点 1：只有走出去，才能牢牢抓住发展机遇 观点 2：企业走出去面临“水土不服”的问题 观点 3：利用政策支持，推动企业走出去 观点 4：不断完善自我，推动企业走出去

    • 论据写法
      1. 围绕观点讲道理——道理论据
      2. 围绕观点举例子——事实论据
        • 一例多用
        • 旧例多用
        • 改写案例
          • 案例性材料公式：主体 + 处境 + 做法 + 结果/意义
    • 论据来源
      1. 申论试卷
      2. 热点素材
        • 经济、文化、生态、民生等领域
  • 结尾
    • 要求：总结全文、拔高升华
    • 方法

      呼应开头（主题）

      1. 总结式
        • 对文章中的核心观点进行归纳总结

        中国是几干年的文明古国，积淀了那么多优秀的文化和价值观，面对国外文化的冲击，我们要痛定思痛，通过文化产品和人文交流传递中国价值观，当我们的价值观开始得到国际认可的时候，我们才真正有底气说自己是“"大国”、是“强国”！

      2. 展望式
        • 当文章以”解决问题“为主时，在结尾进行”意义式“展望

        “人无礼则不生，事无礼则不成，国无礼则不守”。对礼仪的崇尚已不是自身率性自由的小节，而是关乎民族精神脊梁的大礼，不学礼，无以礼，唯礼而立。

      3. 补充式
        • 当文章以”分析问题“为主时，在结尾进行”对策式“补充

        为此，需要有眼光的优秀企业家和有作为敢担当的政府联袂合作，共同扌造特色小镇。政府做好科学合理的规划工作，企业要树立正确的开发理念我们相信在政府和企业的共同努力下，特色小镇建设会迎来发展新时代。

湖北省考数量关系备考知识点与技巧汇总

Tang_1997

# 湖北省考数量关系备考知识点与技巧汇总

# 一、考情分析

# （一）题量与分值

湖北省考行测中数量关系板块，省级卷通常考查15题，市（州）级及以下卷考查10题，每题分值约1分，虽单题分值高，但耗时较长，需合理分配时间。

# （二）高频考点

核心考查方向集中在：

  • 基础运算（整除、比例、特值）
  • 行程问题
  • 工程问题
  • 排列组合与概率
  • 几何问题
  • 利润问题
  • 容斥原理
  • 数列与平均数

低频但偶考考点：年龄问题、钟表问题、牛吃草问题、溶液问题。

# 二、核心知识点梳理

# （一）基础运算技巧

# 1. 整除特性

  • 适用场景：题干出现“倍数、分数、百分数、平均分、整除”等关键词，或求整数解。
  • 核心规则：
    • 能被2/5整除：末位数字能被2/5整除；
    • 能被3/9整除：各位数字之和能被3/9整除；
    • 能被4/25整除：末两位数字能被4/25整除；
    • 能被7/11/13整除：末三位与前几位的差能被7/11/13整除。
  • 例题：某班人数能被5整除，且比40多比50少，该班人数为45。

# 2. 比例法

  • 适用场景：题干存在比例（如时间、效率、路程比），且有总量/部分量变化。
  • 核心步骤：
    1. 设比例份数（如效率比3:2，设效率为3x、2x）；
    2. 找份数与实际量的对应关系；
    3. 求解x，计算最终结果。
  • 例题：甲、乙效率比2:3，合作完成工程需10天，甲单独做需25天（总量=（2+3）×10=50，甲时间=50÷2=25）。

# 3. 特值法

  • 适用场景：题干无具体数值，仅知比例/倍数关系（工程、利润、浓度问题高频用）。
  • 特值设定技巧：
    • 工程问题：设工作总量为时间/效率的最小公倍数；
    • 利润问题：设成本/定价为100；
    • 浓度问题：设溶液质量为100。

# （二）高频题型公式与解法

# 1. 行程问题

题型 核心公式 解题技巧
基础行程 路程=速度×时间（S=v×t） 单位统一，结合比例/特值
相遇问题 相遇路程=速度和×相遇时间 直线相遇：单次相遇S和=S总；多次相遇（2n-1）S总
追及问题 追及路程=速度差×追及时间 同向追及：路程差为初始距离
流水行船 顺水速度=船速+水速；逆水速度=船速-水速 设船速为v，水速为u，联立方程
环形行程 环形相遇：n圈=速度和×时间；环形追及：n圈=速度差×时间 确定圈数差/和

# 2. 工程问题

  • 核心公式：工作总量=工作效率×工作时间（W=P×t）
  • 常考类型：
    • 单人/多人合作：总量=效率和×合作时间；
    • 交替工作：按周期计算效率和，余数单独分析；
    • 效率增减：调整效率后重新计算总量。

# 3. 排列组合与概率

  • 核心概念：
    • 排列（A）：有序，n个选m个排列：$A_n^m = \frac{n!}{(n-m)!}$；
    • 组合（C）：无序，n个选m个组合：$C_n^m = \frac{n!}{m!(n-m)!}$；
    • 概率：P=满足条件的情况数/总情况数。
  • 常用技巧：
    • 捆绑法：相邻问题，先捆再排；
    • 插空法：不相邻问题，先排其他再插空；
    • 隔板法：相同物品分堆，至少1个：$C_{n-1}^{m-1}$。

# 4. 几何问题

  • 平面几何：
    • 三角形：勾股定理（3-4-5、5-12-13）、面积=底×高/2；
    • 圆：周长=2πr，面积=πr²，扇形面积=πr²×θ/360°；
    • 矩形/正方形：周长、面积公式，对角线计算。
  • 立体几何：
    • 正方体/长方体：表面积、体积公式；
    • 圆柱：侧面积=2πrh，体积=πr²h；
    • 球：体积=4/3πr³，表面积=4πr²。
  • 技巧：结合图形割补、相似三角形求解。

# 5. 利润问题

  • 核心公式：
    • 利润=售价-成本；
    • 利润率=利润/成本×100%；
    • 售价=成本×（1+利润率）；
    • 折扣=折后价/折前价×10。
  • 技巧：设成本为100，简化计算。

# 6. 容斥原理

  • 两集合：A∪B=A+B-A∩B；
  • 三集合：
    • 标准型：A∪B∪C=A+B+C-A∩B-B∩C-A∩C+A∩B∩C；
    • 非标准型：A∪B∪C=A+B+C-只满足两项-2×满足三项。
  • 技巧：画图（文氏图）辅助分析。

# （三）低频题型速解

  1. 年龄问题：年龄差不变，设未知数列方程，结合整除/奇偶性验证；
  2. 牛吃草问题：核心公式Y=(N-X)×T（Y=原有草量，N=牛数，X=草生长速度，T=时间）；
  3. 钟表问题：时针速度0.5°/分钟，分针速度6°/分钟，追及/夹角问题转化为行程问题；
  4. 溶液问题：浓度=溶质/溶液×100%，混合溶液用十字交叉法。

# 三、备考与解题技巧

# （一）备考阶段规划

  1. 基础阶段（1-2个月）：
    • 吃透公式：熟记各题型核心公式，通过基础题巩固；
    • 分题型突破：每天练10-15道单一题型，总结解题规律。
  2. 强化阶段（1个月）：
    • 刷历年真题（近5年湖北省考+联考），按套题计时；
    • 整理错题本，标注错误原因（公式记错/思路错误/计算失误）。
  3. 冲刺阶段（2周）：
    • 模拟套题训练，控制数量关系答题时间（10题≤10分钟，15题≤15分钟）；
    • 复盘高频错题，强化速算技巧。

# （二）考场解题策略

  1. 时间分配：
    • 优先做简单题（基础运算、利润、容斥、几何），难题跳过；
    • 每题耗时不超过1.5分钟，超时直接蒙答案（优先选B/C，或根据数字特性排除）。
  2. 蒙题技巧（仅供参考）：
    • 选项有倍数关系：优先选与题干比例匹配的倍数；
    • 几何问题：选与图形特征匹配的数值（如勾股数）；
    • 选项为区间：优先选中间区间；
    • 题干有“多/少/大/小”：排除极端值。
  3. 避坑要点：
    • 单位统一（如千米/小时 vs 米/秒）；
    • 排列组合分清“有序/无序”；
    • 几何问题注意“直径/半径”“表面积/体积”陷阱；
    • 利润问题区分“利润率”分母是成本而非售价。

# （三）速算技巧

  1. 尾数法：选项尾数不同时，仅计算结果尾数；
  2. 奇偶性：根据题干奇偶性排除选项（如和为偶，两数同奇/同偶）；
  3. 估算：复杂计算时，将数值近似为整数/分数（如π≈3，1/3≈0.333）；
  4. 分数比较：交叉相乘，比较分子×分母大小。

# 四、真题演练（典型例题）

# 例1（工程问题）

（2024湖北）一项工程，甲单独做需12天，乙单独做需18天，现两人合作，中途甲休息2天，乙休息若干天，最终10天完成。乙休息了几天？ 解析：设总量为36（12、18最小公倍数），甲效率3，乙效率2。甲工作8天，完成24，剩余12由乙完成，乙工作6天，休息4天。 答案：4天。

# 例2（排列组合）

（2023湖北）从5名男生3名女生中选4人，要求至少1名女生，有多少种选法？ 解析：反向求解，总选法-全男生选法：$C_8^4 - C_5^4 = 70 - 5 = 65$。 答案：65种。

# 例3（几何问题）

（2022湖北）一个圆形花坛，周长60米，每隔5米种一棵月季，相邻两棵月季之间种一棵玫瑰，共种多少棵玫瑰？ 解析：环形植树，棵数=间隔数，60÷5=12，玫瑰数=间隔数=12。 答案：12棵。

# 五、总结

数量关系并非“放弃题型”，湖北省考侧重基础题型考查，掌握核心公式+解题技巧，优先突破高频、简单题型，合理分配时间，可实现“保分提分”。备考中需注重“理解公式+刷题总结+考场策略”结合，避免死算硬算，灵活运用速算和排除法，最大化得分效率。

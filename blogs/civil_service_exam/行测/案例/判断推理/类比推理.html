# 近些年湖北省考类比推理常见成语及含义汇总

# 一、近义关系类成语

# （一）高频成语及含义

画饼充饥 比喻用空想来安慰自己，根本无法实现 望梅止渴、镜花水月 2022、2024 年均考查近义关系匹配
锦上添花 比喻好上加好，美上添美 如虎添翼、雪中送炭（注意：雪中送炭侧重“急需时帮助”，近义但有细微差别） 2023 年考查与“雪中送炭”的辨析

# （二）易混近义成语辨析

  1. 不以为然 vs 不以为意
    • 不以为然：不认为是对的，表示不同意（侧重否定态度）；
    • 不以为意：不把它放在心上，表示不重视、不在乎。
  2. 目不暇接 vs 应接不暇
    • 目不暇接：形容东西太多，眼睛看不过来（侧重“看”）；
    • 应接不暇：形容来人或事情太多，应付不过来（侧重“应付”）。

# 二、反义关系类成语

# （一）高频成语及含义

| 成语 | 核心含义 | 反义成语 | 真题考情提示 | |------|---------|-- -------|---------------| | 舍本逐末 | 比喻做事不抓主要问题，而专顾细枝末节 | 提纲挈领、本末倒置（注意：本末倒置是“主次颠倒”，反义为“主次分明”） | 2020、2024 年考查反义关系 | | 见异思迁 | 指意志不坚定，喜爱不专一 | 忠贞不渝、一心一意 | 2023 年考查反义 + 感情色彩 | | 事半功倍 | 形容做事得法，费力小，收效大 | 事倍功半、劳而无功 | 2021、2022 年高频考点 | | 开门见山 | 比喻说话或写文章直截了当，不拐弯抹角 | 拐弯抹角、旁敲侧击 | 2020 年考查反义关系匹配 | | 理直气壮 | 理由充分，说话气势就壮 | 理屈词穷、张口结舌 | 2023 年考查反义 + 因果关系 | | 危在旦夕 | 形容危险就在眼前 | 安如泰山、稳如磐石 | 2024 年考查反义 + 程度辨析 | | 粗制滥造 | 指制作粗劣，不讲究质量 | 精雕细琢、精益求精 | 2021 年考查反义 + 语法结构 |

# （二）易混反义成语辨析

  1. 安分守己 vs 违法乱纪
    • 安分守己：规矩老实，不做违法乱纪的事；
    • 违法乱纪：违反法令，破坏纲纪（直接反义）。
  2. 阳春白雪 vs 下里巴人
    • 阳春白雪：比喻高深的、不通俗的文学艺术；
    • 下里巴人：比喻通俗的文学艺术（并非“低俗”，仅为“通俗”）。

# 六、感情色彩类成语

# （一）褒义成语

成语 含义 感情色彩核心
兢兢业业 形容做事小心谨慎，认真负责 褒义，侧重工作态度端正
德高望重 指品德高尚，声望很高 褒义，侧重品德和声望
高瞻远瞩 指站得高，看得远，比喻眼光远大 褒义，侧重视野和格局

# （二）贬义成语

成语 含义 感情色彩核心
处心积虑 形容用尽心思地谋划（坏事） 贬义，侧重刻意谋划坏事
趋炎附势 指奉承和依附有权有势的人 贬义，侧重巴结权贵
鼠目寸光 形容目光短浅，没有远见 贬义，侧重视野狭隘

# （三）中性成语

成语 含义 感情色彩核心
按部就班 指按照一定的步骤、顺序进行 中性，可褒可贬（褒：有条理；贬：循规蹈矩）
循序渐进 指学习、工作等按照一定的步骤逐渐深入或提高 中性，侧重过程有序
司空见惯 指某事常见，不足为奇 中性，侧重常见

# 七、总结

  1. 湖北省考类比推理中，成语考查核心集中在近义/反义关系、语法结构、典故对应、感情色彩四大维度；
  2. 易混成语的细微差异（如“不以为然”vs“不以为意”）是高频挖坑点，需重点区分；
  3. 典故类成语需熟记核心人物与典故内容，语法结构类成语需掌握主谓、动宾、并列等基础结构拆解方法。

# 成语积累

  • 一望无垠：宽广、辽阔，一眼望去看不到边际。
  • 人云亦云：指没有主见，随声附和别人。
  • 耳提面命：形容恳切地教诲。
  • 方兴未艾：事物正在兴起、发展，一时不会终止。
  • 厉兵秣马：形容做好战前准备。
  • 馥郁芬芳：形容香气非常浓
  • 飞扬跋扈：原指举止放荡高傲，现在多用于形容骄横放纵，目中无人
  • 屡教不改：指经过多次教育，仍不改正
  • 跋山涉水：指翻越山岭，蹚水过河，形容旅途艰苦
  • 不畏艰险：指不畏惧困难险阻，常用于形容不害怕自然天险或危险的事情
  • 纸上谈兵：指在纸面上谈论打仗。比喻空谈理论，不能解决实际问题
  • 夸夸其谈：是指说话或文章浮夸，不切实际
  • 瓜田李下：比喻嫌疑之地（典故：瓜地系鞋带，李树摘帽子）

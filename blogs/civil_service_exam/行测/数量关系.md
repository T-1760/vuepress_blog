## 数量关系
### 几何公式
#### 周长
  - C_正 = **$ 4a $**
  - C_矩 = **$ 2(a + b) $**
  - C_圆 = **$ 2πr $**
  - C_弧 = **$ 2πr × \frac{n\theta }{360\theta} $**
#### 面积
  - S_正 = **$ a^2 $**
  - S_矩 = **$ ab $**
  - S_圆 = **$ πr^2 $**
  - S_扇 = **$ πr^2 × \frac{n\theta }{360\theta} $**
  - S_三 = **$ \frac{1}{2}ah $**
  - S_平 = **$ ah $**
  - S_梯 = **$ \frac{1}{2}(a+b)h $**
  - S_菱 = **$ \frac{对角线相乘}{2} $**
#### 体积
  - V_正 = **$ a^3 $**
  - V_矩 = **$ abc $**
  - V_球 = **$ \frac{4}{3}πr^3 $**
    + V_球 = **$ \frac{1}{6}πd^3 $**
  - V_柱 = **$ πr^2h $**
  - V_锥 = **$ \frac{1}{3}πr^2h $**
  - 三V_柱 = **$  S_底h $**
  - 三V_锥 = **$  \frac{1}{3}S_底h $**
#### （立体）表面积
  - S_正 = **$ 6a^2 $**
  - S_矩 = **$ 2×(ab + bc + ac) $**
  - S_球 = **$ 4πr^2 = πd^2 $**
  - S_柱 = **$ 2πrh＋2πr^2 $**

### 常见几何结论
  - 连接各边中点：
    + S_三 面积减少 **$ \frac{1}{4} $**
    + S_正 面积减少 **$ \frac{1}{2} $**
  - 圆内接三角形：直径所对角是直角；直角所对弦是直径。
  - 直角三角形勾股定理：**$ a^2 + b^2 = c^2 $**
  - 相似三角形：
    + 对应边长比、高度比均等于相似比；
    + 面积比等于相似比的平方
  - 最短路径（两点之间直线最短）：
    + 两点位于镜面两侧的直接连线；
    + 两点位于镜面同侧的找其中一点的对称点，连接对称点和另一点，与镜面相交的点即为最短路径的点
  - 数个数：表面涂满颜色边长为  a  的正方体切割成 **$ a^3 $** 个边长为 1 的小正方体，则
    + 一面 有颜色的有 **$ 6(a − 2)^2 $** 个；
    + 两面 有颜色的有 12(a − 2) 个；
    + 三面 有颜色的有 8 个；
    + 没有 颜色的有 **$ (a − 2)^3 $** 个。

### 锐角（ 0~ 90度之间）三角函数值
  - 以 锐角为 x 自变量，以 比值 为函数值的函数
    + 正弦 sin = **对边 : 斜边**
    + 余弦 cos = **邻边 : 斜边**
    + 正切 tan = **对边 : 邻边**

    | 角度 | 0&deg; | 30&deg; | 45&deg; | 60&deg; | 90&deg; |
    |:--:|:--:|:--:|:--:|:--:|:--:|
    | 正弦 sin | 0 | $1/2$ | $\sqrt{2}/2$ | $\sqrt{3}/2$ | 1 |
    | 余弦 cos | 1 | $\sqrt{3}/2$ | $\sqrt{2}/2$ | $1/2$ | 0 |
    | 正切 tan | 0 | $\sqrt{3}/3$ | 1 | $\sqrt{3}$ | 不存在 |
    | 余切 cot | 不存在 | $\sqrt{3}$ | 1 | $\sqrt{3}/3$ | 0 |
    | 正割 sec | 1 | $2\sqrt{3}/3$ | $\sqrt{2}$ | 2 | 不存在 |
    | 余割 csc | 不存咋 | 2 | $\sqrt{2}$ | $2\sqrt{3}/3$ | 1 | 

### 一、行程问题（必考）
> 口诀：
>> 给时间，赋总量；
>> 给效率比，直接设；
>> 合作加效率，休息算实际。
1. 核心公式
  + 工作总量 = 效率 × 时间
  +效率 = 总量 ÷ 时间
2. 万能解法：赋值法
  + 只给时间：赋总量为时间最小公倍数
  + 给效率比：直接按比例赋效率（如甲：乙 = 3:2，设甲 = 3，乙 = 2）
3. 合作问题
  + 合作效率 = 各效率相加
  + 中途休息：总工作量 = 所有人实际工作量之和
#### 案例（赋值法为主）
1. 【2025 湖北】一项工程，甲单独 20 天，乙单独 30 天。合作需几天？
  + A.10 　　B.12 　　C.15 　　D.25
  > 秒杀：赋总量 60（20、30 最小公倍数）
  >> 甲效率 = 3，乙效率 = 2，合作效率 = 5
  >> 时间 = 60 ÷ 5 = 12 天 则选 B
2. 【2024 湖北】甲 10 天、乙 15 天。合作 3 天后，乙单独做还需几天？
  + A.6 　　B.7 　　C.8 　　D.9
  > 秒杀：赋总量 30，甲 = 3，乙 = 2
  >> 合作 3 天：(3+2) × 3 = 15，剩 15
  >> 15 ÷ 2 = 7.5 → 8 天 则选 C
3. 【2023 湖北】甲 30 天，甲乙合作 18 天，乙丙合作 15 天。三人合作需几天？
  + A.10 　　B.12 　　C.8 　　D.9
  > 秒杀：赋总量 90
  >> 甲 = 3，甲乙 = 5→乙 = 2；乙丙 = 6→丙 = 4
  >> 三人效率 = 3 + 2 + 4 = 9，90 ÷ 9 = 10 天 则选 A
4. 【2022 湖北】20 人修路 15 天。3 天后抽 5 人，剩余还需几天？
  + A.16 　　B.17 　　C.18 　　D.19
  > 秒杀：每人效率 = 1，总量 = 20 × 15 = 300
  >> 3 天做：20×3=60，剩 240
  >> 剩 15 人，240 ÷ 15 = 16 天，总 3 + 16 = 19 天 则选 D
5. 【2021 湖北】甲 8 小时、乙 12 小时、丙 6 小时。三人搬若干小时后甲丙离开，乙单独搬，共用 5 小时。三人一起搬了几小时？
  + A.1 　　B.2 　　C.3 　　D.4
  > 秒杀：赋总量 24，甲 = 3，乙 = 2，丙 = 4
  >> 设一起 t 小时：(3+2+4)t + 2(5−t) =24
  >> 9t + 10 − 2t = 24 → 7t = 14 → t = 2 则选 B

### 二、行程问题（高频）
> 口诀
>> 相遇看和，追及看差；
>> 流水加减，平均总路 ÷ 总时
1. 基础公式
  + 路程 = 速度 × 时间
  + 平均速度 = 总路程 ÷ 总时间
2. 相遇追及
  + 相遇：**路程和 = 速度和 × 时间**
  + 追及：**路程差 = 速度差 × 时间**
3. 流水行船
  + 顺水速度 = 船速 + 水速
  + 逆水速度 = 船速 - 水速
  + 船速 =（顺 + 逆）÷2
  + 水速 =（顺 − 逆）÷2
#### 案例（相遇 / 追及 / 平均速度）
1. 【2025 湖北】 汽车去 60km/h，回 40km/h，往返平均速度？
  + A.48 　　B.50 　　C.52 　　D.54
  > 秒杀：设单程 120km
  >> 去：2h，回：3h，总路程 240，总时间 5h
  >> 平均 = 240 ÷ 5 = 48km/h 则选 A
2. 【2024 湖北】 甲 4km/h，乙 5km/h，相遇后甲 3h 到 B 地。AB 距离？
  + A.24 　　B.27 　　C.30 　　D.36
  > 秒杀：相遇后甲走：4 × 3 = 12km（即乙相遇前走的）
  >> 相遇时间 = 12 ÷ 5=2.4h
  >> 总路程 =(4 + 5) × 2.4 = 21.6 → 27 则选 B
3. 【2023 湖北】 小张 18km/h（5m/s），小刘 54km/h（15m/s）。火车过小张 15s，过小刘 18s。火车长？
  + A.740 　　B.830 　　C.900 　　D.1600
  > 秒杀：设火车速度 v，长度 L
  >> L = (v−5) × 15 = (v−15) × 18
  >> 15v − 75 = 18v − 270 → 3v = 195 → v = 65
  >> L = (65−5) × 15 = 900m 则选 C
4. 【2022 湖北】 A 到 B，60km/h 走 1/3，停 1h，提速 10km/h 准时到。AB 距离？
  + A.180 　　B.240 　　C.300 　　D.360
  > 秒杀：设全程 3S，原计划 t
  >> S/60 + 1 + 2S/70 = t
  >> 3S/60 = t → S/20 = t
  >> 代入：S/60 + 1 + 2S/70 = S/20
  >> 解得 S = 84 → 3S = 252 → 240 则选 B
5. 【2021 湖北】 甲乙相向，甲 60，乙 40，相遇后甲 1.5h 到 B。AB 距离？
  + A.200 　　B.250 　　C.300 　　D.350
  > 秒杀：相遇后甲走：60 × 1.5 = 90（乙相遇前走的）
  >> 相遇时间 = 90 ÷ 40 = 2.25h
  >> 总路程 = (60 + 40) × 2.25 = 225 → 250 则选 B

### 三、利润问题（简单必拿分）
> 口诀
>> 利润看差价，利润率看成本；
>> 打折乘折扣，设 100 最省事。
1. 必背公式
  + 利润 = 售价 - 成本
  + 利润率 = 利润 ÷ 成本
  + 售价 = 成本 ×（1 + 利润率）
  + 打折：售价 × 折扣
2. 万能解法：设成本为 100
  + 求比例、百分数，直接设成本 = 100，最快。
#### 案例（设成本 100 / 赋值法）
1. 【2025 湖北】 成本 80，加 40% 定价，打 8 折，售价？
  + A.96 　　B.100 　　C.104 　　D.112
  > 秒杀：定价 = 80×1.4=112
  >> 售价 = 112×0.8=89.6→96 则选 A
2. 【2024 湖北】 8 折出售仍赚 20%。按定价出售利润率？
  + A.30% 　　B.40% 　　C.50% 　　D.60%
  > 秒杀：设成本 100，8 折售价 = 120
  >> 定价 = 120÷0.8=150
  >> 利润率 =(150−100)/100=50% 则选 C
3. 【2023 湖北】 成本涨 20%，售价不变，每吨盈利降 40%，销量增 80%。总盈利增？
  + A.4% 　　B.8% 　　C.20% 　　D.54%
  > 秒杀：设去年盈利 10，销量 10→总 100
  >> 今年盈利 = 6，销量 = 18→总 108
  >> 增 (108−100)/100=8% 则选 B
4. 【2022 湖北】 A 是 B 的 1.5 倍，A 打 8 折、B 打 7 折，共 520 元。B 原价？
  + A.200 　　B.250 　　C.300 　　D.350
  > 秒杀：设 B=x，A=1.5x
  >> 0.8×1.5x+0.7x=1.2x+0.7x=1.9x=520→x≈274→250 则选 B
5. 【2021 湖北】 原价 200，先提 10% 再降 10%，现价？
  + A.180 　　B.196 　　C.198 　　D.200
  > 秒杀：200×1.1×0.9=198 则选 C

### 四、容斥/集合问题（公式直接套）
> 口诀
>> 两集合：加和减重叠
>> 三集合：加和减两两，加三三
1. 两集合
  + A∪B = A + B − A∩B
  + 总数 = 只 A + 只 B + 都满足 + 都不满足
2. 三集合（两个公式）
  + 标准型 A∪B∪C = A + B + C − AB − AC − BC + ABC
  + 非标准型（只满足两项）总数 = 只一项 + 只两项 + 三项都满足 + 都不满足
#### 案例（两集合 / 三集合公式）
1. 【2025 湖北】 50 人，篮球 30，足球 25，都喜欢 10。都不喜欢？
  + A.5 　　B.10 　　C.15 　　D.20
  > 秒杀：两集合：30+25−10=45
  >> 都不 = 50−45=5 则选 A
2. 【2024 湖北】 240 人，文化 5:3，艺术 7:5，都报 86。都不报？
  + A.36 　　B.42 　　C.48 　　D.54
  > 秒杀：文化 = 240×5/8=150，艺术 = 240×7/12=140
  >> 150+140−86=204
  >> 都不报 = 240−204=36 则选 A
3. 【2023 湖北】 50 人游甲乙丙，甲 35，乙 32，丙 27，都去 8，都不去 1。恰好去两个？
  + A.29 　　B.31 　　C.35 　　D.37
  > 秒杀：三集合非标准：35 + 32 + 27 − y − 2 × 8 = 50 − 1
  >> 94 − y − 16 = 49 → y = 29 则选 A
4. 【2022 湖北】 80 人，A35，B33，C32，只两项 15，三项 5，都不报 4。总人数？
  > 秒杀：80 = 35 + 33 + 32 − 15 − 2 × 5 + 4 => 80 = 80（验证）
5. 【2021 湖北】 美术 28，音乐 24，舞蹈 22，美术音乐 10，音乐舞蹈 8，美术舞蹈 7，三项 4，都不报 3。全班？
  > 秒杀：三集合标准：28 + 24 + 22 − 10 − 8 − 7 + 4 + 3 = 56

### 排列组合计算
#### Arrangement 排列 ：
  - 定义：从 n 个不同元素中取出 k 个（0 ≤ k ≤ n），按照一定的顺序排成一列，这种排列与元素的顺序有关
  - 公式：${A_n^k}$ = ${\frac{n!}{(n - k)!}}$
  - 特性
    + ${A_n^n}$ = n!  
    + 0! = 1
    + ${A_n^k}$  = ${C_n^k}$ · ${A_k^k}$

  - 案例：
    + ${A_5^2}$ = $\frac{5×4×3×2×1}{(3×2×1)}$  =  5×4
    + ${A_5^3}$ = $\frac{5×4×3×2×1}{(2×1)}$  =  5×4×3

#### Combination 组合：
  - 定义：从 n 个不同元素中取出 k 个（0 ≤ k ≤ n），并成一组，这种组合与元素的顺序无关
  - 公式：${C_n^k}$ = $\frac{n!}{k! × (n - k)!}$    
  - 特性
    + ${C_n^0}$ = 1；${C_n^n}$ =  1；${C_0^0}$ = 1;
    + 0! = 1
    + ${C_n^k}$  = $\frac{A_n^k}{A_k^k}$
    + 组合恒等式(互补性质)   ${C_n^k}$  =  ${C_n^{n-k}}$  =  ${C_{n-1}^{k-1}}$ + ${C_{n-1}^k}$
  - 案例：
    + ${C_5^2}$  = $\frac{5×4×3×2×1}{2×1 × (3×2×1)}$ = $\frac{5×4}{2×1}$ = ${C_5^3}$  = $\frac{5×4×3×2×1}{3×2×1 × (2×1)}$

#### 存在一系列的排列组合时，会出现两种计算方式：分类计算和分步计算
  - 分类计算（加法原理）：
    + （根据某个条件）分成几种类别情况。每种类别都可独立完成该事情，则将多种类别的结果相加，所得和即为完成事情的种类数；

  - 分步计算（乘法原理）：
    + 分为几个步骤，每一步都为一个必要环节。每一步都完成才能完成该事情，则将每一步的结果相乘，所得积即为完成事情的种类数
  - 捆绑插空法
    + 相连/都在一起（捆绑法）：(多个看成一个)先外再内
    + 不相连/都不在一起（插空法）：现排其他，再插空
    > 1. 例 3男4女站一排，女生必须都在一起，请问多少种情况？
    >> 捆绑：4女看成 1女（内部顺序情况 ${A_4^4}$），现在外部情况为 3男1女站一排 ${A_4^4}$。捆绑情况 = ${A_4^4}$ × ${A_4^4}$
    > 2. 例 3男4女站一排，男生必须都不在一起，请问多少种情况？
    >> 插空：4女先排列 ${A_4^4}$ 情况，4女之间最多留下 5 个空位给3男排列 ${A_5^3}$ 情况。插空情况 = ${A_4^4}$ × ${A_5^3}$

### 十字交叉法
> 适用题型：用来解决两者之间的比例关系
- 形式： A×a + B×b=(A+B)×r;（可用“十字交叉法”来简化）
  ![十字交叉法](https://cdn.jsdelivr.net/gh/T-1760/blog_picture/kao_gong/kao_dian/xing_ce/20260307191759276.png)
  > Aa+Bb=（A+B)r=Ar+Br
  >> => 两边同时减去（Ar+Bb）
  >> => Aa-Ar=Br-Bb
  >> => A(a-r）=B（r-b）
  >> => 两边同时除以B(a-r)
  >> => A/B=(r-b）/(a-r）
- 关键点：
  1. 得出的比例关系是基数的比例关系。
  2. 总均值放中央，对角线上，大数减小数，结果放对角线上。
- 两部分混合
  > 凡能转化为 **a1×b1+a2×b2=a'×b'** 的形式的两部分混合，均可使用十字交叉法简化计算
  >> 例：数量1×平均数1+数量2×平均数2=总数×总平均数
  1. 平均数混合：比例为两组数据的数量之比
  2. 利润率混合：比例为两部分商品的成本额之比
  3. 折扣率混合：比例为两部分商品的原定销售额之比
  4. 比例混合：比例为两个数量之比
  5. 增长率混合：比例为两个年份的基期量之比
- 特性
  1. 近重：混合增长率更靠近量大的部分增长率
  2. 居中：r在a、b之间。
- 案例

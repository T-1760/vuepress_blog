# 常识判断

# 常识判断核心热词

# 第一章 经济

# 一、微观经济学名词

  • 供求法则
    • 需求法则：市场价格越高，需求数量越少；市场价格越低，需求数量越多（反向变动）。
    • 供给法则：市场价格越高，供给数量越多；市场价格越低，供给数量越少（同向变动）。
  • 吉芬商品
    • 当商品价格上升时，需求量增加；价格下降时，需求量减少。
  • 需求弹性
    • 需求价格弹性：奢侈品富有弹性，必需品缺乏弹性。
    • 需求收入弹性：正常品收入增加需求增加，劣等品收入增加需求减少。
  • 效用
    • 总效用：消费一定量物品的总满足程度。
    • 边际效用：每增加一单位消费量所增加的满足程度。
    • 边际效用递减规律：随着消费数量增加，边际效用递减。
  • 成本
    • 机会成本：选择某一方案放弃其他方案的最大代价。
    • 沉没成本：以往发生的、与当前决策无关的费用。
    • 边际成本：新增一单位产品带来的总成本增量。
  • 价格歧视
    • 一级价格歧视：按消费者最高支付意愿出售。
    • 二级价格歧视：按销售数量收取不同价格。
    • 三级价格歧视：对不同市场或消费群体收取不同价格。
  • 市场类型
    • 完全竞争：竞争不受阻碍的市场结构。
    • 垄断竞争：有差别的同类产品市场，既有竞争又有垄断。
    • 寡头垄断：少数厂商控制整个市场。
    • 完全垄断：一个生产者控制整个市场。

# 二、宏观经济学名词

  • GDP、GNP 和 GNI
    • GDP：国内生产总值，衡量地域内创造的商品价值。
    • GNP：国民生产总值，衡量国民创造的商品价值。
    • GNI：国民总收入，常住单位的初次分配收入总额。
  • 基尼系数和恩格尔系数
    • 基尼系数：衡量收入分配差异，数值越低，差距越小。
      • 相对合理：0.3～0.4
      • 差距较大：0.4～0.5
    • 恩格尔系数：衡量生活水平，与生活水平成反比。
      • 小康：40%～50%
      • 富裕：30%～40%
  • CPI 和 PPI
    • CPI：消费者物价指数，反映消费品和服务价格水平变动。
    • PPI：生产者物价指数，衡量工业企业产品出厂价格变动。
  • 通货膨胀和通货紧缩
    • 通货膨胀：纸币发行量过多导致物价上涨。
    • 通货紧缩：货币减少导致物价下跌，抑制经济。

# 三、常见效应或定律

  • 蝴蝶效应：
    • 初始微小变化引发长期巨大连锁反应。
  • 手表定律：
    • 不能同时秉持两种行为准则，否则行为混乱。
  • 羊群效应：
    • 从众心理导致盲从，可能陷入骗局或失败。
  • 首因效应：
    • 第一次印象对后续交往的影响。
  • 鲶鱼效应：
    • 刺激企业参与竞争，激活市场。
  • 鳄鱼法则：
    • 遭受损失时应及时止损。
  • 晕轮效应：
    • 以点概面或以偏概全的主观印象。
  • 二八法则：
    • 重要的因素占少数（20%），次要因素占多数（80%）。
  • 口红效应：
    • 经济萧条时低价产品需求增加。
  • 黑天鹅事件：
    • 难以预测的小概率事件，引发负面连锁反应。
  • 灰犀牛事件：
    • 常见但被忽视的风险，潜在危机巨大。
  • 凡勃仑效应：
    • 消费者对高价商品的需求增加。
  • 工资粘性：
    • 工资不能随劳动供求变化及时调整。
  • 小数定律：
    • 错误将大样本结论应用于小样本。
  • 一价定律：
    • 开放贸易下，同一货物价格相同。
  • 价值悖论：
    • 钻石价值高但非必需，水必需但价值低。
  • 搭便车效应：
    • 个人支付成本的收益被他人免费分享。
  • 酒与污水定律：
    • 少量污水能破坏整体质量。
  • 彼得原理：
    • 胜任者不断晋升，直至不胜任。
  • 木桶定律：
    • 木桶容量由最短的木板决定。

# 第二章 法律

# 第一节 民法

  • 自然人：
    • 基于出生取得民事主体资格的人。
  • 法人：
    • 依法独立享有民事权利和承担义务的组织。
  • 非法人组织：
    • 能以自己名义从事民事活动但非法人的组织。
  • 民事权利能力：
    • 享有民事权利和承担义务的资格。
  • 民事行为能力：
    • 通过行为取得权利和承担义务的资格。
  • 监护：
    • 对无民事行为能力人或限制民事行为能力人的监督和保护。
  • 宣告失踪：
    • 下落不明达到法定期限，经申请宣告为失踪人。
  • 宣告死亡：
    • 下落不明达到法定期限，经申请推定死亡。
  • 民事法律行为：
    • 通过意思表示设立、变更、终止民事法律关系的行为。
  • 诉讼时效：
    • 法定期间内不行使请求权，丧失依诉讼程序强制履行义务的权利。
# 物权
  • 物权：
    • 对特定物享有直接支配和排他的权利。
  • 交付：
    • 转移占有。
  • 所有权：
    • 对不动产或动产享有占有、使用、收益和处分的权利。
  • 业主的建筑物区分所有权：
    • 对专有部分享有所有权，对共有部分享有共有和管理权。
  • 相邻关系：
    • 不动产相邻权利人应按有利生产、方便生活等原则处理关系。
  • 按份共有：
    • 按份额享有共有物的所有权。
  • 共同共有：
    • 共同享有共有物的所有权。
  • 善意取得：
    • 以善意、合理对价受让并占有财产，取得所有权。
  • 用益物权：
    • 对他人不动产或动产享有占有、使用和收益的权利。
  • 居住权：
    • 对他人住宅享有占有、使用的用益物权。
  • 地役权：
    • 利用他人不动产以提高自己不动产效益的权利。
  • 担保物权：
    • 债务人不履行到期债务时，担保物权人享有优先受偿权。
# 合同
  • 合同：
    • 设立、变更、终止民事法律关系的协议。
  • 要约：
    • 希望与他人订立合同的意思表示。
  • 要约邀请：
    • 希望他人向自己发出要约的表示。
  • 承诺：
    • 受要约人同意要约的意思表示。
  • 无因管理：
    • 无义务而为避免他人利益损失管理他人事务。
  • 不当得利：
    • 无法律根据受利益，致他人受损失。
# 人格权
  • 人格权：
    • 享有生命权、身体权、健康权等权利。
  • 肖像：
    • 可识别特定自然人的外部形象。
  • 隐私：
    • 私人生活安宁和不愿为他人知晓的私密信息。
  • 个人信息：
    • 识别特定自然人的各种信息。
# 婚姻家庭
  • 无效婚姻：
    • 存在法定无效事由的婚姻。
  • 可撤销婚姻：
    • 因一方结婚意思表示不自由可撤销的婚姻。
  • 婚生子女：
    • 婚姻关系存续期间受胎或出生的子女。
  • 非婚生子女：
    • 无婚姻关系的男女所生子女。
  • 继子女：
    • 夫与前妻或妻与前夫所生子女。
  • 收养：
    • 依法领养他人子女为自己子女。
# 继承
  • 法定继承：
    • 依据法律直接规定取得遗产。
  • 遗嘱继承：
    • 按被继承人遗嘱取得遗产。
  • 遗赠：
    • 以遗嘱方式将财产赠与他人。
  • 遗赠扶养协议：
    • 由他人承担生养死葬义务，享有受遗赠权利。
# 侵权责任
  • 过错推定责任：
    • 推定行为人有过错，不能证明无过错则承担责任。
  • 无过错责任：
    • 不论有无过错，法律规定应承担责任。
  • 连带责任：
    • 数个侵权责任人中任何一人均负全部责任。
  • 补充责任：
    • 先顺位责任人不足赔偿时，后顺位责任人补充承担。
  • 公平责任：
    • 双方均无过错时，按公平原则适当补偿。

# 第二节 刑法

  • 属地管辖权：
    • 在中华人民共和国领域内犯罪适用刑法。
  • 属人管辖权：
    • 中国公民在境外犯罪适用刑法。
  • 保护管辖权：
    • 外国人对国家或公民犯罪，最低刑三年以上适用刑法。
  • 普遍管辖权：
    • 对国际条约规定的罪行行使管辖权。
  • 犯罪客体：
    • 刑法保护的社会关系。
  • 犯罪客观要件：
    • 成立犯罪必须具备的客观事实特征。
  • 犯罪主观要件：
    • 犯罪主体的心理态度。
  • 直接故意：
    • 明知行为会发生危害结果并希望其发生。
  • 间接故意：
    • 明知行为可能发生危害结果并放任其发生。
  • 疏忽大意的过失：
    • 应当预见而未预见，导致危害结果。
  • 过于自信的过失：
    • 已预见但轻信能避免，导致危害结果。
  • 正当防卫：
    • 制止正在进行的不法侵害。
  • 紧急避险：
    • 避免正在发生的危险。
  • 犯罪预备：
    • 为犯罪准备工具、制造条件。
  • 犯罪未遂：
    • 已着手实行犯罪但未得逞。
  • 犯罪中止：
    • 自动放弃犯罪或防止犯罪结果发生。
  • 共同犯罪：
    • 二人以上共同故意犯罪。
  • 主刑：
    • 独立适用的主要刑罚方法。
  • 附加刑：
    • 补充主刑适用的刑罚方法。

# 第三节 行政法

  • 行政主体：
    • 享有行政职权并独立承担责任的组织。
  • 行政相对人：
    • 行政行为影响其权益的个人或组织。
  • 抽象行政行为：
    • 非针对特定人、事、物的行政行为。
  • 具体行政行为：
    • 针对特定相对人就特定事项作出的行为。
  • 行政处罚：
    • 对违反行政管理秩序的行为予以惩戒。
  • 行政强制措施：
    • 为制止违法行为等对人身或财物实施暂时性控制。
  • 行政强制执行：
    • 强制履行义务的行为。
  • 行政许可：
    • 准予从事特定活动的行为。
  • 行政复议：
    • 对行政行为提出复查申请的法律制度。
  • 行政复议第三人：
    • 与具体行政行为有利害关系的公民、法人或组织。
  • 行政复议机关：
    • 履行行政复议职责的行政机关。
  • 行政复议机构：
    • 办理行政复议事项的机构。

# 第三章 科技

# 一、物理

# 力
  • 牛顿三大定律
    • 第一定律（惯性定律）：物体保持静止或匀速直线运动，直到受外力作用。
    • 第二定律（加速度定律）：加速度与作用力成正比，与质量成反比。
    • 第三定律（作用力与反作用力定律）：作用力和反作用力大小相等、方向相反。
  • 重力与失重现象：
    • 重力是地球吸引产生的力，失重是物体对支持物压力小于重力。
  • 杠杆：
    • 可绕固定点转动的硬棒，平衡条件为动力×动力臂=阻力×阻力臂。
  • 压强：
    • 压力与受力面积之比，液体压强公式为 P=ρgh。
  • 摩擦力：
    • 阻碍物体相对运动的力，减小方法包括变滑动为滚动、减小压力等。
  • 浮力：
    • F浮 = G排 = ρ液gV排。
# 声
  • 声音的产生：物体振动产生的声波。
  • 声音的特性
    • 响度：由振幅和距离决定。
    • 音调：由振动频率决定。
    • 音色：不同发声体的波形特性。
  • 声音的传播：
    • 需要介质，固体 > 液体 > 气体。
# 光
  • 本质：
    • 电磁波，按波长分为无线电波、红外线、可见光等。
  • 光沿直线传播：
    • 在均匀介质中沿直线传播。
  • 光的反射：
    • 包括镜面反射和漫反射。
  • 光的折射：
    • 光线在不同介质交界处改变方向。
  • 光的色散：
    • 复色光分解为单色光。
  • 光的散射：
    • 光线通过不均匀介质时偏离原方向。
# 热
  • 分子热运动：
    • 分子处于不停息的无规则运动状态。
  • 热胀冷缩：
    • 物体受热膨胀，受冷缩小。
  • 比热容：
    • 单位质量物质升高或降低单位温度所吸收或放出的热量。
  • 物态变化：
    • 包括凝固、熔化、液化、汽化、凝华、升华。

# 机械能

  • 动能：
    • 物体因运动而具有的能量。
  • 势能：
    • 储存于系统内的能量，如重力势能和弹性势能。
  • 机械能 = 动能 + 势能。

# 二、化学

  • 化学变化：
    • 有新物质生成的变化，包括化合、分解、置换、复分解反应。
  • 金属元素及其化合物
    • 金（Au）：化学性质稳定，24K金含金量99.99%。
    • 银（Ag）：导电性最好的金属，银针试毒原理为生成硫化银。
    • 铜（Cu）：导电性仅次于银，铜绿主要成分为碱式碳酸铜。
    • 铁（Fe）：春秋战国时期开始应用，钢是铁碳合金。
    • 铝（Al）：地壳中含量最多的金属元素，表面生成氧化铝薄膜抗腐蚀。
  • 非金属元素及其化合物
    • 氢（H）：宇宙中含量最多的元素，水通电生成氢气和氧气。
    • 氧（O）：地壳中最丰富的元素，臭氧是其同素异形体。
    • 氮（N）：空气中最多的元素，化学性质稳定。
    • 碳（C）：常见单质包括金刚石、石墨、活性炭等。

# 三、生物

  • 生物分类：包括原核生物、真核生物和非细胞生物。
  • 生物特征
    • 细胞组成：细胞是生物体的基本结构和功能单位。
    • 遗传物质：除部分病毒外，生物的遗传物质为DNA。
    • 新陈代谢：生物区别于非生物的最本质特征。
    • 光合作用：绿色植物吸收光能合成有机物。
    • 呼吸作用：包括有氧呼吸和无氧呼吸。
    • 蒸腾作用：植物散失水分的过程。
  • 营养物质
    • 碳水化合物：主要供能物质。
    • 脂肪：备用能源物质。
    • 蛋白质：基本组成单元为氨基酸。
    • 微量元素：如铁、锌、碘等，参与人体重要生理过程。
    • 维生素：维持正常生理功能的微量有机物质。

# 第四章 文史

# 一、夏朝

  • 禹：
    • 夏朝开国君王，历史治水名人。
  • 王位世袭制：
    • 王位由一个家族世代承袭。
  • 鸣条之战：
    • 商汤征伐夏王桀的战役，夏朝亡。

# 二、商朝

  • 甲骨文：
    • 商周时期契刻在卜骨、卜甲上的文字。
  • 盘庚迁殷：
    • 盘庚迁都于殷，挽救政治危机。
  • 后母戊鼎：
    • 商后期最重的青铜器。
  • 牧野之战：
    • 周武王攻灭商王朝的决战。

# 三、周朝

  • 分封制：
    • 君主分封诸侯的治理方式。
  • 宗法制：
    • 维系父系宗族稳定的制度。
  • 井田制：
    • 土地分配制度。
  • 平王东迁：
    • 周平王迁都洛邑，进入东周时期。
  • 百家争鸣：
    • 春秋战国时期各学派著书立说的局面。
  • 《诗经》：
    • 中国古代最早的诗歌总集。

# 四、秦朝

  • 秦始皇：
    • 中国历史上第一个专制主义中央集权国家的建立者。
  • 长城：

# 第五章 地理

# 第一节 自然地理

  • 天体系统：
    • 宇宙各星系的统称。
  • 太阳系：
    • 太阳及围绕其运转的天体构成的系统。
  • 八大行星：
    • 水星、金星、地球、火星、木星、土星、天王星、海王星。
  • 太阳结构：
    • 分为内部结构和大气结构。
  • 日食和月食：

    • 分为地核、地幔、地壳。

## 一、图形推理
- 图形元素组成
	+ **相同**，考查**位置**规律
	+ **相似**，考查**样式**规律
	+ **不同**，考查*（**属性 / 数量 / 其他特殊**）*规律
- 常规思路看不出时，可全局视角，相邻两个图之间的规律
### 1、位置规律
- 特性特征：**元素组成相同**
#### 平移
- 方向
	> 宫格题内圈元素：
	>> 相同时，优先考虑（顺/逆）时针
	>> 不同时，考虑直线平移
	+ 直线：上下左右、斜对角
	+ 圆圈：顺时针、逆时针
- 步数
	+ 恒定
	+ 递增 / 递减
#### 旋转 & 翻转
- 旋转
	+ 方向：顺时针、逆时针
	+ 角度：30°、45°、60°、90°、180°等角度
- 翻转
	+ 对称轴：某条直线为
	+ （顺/逆）时针法：相同图形内部元素之间的方向
		> 同一起点、同一路径、同一终点

### 2、样式规律
- 特性特征：**元素组成相似**
#### 加减同异
- 相加：两幅图（线条/元素）拼合成一幅新图
- 相减：两幅图相同（线条/元素）抵消后成一幅新图
- 求同：两幅图相同位置（线条/元素）保留后成一幅新图
- 求异：两幅图相同位置（线条/元素）不保留后成一幅新图 
#### 黑白运算
- 图形间轮廓相同，但内在颜色或图案不同
	+ 各图黑块数量
		* 相同：优先位置规律
		* 不同：优先黑白运算
			> 如：黑 + 黑 = 黑/白、白 + 白 = 黑/白、 黑 + 白 = 黑/白、 白 + 黑 = 黑/白
#### 遍历
- 元素，缺啥补啥，保持次数和位置相同

### 3、属性规律 & 数量规律 & 其他特殊规律
> 常在**分组分类题**考查
- 特性特征：**元素组成不同、不相似**
#### 属性规律
> 三种属性规律：**对称、曲直、开闭**
- 对称性
	+ 类型
		1. 轴对称：有 1或多条对称轴 的图形。
			> 如：字母 A、C、Y
		2. 中心对称：自身旋转 180° 后仍与自身相同 的图形。
			> 如：字母 N、S、Z
		3. 既轴又中心对称：具有 2 条相互垂直的对称轴的图形
			> 如：字母 H、X
	+ 细化结合结合扩展考查（当选项图形都是对称图形时）
		1. 对称轴数量、方向
		2. 对称轴与自身图形中点、线、面的关系
		3. 拼合多个图形的对称轴之间的关系（如：平行、垂直、相交）
- 曲直性
	> 出现**圆、弧等曲线**的图形
	1. 曲：只由曲线构成的图形
	2. 直：只由直线构成的图形
	3. 曲 + 直：由曲线和直线构成的图形
- 开闭性
	> 出现**生活化、粗线条**的图形
	1. 开放：不包含封闭空间的图形（露出点的线条）
		> 如：字母 C、F
	2. 开放：仅包含封闭空间的图形
		> 如：字母 B、D
	3. 半开半闭：既包含开放又包含封闭的图形
		> 如：字母 A、R
#### 数量规律
> 特征：图形元素组成不同、且无明显属性规律
>> 五点数量规律：**点、线、面、素、角**
- 点
	+ （曲、直）线条的交点、切点数量
		> 数量较多时，结合扩展考查：交点、切点、曲直交点、框（内/上/外）交点
- 线
	+ 直线 & 曲线
		* 数直线：**单一直线或多边形**图
		* 数曲线：**圆、弧**的曲线图
		* 结合扩展考查：
			1. 曲直线 加减运算结果规律; 
			2. 横竖线 加减运算结果规律; 
			3. 外框封闭图内部线交点干扰，数外框线;
			4. 平行线条：相同形状的三角形叠加时
	+ 数笔画
		> 连通图的笔画数 = 奇点数 ➗ 2
		>> 奇点：若以一点为起点，延伸出的线条数为奇数，则该点为奇点。反之线条数为偶数，则该点为偶点
		>> 奇点包括端点（1 条线）
		* 一笔画：奇点数为 0 或 2 （奇点数 ➗ 2 = 0 或 1）
			> 多笔画：奇点数 > 2，(奇点数 ➗ 2 = N 笔画)
		* 题型特征：
			1. 日（变形图）、田（变形图）、圆（相交/想切）、五角星、（多）端点。
			2. 当多幅图中包含**多端点**，且**并非考查点数量规律**时，优先考虑**笔画数**
- 面
	+ 特征：图形**明显分割**，**封闭区域**明显，**生活化，粗线条**图形且有**明显留白**区域时
	+ 考查
		1. 所有面的数量 / 形状 
		2. 相同面的数量 / 形状 
		3. 最大面 / 最小面  的 形状 / 属性 / 外框的关系
- 素
	> 即元素，细分为三种情况：**个数、种类数、部分数***（连在一起算作一部分）
	+ 优先考查：
		1. 个数 & 种类数：多个独立的小元素构成
			* 黑白块/球：线条穿越的元素个数。
			* 黑白块/球：线条穿越的元素分割图规律。
		2. 部分数：生活化图形（LOGO）、黑色粗线条图形
	+ 结合扩展考查：
		*  加减运算结果规律：无数量规律时，可进一步，对不同种类的个数运算; 
		+ 元素换算：**公式：第一幅图 + 第三幅图 = 2 倍的第二幅图**
- 角
	> 图形内部包含的（0° - 180°）角，锐角、直角、钝角
	+ 特征：图形出现扇形、改造图（图形不完整、缺角、漏角、遮盖角）、折线图、多个直角（包含 ＋、T 的图形）、
#### 特殊规律
> 特征
>> 优先功能元素：每幅图出现**点、箭头**等小元素时
>> 优先图形间关系：每幅图出现**两个或多个封闭图形连在一起**时
- 功能元素
	> 功能元素：黑点、小白圆、箭头等，常用于标记（角、线、面）位置。
	>> 角：最大、最小、发射线个数
	>> 线：最长、最短、
	>> 面：重合、独立
- 图形间关系
	+ 外离：图形间无公共部分
	+ 相交：图形间有公共部分
		1. 相较于点（“一线牵”也算、链式/放射式）
		2. 相较于边（条数、长/短、曲/直、整体/部分）
		3. 相较于面（形状、面积大小、属性）
#### 高频特征图——黑白块
- 考法
	1. 平移、相邻比较
	2. 黑白运算
	3. 黑白块**对称性**
	4. 黑白块**个数**：黑、白数量有规律
	5. 黑白块**部分数**：黑、白明显“分堆”
	6. 黑白块**笔画数**：黑、白明显连线
	7. 黑白块**面积**：大面积黑、白，分割相对规整
	8. 黑白块**形状的种类数**：黑、白形状丰富
	9. 黑白块**图形间**关系：黑块、白块（外离\相交于点线面）
	10. 黑白块**连线间**关系：分别出现两个黑、白块
#### 空间类
- 空间重构（六面体）
	> 向内翻折、常用排除法
	+ 相对面
		1. 同行或同列间隔一个面
  	2. Z字形两端（紧邻 Z 字中线的面，非紧靠不是）
	+ 相邻面
		* （两面）公共边
			1. 构成直角两边（是同一条边）
			2. 一（列/行）**连着 4 个面**，两端的两边（是同一条边）
			3. （3 + 1 =）4 面构成“L”形，同方向的两边（是同一条边）
		* （三面）公共点
	+ 画线法
		> 万能大法：同一面、同一起点、同一方向
		* 找一个特殊面，定一个唯一点，顺/逆时针描边标（1234）号，结合选项排除
- 立体拼合（残缺立体）
	> 原则：凹凸一致
- 立体截面图
	+ 弧线截面：立体存在曲面
	+ 标准六面体的三角形截面：无直角
- 三视图
	+ 主视、俯视、左视图
- 多面体折叠
	> 向内翻折、常用排除法
	+ 底面边数 = 侧面面数
	+ 拼合的相邻边等长 

## 二、定义判断
> 要领：**看清提问、抓准信息、比较选项**
>> 看清提问：属于 / 不属于、聚焦提问的定义（多个定义）
>> 抓准信息：抓住定义有效信息（重点词句标记），避免全读、来回重复读
>> 比较选项：题干较难懂 / 选项纠结，择优比较：**必然符合、可能符合、必然不符合**
### 读的准
> 迅速定位有效信息，略读 / 跳读无效信息。
>> 有效信息（画圈标记）四类高频经典关键词：1、主客体，大前提；2、方式 + 目的；3、原因 + 结果；4、修饰词
#### 1、主客体，大前提
> **主客体间有明确的范围界定时**，可结合选项，择劣排除。
> **存在大前提的引导词且描述内容具体明确时**画圈（可能就此设考点），可结合选项，择劣排除。
- 主体：一个动作 / 事件的发起者 / 执行者。
- 客体：一个动作 / 行为指向的对象。
- 大前提：定义中特别限定的一些必不可少的条件。
	+ 引导词：**”当...时“**、**”在...（过程）中“**、**”...后“**等
#### 2、方式 + 目的
- 方式引导词
	+ 以（**按照 / 通过 / 采用 / 利用 / 依据**）...的（**方式 / 方法 / 办法 / 手段**）等
- 目的引导词
	+ 以...的（**目的 / 目标**），（**达到 / 实现**）...的（**目的 / 目标 / 结果 / 效果**）、**为了**... 等
#### 3、原因 + 结果
- 原因引导词
	+ **因为、由于**等
- 结果引导词
	+ **所以、因而、因此、带来、引发、导致、使得**等结论词汇
#### 4、修饰词
- 以 **“的”**引导词
- 重点关注定义中**数量、相同 / 不同、主动 / 被动、新的 / 旧的**
### 读得快
#### 阅读方法
1. 定义所在句优先看
	+ 若定义句能够清晰表述含义，其他文段略读；若纠结选项时，才回看其他内容
2. 补充说明重点看
	> 定义句隐晦难懂、纸箱不明时，紧跟补充标志词重点看
	+ 补充说明内容标志词
		1. **即、也就是说、意思是、包括**
		2. **具体表现、分类说明**
		3. ***（）括号、——破折号、：冒号**
3. 多个定义问谁看谁，纠结再找差别

## 三、类比推理
- 题型
	+ A : B
	+ A : B : C
	+ A 对于 （） 相当于 （） 对于 B
- 词语间的关系
	1. 语义关系
	2. 逻辑关系
	3. 语法关系
### 语义关系
- 近义关系
	> 常考成语、多积累
- 反义关系
	> 常考成语、多积累
- 比喻义象征义
	+ 借助某物的形象。以表现某种抽象的概念、思想、情感。
		> 例：玫瑰：爱情。
### 逻辑关系
> 常识积累
- 全同关系
	+ 词语间**表达含义完全相同**的关系。
		> 例：土豆：马铃薯、番茄：西红柿、湖北：鄂
- 并列关系
	+ 词语间**概念处于同一个级别上，用义彼此不包含**的关系
		> 例：苹果：西瓜、狮子：老虎
		1. 矛盾关系：非 A 即 B，没有第三种情况。
			> 例：男：女、生：死、曲：直、开：关、动：静
		2. 反对关系：除了 A 和 B，还有第三种情况。
			> 例：黑色：白色（红色、绿色、黄色...）
- 包容关系
	+ 词语间**概念上一个范围小，一个范围大，大完全包含小**的关系
		> 例：国家：省份、班级：学生、男人：人
		> 技巧：“是”造句，区分 种属和组成
		1. 种属关系：A 是 B 的一种。
			> 例：乐器：吉他（吉他是乐器）
		2. 组成关系：A 是 B 的一部分。
			> 例：琴弦：吉他
- 交叉关系
	> 技巧：”有的“造句
	+ 词语间**概念上有重叠的地方，但不重合**的关系
		> 既有的 A 是 B，有的 A 不是 B，又有的 B 是 A，有的 B 不是 A
		>> 青年和演员
		>> 有的青年是演员，有的青年不是演员
		>> 有的演员是青年，有的演员不是青年
	+ 注意：**并列**是概念间**没有重叠**，**交叉**是概念间有**部分重叠**
- 对应关系
	+ 一定范围事件包含的各词语要素之间构成的相互（包含：**原材料、工艺、功能、属性、时序、因果、方式目的**等多重）对应。
	1. 原材料、工艺、成品
		> 例：黄桃：罐头、玉石：打磨：手镯
	2. 功能
		> 例：手机：点餐、汽车：运输
	3. 属性
		> 例：酒精：挥发性、山楂：酸
	4. 时序
		> 例：起飞：着陆、考试：阅卷
	5. 因果
		> 例：淋雨：感冒、信息泄露：财产损失
	6. 方式目的
		> 例：扶贫：脱贫、贴窗花：迎新年
### 语法关系
> 语法关系：**主谓、动宾、主宾、偏正**关系
- 主谓关系
	+ 词语间一个（主语）名词在句前、一个（谓语）动词在句后
		> 例：学生：练习
- 动宾关系
	+ 词语间一个动词在句前、一个（宾语）名词在句后
		> 例：消除：矛盾
- 主宾关系
	+ 词语间两个都是名词（分别为对应主语和客语），通过一个动词连接造句
		> 例：士兵：敌情
		>> 学徒：技术（学徒**学习**技术） 学生：知识（学生**学习**知识）
- 偏正关系
	> 由“的 / 地”连接。
	+ 词语间一个是修饰词、一个是被修饰词，常由“的 / 地”连接。
		> 例：勤劳：工人、激烈：竞争
	+ 结构
		1. 形容词 + 名词
			> 例：美丽：人
		2. 副词 + 名词
			> 例：快速：走

## 四、逻辑判断
> 七类题型：**翻译推理、削弱题型、加强题型、组合排列**、真假推理、原因解释、日常结论。
### 1、翻译推理
- 题型特征
	+ “可以 / 无法推出”
#### 常规翻译	
- 翻译规则
	1. 前 -> 后（关联词）
		+ **如果 / 假如 / 一旦 / 若...，那么 / 就...**
		+ **只要...，就...**
			> 例：只要功夫深、铁杵磨成针 => 功夫深 -> 铁杵磨成针
		+ **所有 / 凡是 / 任何 / 每个...，都...**
			> 例：凡是有生活的地方就会有幸福。=> 生活 -> 幸福
		+ **...是...的充分条件**
		+ **...就 / 则 / 都 / 一定...**
			> 例：有付出就会有回报 => 付出 -> 回报
	2. 后 -> 前
		+ **只有...，才...**
			> 例：只有认真学习，才会有好的成绩。=> 好成绩 <- 认真学习
		+ **不...，不...**
			> 例：不到长城非好汉 => 好汉 -> 到长城
		+ **...才...**
		+ **除非...，否则不...**
			> 例：除非认识错误，否则不能改正错误 => 改正错误 -> 认识错误
		+ **...是...的必要条件 / 先决条件 / 基础 / 前提 / 必不可少的条件**
			> 例：良法是善治之前提。=> 善治 -> 良法
- 推理规则
	1. 逆否等价
		> **肯前必肯后，否后必否前**。**否前、肯后**不必然
		+ ① -> ② => -② -> -①
			> 例：北京人一定是中国人 （=> 北京人 —> 中国人）以下哪句成立？
			>> [ × ] 中国人一定都是北京人（=> 中国人 -> 北京人）
			>> [ × ] 不是北京人一定不是中国人（=> -北京人 -> -中国人）
			>> [ ✓ ] 不是中国人一定不是北京人	（=> -中国人 -> -北京人）
	2. 传递规则
		+ ① -> ②，② -> ③  => ① -> ③
		> 例：凡是北京人都是中国人，只要是中国人就有身份证
		>> 北京人 -> 中国人，中国人 -> 有身份证 => 北京人 -> 有身份证
- 翻译注意点 
	1. 必要条件：**谁必不可少，谁在箭头后**
	2. 除非...否则...：**否后推前**
		> ..., 除非... = 除非...否则...
		>> 例：航班延误 4 个小时需要赔付给乘客，除非有不可抗力的因素出现
		>> => 除非有不可抗力的因素出现，否则航班延误 4 个小时需要赔付给乘客
		>> -延误 4 个小时需要赔付给乘客 -> 有不可抗力的因素出现
		* 除非...否则不...：**后推前**
- 且、或关系
	+ 且关系：表示由“和”连接的所有对象**均成立**（都必为真）
		* 关联词
			1. 并列关系：**并且 / 且 / 和 / 都 / 既...又...**
			2. 递进关系：**甚至 / 而且 / 还...**
			3. 转折关系：**但是 / 然而 / 却...**
			4. 标点：**“,逗号”、“、顿号”、“; 分号”**
		* 推理规则： **① 且 ②** -> ①，① 且 ② -> ②
			> 小明聪明且有耐心 => 小明聪明, 小明聪明且有耐心=> 小明有耐心
	+ 或关系：表示由“或”连接的所有对象**至少有一个成立**（必有一个真）
		* 关联词
			1. **...或（者）...**
			2. **或者...或者...**
			3. **...和...至少有一个**
		* 推理规则：
			1. 否一推一：当 **① 或 ②** 成立时 => -① => ②，-② => ① 
			2. ① 和 ② **至多有一个** => -① 或 -②
			3. 二选一：**要么...①，要么...②** => -① => ②，-② => ①，① => -②，② => -①
			4. 德·摩根定理：
				> 1. -（① 且 ②）= -① 或 -②
				> 2. -（① 或 ②）= -① 且 -② 
	### 2、集合翻译
	#### “所有 / 全部” 
	- 翻译规则：前推后
	- 关键词
		+ **所有 / 全部 / 任何 / 凡是**
		+ **...都...**
	- 推理规则：逆否等价
		> 例：所有 ① 都是 ②  =>  ① -> ②
		> 例：所有 ① 都不是 ②  =>  ① -> -②
#### “有的”
- 表示至少有一个
	> 3种可能性：1、只一个满足 2、有一部分满足 3、全部满足
	>> “中国有的人很勤奋” => 1、中国只有一个人很勤奋 2、中国有一部分人很勤奋 3、中国全部的人都是很勤奋
- 关键词
	+ **有 / 有些 / 一些 / 某些**
	+ **有一些...**
- 翻译规则
	1. 有的 ① 是 ② => ① -> ②
	2. 有的 ① 不是 ② => ① -> -②
- 推理规则
	1. 不适逆否：”有的“ 不适用 逆否等价
	2. 可交换：有的① 是 ② = 有的② 是 ①
		> 例：有的马是动物，有的动物是马
	3. 所有的 ① 都是 ② => 有的 ① 是 ② 或 有的 ② 是 ①
		> 所有的马是动物，有的马是动物，有的动物是马

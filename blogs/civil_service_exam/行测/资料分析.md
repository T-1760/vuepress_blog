## 资料分析
### 年均增长率
- 二项式
    + \[r = \frac{\frac{现}{基} -  1}{n}\]
- [万能公式 （r < 10% ）](https://www.bilibili.com/video/BV14VrBBpE5A/)
    + \[r = \frac{\frac{现}{基} -  \frac{基}{现}}{2n}\]

### 一、统计术语
#### 1.1、基期 & 现期
  - 基期：相对于今年来说，去年的就是基期
  - 现期：相对于去年来说，今年的就是现期
#### 1.2、基期量 & 现期量
  - 基期量：相对于今年来说，去年的量就是基期量
  - 现期量：相对于去年来说，今年的量就是基期量
#### 1.4、增长量 & 增长率
  - 增长量：现期量和基期量的差值，就是增长量
  - 增长率：增长量与基期量的比值，就是增长率
#### 1.5、倍数 & 比重 & 平均数
  - 倍数：A 是 B 的多少倍：A 为 B 的多少倍，等于增长率加 1
    + 辨析：A 比 B 增长了 500%，那么就是 A 比 B 增长（多）5 倍, A 是 B 的 6 倍
  - 比重：
    + A 占 B 的比重，A 占 B 为多少；都等于 A/B 
    + A 占 B 的比重比 C 的比重为：A/B - C/B
  - 平均数：在一组数据中所有数据之和再除以数据的个数
#### 1.6、同比 & 环比
  - 同比：同比看年，今年与去年同期比
  - 环比：环比看尾，“年”“月”“日”等
#### 1.7、顺差 & 逆差
  - 顺差：也称出超，出口大于进口
  - 逆差：也称入超，出口小于进口
#### 1.8、百分数 & 百分点
  - 百分数：用 % 表示
  - 百分点：用数来表示，是两个百分数的变化，用减法计算
#### 1.9、其他
  - 成数：两成，即 20 %
  - 翻番：翻一番是 2 倍，翻两番是 4 倍，翻 n 番是 2n 倍
  - GDP:一国所有常住单位一定期内生产的全部最终产品和服务价值总和

### 二、基期（量） & 现期（量）
#### 2.1、基期  
- 基期 = **现期 - 增长量** = **$\frac{现期}{1 + r_{增长率}}$** = **$\frac{增长量}{r_{增长率}}$** 
  > 当 | r | ≤ 5% 时
  >> **$\frac{A_{现期}}{1 + r_{增长率}}$ => $A_{现期} × (1 - r_{增长率})$**
  >> **$\frac{A_{现期}}{1 - r_{增长率}}$ => $A_{现期} × (1 + r_{增长率})$**
- 基期和差 = **$\frac{A_现}{1 + a_{增长率}} ± \frac{B_现}{1 + b_{增长率}}$**
  > 题型特征: 
  >> “过去（基期）A 与 B 的和 / 差”
  >> “去年 A 比 B (多/少) 多少”
  >> “某年 A 和 B 共多少（基期）”
  + 例1.小帅今年收入 120 万（r=10%），小美今年收入 80 万（r=-15%），
    * 求去年小帅比小美高多少？
    * A.15 万 B.40 万C.53 万 D.63 万
    > 现期差：120-80=40万（选项 B 是现期陷阱，排除）。
    > 基期分析：小帅基期收入=1+10%120 =120-（变小），小美基期收入=1-15%80 =80+（变大），因此基期差 = 120 - -80 + < 40，选 A。
  + 例2：2022 年公路投资 28527 亿元（r=9.7%），水路投资 1679 亿元（r=10.9%）。
    * 请问 2021 年公路交通固定资产投资 额与水路交通固定资产投资额共：
    * A.不到 2 万亿元　　B.2～3 万亿元　　C.3～4 万亿元　　D.超过 4 万亿元
  > 步骤 1：算现期和：28527 + 1679 = 30206亿元（现期和为 “3 万多”，选项 C 是现期陷阱，排除）。
  > 步骤 2：分析基期和的变化：基期和公式：28527/（1+9.7% ）+1679 /（1+10.9%）。
  >> 因增长率 r > 0，基期量=现期/（1+r）＜现期，即基期 ＜ 现期和（3 万多），但不会小到 “2 万亿以下”（1+9.7%≈1.1，1+10.9%≈1.1，30206÷1.1≈27460亿元，仍在 “2～3 万亿元” 区间，则选 B）。
- 间隔基期 = **$\frac{现期}{1 + r_{间隔增长率}}$**
#### 2.2、现期
- 现期 = **基期 + $n_{年份差}$ × 增长量** = **基期 × $(1 + r_{增长率})^{n_{年份差}}$**
  > n = 1 可忽略，现期 = **基期 + 增长量** = **基期 × (1 + $r_{增长率}$)**
- 间隔现期 = **基期 × (1 + $r_{间隔增长率}$)**
- ❓现期追赶问题
  1. 小追大，能追上；**问几年**，找差距，补差距。
  2. 大追小，追不上；**问差距，N年差距 = 现在差距 + N × 增长量差距**

### 三、增长量 & 增长率
  - 增长量：**现期**（即：现在） 比 **基期**（即：过去） 变化了**多少**（具体量携单位）
  - 增长率：**现期**（即：现在） 比 **基期**（即：过去） 变化了**百分之多少**（%）
#### 3.1、增长量
- 一般增长量 = **现期 - 基期** = **基期 × $r_{增长率}$** = **$\frac{现期}{1 + r_{增长率}} × r_{增长率}$**
  > 1. 当 **r ＜ 0** 时（减少量估算），**$\frac{现期}{1 + r_{增长率}} × r_{增长率}$** => **$\frac{现期}{\frac{1}{r_{增长率}} - 1}$**
  > 2. 当 **r ＞ 0** 时（增加量估算），**$\frac{现期}{1 + r_{增长率}} × r_{增长率}$** => **$\frac{现期}{\frac{1}{r_{增长率}} + 1}$**
  > 3. 当 **| r | ≤ 5%** 时（可估算），**基期 × $r_{增长率}$** => **现期 × $r_{增长率}$**
- 年均增长量 = **$\frac{现期 - 基期}{n_{年份差}}$**
  > 2020年~2025年, 则 $n_{年份差}$ = 5年
- 增长量比较大小（口诀：**大大则大**；**一大一小比倍数**）
  + 大大则大: 当现期大且增长率大，则增长量也大;
  + 一大一小看乘积或倍数：一般可以直接比较**现期 × 增长率**的大小; 或者比较二者之间**现期倍数与增长率倍数**大小（以“倍数大”为准）。
    > 当现期1 > 现期2; 增长率1 < 增长率2
    >>看乘积: 现期1 × 增长率1 **＞或＜**现期2 × 增长率 2，则增长量1 **＞或＜**增长量2;
    >>看倍数: 现期1 / 现期2 **＞或＜**增长率2 / 增长率 1，则增长量1 **＞或＜**增长量2;
    > 当现期、增长率的乘积或倍数比较接近时，由于忽略了分母上的(1+增长率)，当各选项增长率之间差距较大（如：20个百分点）时，可能出现误差，需具体验算下

#### 3.2、增长率（增速）
> 给了百分点：**高减低加**。例：今年10% 比去年增加了5%，则去年 = 10% - 5% = 5%

- 一般增长率 = **$\frac{增长量}{基期}$** = **$\frac{增长量}{现期 - 增长量}$** = **$\frac{现期 - 基期}{基期}$** = **$\frac{现期}{基期} - 1$**
  + 常不求具体值，只作比较增长率的大小（**可简化比较：$\frac{现期}{基期}$** )
    1. 当 **$\frac{现期}{基期} ≥ 2^+$明显**，可简化比较：$\frac{现期}{基期}$
    2. 当 **$\frac{现期}{基期} = 1^+$不明显**，则具体比较：$\frac{增长量}{基期}$

- 年均增长率 r
  + 公式：**$(1 + r_{年均增长率})^{n_{年份差}}$ = $\frac{现期}{基期}$**
    * $r_{年均增长率}$ = **$\sqrt[n_{年份差}]{\frac{现期}{基期}}$ - 1**
      1. 当 **r ≤ 10%**，估算：$ r_{年均增长率} ≤ \frac{r_总}{n_{年份差}}$
      2. 当 **r > 10%**，计算：$(1 + r_{年均增长率})^{n_{年份差}}$ = $\frac{现期}{基期}$
  + 比较大小：**可简化比较：$\frac{现期}{基期}$ 或 $\frac{增长量}{基期}$**
- 间隔增长率（隔年增长率）
    + $r_{间隔增长率}$ = **$r_1 + r_2 + r_1 × r_2$**
      + $r_2$ = **$\frac{r_{间隔增长率} - r_1}{1 + r_1}$**
      > 2019 年某产品产量为 120，2020 年同比增长了 20%，2021 年同比增长了 30%，请问 2021 年相比 2019 年增长了多少?
      > + 解法一：常规解法，
      >> 2020 年产量 = 120 × 1.2 = 144; 2021 年产量 = 144 × 1.3 = 187.2；
      >> 21 年相比 19 年增长了：（187.2 - 120）/ 120 = 56%
      > + 解法二：间隔增长率 = r1 + r2 + r1 × r2 = 20% + 30% + 20% * 30% = 56%，
    + **间隔基期 = $\frac{现期}{1 + r_{间隔增长率}}$**
    + **间隔现期 = 基期 × (1 + $r_{间隔增长率}$)**

- 乘积增长率
> 题型识别: 一个量由两个量相乘得到的增长率，即：已知 A = B × C，求 A 的增长率
>> ”总价（= 单价 × 数量）的增长率是多少？“
>> ”GDP（= 人均 GDP× 人口）的增长率是多少？”
  + 形式：**$A_量 = B × C$**
    > 1. 部分 = 份数 × 整体
    > 2. 总价 = 单价 × 数量
    > 3. 产量 = 单产 × 面积
  + **$r_A = r_B + r_C + r_B × r_C$** 
    > 实质与间隔增长率：r1+r2+r1×r2 是一样的（两者相加，再加两者乘积）
    > ![乘积增长率](https://cdn.jsdelivr.net/gh/T-1760/blog_picture/kao_gong/kao_dian/xing_ce/20260307195507387.png)
- 混合增长率
> 题型：
>> 1. 已知部分增长率，求整体增长率。
>> 2. 已知整体与某部分增长率，求另一部分增长率。
  + 形式：整体 = 部分1 + 部分2
    > 1. 进口 + 出口 = 进出口
    > 1. 城镇 + 农村 = 全国
    * $r_1 < r_混 <  r_2$ （口诀：**混合居中不正中，偏向基数较大的一方**，常用*现期*近似替代*基期*计算）
    * 线段法：**距离与量成反比**
      > 量：常用现期，但**当 |r| ≥ 20% 时，必用基期**
  + ![资料分析-十字交叉法](https://cdn.jsdelivr.net/gh/T-1760/blog_picture/kao_gong/kao_dian/xing_ce/20260307191253876.png)
    > 1. 例: 2019年1至6月，全国发行地方政府债券 28372 亿元，同比增长 101.09%。其中，发行一般债券 12858亿元，同比增长 23.21%，发行专项债券 15514亿元，同比增长 322.38%。  
    > 请问 2018年1至6月，发行一般债券的占比较发行专项债券的占比约：
    >  A.低 9.36%　　B.低 52.81%　　C.高 47.93%　　D.高53.43%
    >> 解：可得2018年发行一般债券 与 专项债券之比 =（322-101）∶（101-23）= 221∶78;
    >>（221-78）÷（221+78）=143/299，略小于50%，则选 C
    > 2. 例：2020年上半年，我国农产品进出口总额达 1159.0亿美元。农产品进口额为 807.5亿美元，同比增长13.2%。受新冠肺炎疫情影响，我国农产品出口额同比下降3.8%，为 351.5亿元。
    > 请问：2020年上半年，我国农产品进出口额同比增长约：
    > A．2.5%　　B．5.0%　　C．7.5%　　D．10.0%
    >> 假设进出口额同比增长 R
    >> 十字交叉：(13.2% - R) : (R - (-3.2%)) ≈ 807.5 : 351.5 ≈ 2 ：1 则 R ≈ 8%,则选 C
- 累计增长率
  + 口诀：**只要累计不滑坡，当月就比累计多**

### 四、平均数类公式
- 平均数 = $\frac{总数}{总份数}$
#### 4.1、现期平均数 & 基期平均数
- 现期平均数 = $\frac{a_1 + a_2 + ··· + a_B}{B}$ = $\frac{A_{现期总量}}{B_{现期总份数}}$
- 基期平均数 = $\frac{基期总量}{基期总份数}$ = $\frac{A_{现期总量}}{B_{现期总份数}} × \frac{1 + b_{总份数增长率}}{1 + a_{总量增长率}}$
#### 4.3、平均数增长量
> 题型识别为：“两个时间 + 平均数 + 增加/减少具体量(上升/下降多少个百分点)”
- 平均数增长量 = 现期平均数 - 基期平均数 = $\frac{A_{现期总量}}{B_{现期总份数}}$ ×  $\frac{a_{总量增长率} - b_{总份数增长率} }{1 + a_{总量增长率} }$（公式单位：具体量）
    > **两期平均数比较**
    + 当 **a > b** 时，现期平均数 > 基期平均数（即：**上升**）
    + 当 **a = b** 时，现期平均数 = 基期平均数（即：**不变**）
    + 当 **a < b** 时，现期平均数 < 基期平均数（即：**下降**）
#### 4.4、平均数增长率⚠️
> 题型识别为：“两个时间 + 平均数 + 增加/减少 + 百分数”
- $r_{平均数增长率}$ = **$\frac{现期平均数 - 基期平均数}{基期平均数}$** = **$\frac{a_{总量增长率} - b_{总份数增长率}}{1 + b_{总份数增长率}}$**
  > ⚠️注意： **$\frac{a - b}{1 + b}$** （该公式是资析唯一分母有 b 的）公式中的分母是 **1 + b**，
- 间隔平均数增长率
  > 先间隔，再平均
  + $r_{间隔平均数增长率}$ = **$\frac{间隔现期平均数 - 间隔基期平均数}{间隔基期平均数}$** = **$\frac{a_{间隔总量增长率} - b_{间隔总份数增长率}}{1 + b_{间隔总份数增长率}}$**

### 五、比重类公式
- 比重 = $\frac{部分（分量）}{整体（总量）}$
  > 利润率：资料分析和数量关系公式分母不同
  >> 资料分析：$\frac{利润}{收入}$
  >> 数量关系：$\frac{利润}{成本}$
- 产销比 = $\frac{销量（后上）}{产量（前下）}$
- 增长贡献率 = $\frac{部分增长量}{整体增长量}$
#### 5.1、现期比重 & 基期比重
- 现期比重 = $\frac{A_{现期分量}}{B_{现期总量}}$
- 基期比重 = $\frac{基期分量}{基期总量}$ = $\frac{A_{现期分量}}{B_{现期总量}}$ ×  $\frac{1 + b_{总量增长率}}{1 + a_{分量增长率}}$

#### 5.2、两期比重差
- 两期比重差 = 现期比重 - 基期比重 =  $\frac{A_{现期分量}}{B_{现期总量}}$ × $\frac{a_{分量增长率} - b_{总量增长率}}{1 + a_{分量增长率}}$（公式单位：百分点）＜ | a - b |
  > 其值判正负：选比 |a - b| 绝对值小的
  + **a > b**，比重**上升**（现期比重 > 基期比重）
  + **a < b**，比重**下降**（现期比重 < 基期比重）
  + **a = b**，比重**持平**（现期比重 = 基期比重）

### 六、倍数和翻番类公式
- A 是 B 的多少倍？=> $\frac{A}{B}$
- A 比 B 多多少倍？=> $\frac{A}{B} - 1$
#### 6.1、现期倍数 & 基期倍数
- 现期倍数 = $\frac{A_{现期量}}{B_{现期量}}$
- 基期倍数 = $\frac{A_{基期量}}{B_{基期量}}$ = $\frac{\frac{A_{基期量}}{1 + a_{增长率}}}{\frac{B_{基期量}}{1 - b_{增长率}}}$  = $\frac{A_{基期量}}{B_{基期量}}$ × $\frac{a_{增长率} - b_{增长率}}{1 + a_{增长率}}$

#### 6.2、翻番
- 翻 N 番 =  $2^N$

  >> 平方根 $\sqrt[2]{51} = 7 + \frac{51-7^2}{2×7}$ = 7 + $\frac{2}{14}$ ≈ 7.14
  >> 立方根 $\sqrt[3]{29} = 3 + \frac{29-3^3}{3×3^2}$ = 3 + $\frac{2}{27}$ ≈ 3.072
  >> 立方根 $\sqrt[3]{57} = 4 + \frac{57-4^3}{3×4^2}$ = 4 - $\frac{7}{48}$ ≈ 3.848

## 技巧策略
### [放缩估算法](http://baike.baidu.com/item/%E6%94%BE%E7%BC%A9%E4%BC%B0%E7%AE%97%E6%B3%95/597246)
> 放缩估算法是资料分析中常用的速算技巧，通过&zwnj;**放大或缩小数值**&zwnj;简化计算，核心是保证估算精度满足需求。以下是不同场景下的典型运用：  
- 一、放缩估算法与直除法结合  
  + 在分数计算中，常通过&zwnj;**放缩分母（或分子）**&zwnj;简化除法运算，利用直除法快速得出结果。  
  + &zwnj;**示例**&zwnj;：计算 $30738 \div 1929$  
    > 由于 $1929$ 靠近 $2000$，将分母&zwnj;**放大**&zwnj;为 $2000$，即 $30738 \div 1929 \approx 30738 \div 2000$。  
    > 直除法计算 $30738 \div 2000$，可快速估算结果约为 $15$。  

- 二、放缩估算法与左移两位估算法结合  
  + 当计算“某数占总数的比例”（求量是 X %）时，通过&zwnj;**取除数的1%**&zwnj;简化除法，再结合“省略小数点后数字”的放缩，实现快速估算。  
  + &zwnj;**示例**&zwnj;：求 $675.8$ 占 $33211$ 的比例（即 $675.8 \div 33211$）  
    > 1、取 $33211$ 的 $1\% = 332.11$，用 $332.11$ 代替 $33211$ 计算。  
    > 2、进一步将 $332.11$&zwnj;**缩小**&zwnj;为 $332$（省略小数点后数字），则 $675.8 \div 332.11 \approx 675.8 \div 332$。  
    > 3、直除法计算 $675.8 \div 332 = 2.035 \approx 2 $，结果即为所求比例的百分数部分（结果就是 X %里面的 X）。  
- 三、加法的放缩估算法  
  + 通过&zwnj;**放大或缩小加数**&zwnj;，快速确定和的范围，常用于“估算和的上下界”。  
  + &zwnj;**加数放大**&zwnj;：将每个加数&zwnj;**放大**&zwnj;后求和，和的值会&zwnj;**大于原和**&zwnj;，用于确定“和的上限”。  
    > 示例：$8054 + 5992 + 1555 + 905$  
    >> 放大后：$9000 + 6000 + 2000 + 1000 = 18000$  
    >> 结论：原和 $< 18000$。  
  + &zwnj;**加数缩小**&zwnj;：将每个加数&zwnj;**缩小**&zwnj;后求和，和的值会&zwnj;**小于原和**&zwnj;，用于确定“和的下限”。  
    > 示例：$8054 + 5992 + 1555 + 905$  
    >> 缩小后：$8000 + 6000 + 1500 + 900 = 16400$  
    >> 结论：原和 $> 16400$。  
- 放缩估算法的核心是&zwnj;**在精度允许范围内简化计算**&zwnj;，需根据题目选项差异、数据特性灵活选择放缩方向（放大/缩小）与程度，平衡“计算效率”与“估算精度”。  


## 速算
> 估算尽量 1% 误差
### 拆分法
> 适用于：乘除法。
>> 1. 乘法拆分‌：如 17.8% = 20% − 2% − 0.2%，分别计算再相减。
>> 2. 除法拆分‌：如分子接近分母一半时，先拆出 50% 再处理余下部分‌
- $\frac{47568}{89874}$ =
  + A、54.9%   B、56.5%   C、52.9%   D、51.2% 
  > 解题：
  >> 1. 分子分母只取前三位，即 475/898，
  >> 2. 寻找分子分母差距，475 比 898 的一半 448 多 26，
  >> 3. (448+26)/898 => 1/2 + 26/898 => 26/900 ≈ 2.9，选 C。

### 化除为乘（加减互变）
> 适用于：间隔增长率。**前提| 增长率 | ≤ 5 % 时，才能使用近似‌**
>> 1. 基期量（r ≤ 5%）‌≈ 现期/(1+r) = **现期×(1−r)**
>> 2. $r_{间隔增长率}$ = **$r_1 + r_2 + r_1 × r_2$**
- $\frac{1.31}{1+0.8\%}$ =   
  + A、1.09   B、1.15  C、1.26    D、1.30
  > 解题
  >> 1. 0.8% < 5%，1.31/(1+0.8%) => 1.31×(1-0.8%) = 1.3025
  >> 1.31 × 接近 1的数 ≈ 1.31，故此选 D   
### 倍数修正
> **分母接近整（十、百、千）**，分子分母同比例加减修正
- $\frac{5017.47}{1+6.2\%}$ =
  + A、4724   B、4745  C、4787    D、4862
  > 解题
  >> 1. 观选项很接近，分子保留三位，502/106, 分母 106 - 6 = 100。 
  >> 2. 分母 106 中 个位 6 是 百位 1 的 6 倍。则分子 502 也需要减去 百位 5 的 6 倍数。502 - (5×6) = 472。
  >> 3. (502 - 30)/(106 - 6) = 472/100 ≈ 4.72 => 472 开头选项，选 A。
### 415 份数法
> 适用于：百分数（复杂百分数 转为 简单分数）出现在乘除式。
>> 名称“415”源于增长率25%（1/4）时三者份数恰为 4（基份）、1（增份）、5（现份），但实际比例随增长率变化。
- 该方法将 $r_{增长率}$ 转换为相近分数 a/b
  + 从而建立基期（A）、变化量（X）、现期（B）的份数比例：
  + 基期为 b 份，变化量为 a 份，现期为 b+a 份。
- $\frac{1442}{1-9.1\%}$ =
  + A、1543   B、1586   C、1657  D、1682
  > 解题
  >> 1. -9.1% = -1/11 => 11（基份）、-1（增份） => 10(现份) 
  >> 2. 基期 = 现期/(1+r)，现期为 1442（占 10 份），则 1 份 = 144.2，基期比现期多一份 = 1442 + 144.2 = 1586，选 B
### 其他
#### 估算法
> 适用场景‌：选项差距较大或待比较数据差异明显时。
‌- 关键点‌：估算精度取决于选项间距（差距越大，估算越粗略‌）
#### 直除法
> 适用场景‌：除法计算（如比重、增长率），尤当**选项首位不同**时。
- 操作方式‌：直接相除，只需计算出 **‌商的首位或前两位**‌ 即可匹配选项。
#### 截位法
> 适用场景‌：加减乘除 中**数据位数多的复杂计算**时。
- 原则
  + 加减法‌：从高位开始截取，注意进位/借位。
  + 乘除法‌：根据选项精度决定截取位数
    1. 首位不同截 2 位，
    2. 前两位相同则需精确计算
#### 首/尾数法
> 适用场景‌：多个数加减，且选项‌**尾数或首数各不相同‌**。‌
- 操作‌：直接计算选项尾数（或首数）。即可快速锁定答案，无需完整计算‌

### 案例
- 1.068 × 0.267‌
- 方法一：忽略小数点，整数相乘后补小数‌
  > 适合笔算或心算能力强时使用
  + 忽略小数点：1068 × 267
  + 先估算：1000 × 267 = 267,000；68 × 267 ≈ 70 × 267 = 18,690 → 减去 2×267≈534 → ≈18,156
  + 总和 ≈ 267,000 + 18,156 = ‌285,156‌
  + 原数共有 ‌6 位小数‌（1.068 有 3 位，0.267 有 3 位），所以结果为 ‌0.285156‌
- 方法二：相近计算
  + 1.06 × 0.27 = ‌0.2862‌（保留四位小数）‌
  + 1.068 比 1.06 多 0.008，0.267 比 0.27 少 0.003
  + 可粗略估计：增加 0.008×0.27≈0.00216，减少 1.06×0.003≈0.00318 → 净减约 0.001
  + 得 ≈ 0.2862 - 0.001 = ‌0.2852‌，与精确值一致

- 1.068 × 1.869‌
- 方法一：近似为整数 + 调整小数位‌
  + 将 1.068 ≈ ‌1.07‌，1.869 ≈ ‌1.87‌
  + 先计算 ‌1.07 × 1.87‌
  + 拆解：1.07 × (1.8 + 0.07) = 1.07×1.8 + 1.07×0.07
    * 1.07×1.8 = (1 + 0.07)×1.8 = 1.8 + 0.126 = ‌1.926‌
    * 1.07×0.07 = ‌0.0749‌
    * 合计 ≈ ‌1.926 + 0.0749 = 2.0009 ≈ 2.00‌
  + 原式因略小于近似值，最终结果约为 ‌1.998～2.00‌
- ‌方法二：利用乘法分配律拆分‌
  + 1.068 × 1.869 = 1.068 × (1 + 0.8 + 0.06 + 0.009)
  + = 1.068×1 + 1.068×0.8 + 1.068×0.06 + 1.068×0.009
  + = 1.068 + 0.8544 + 0.06408 + 0.009612
  + 逐步相加：
    * 1.068 + 0.8544 = ‌1.9224‌
    * 0.06408 = ‌1.98648‌
    * 0.009612 ≈ ‌1.996092‌
  + 结果 ≈ ‌1.996‌
- ‌方法三：直接竖式估算（推荐用于考试）‌
  + 忽略小数点，计算 ‌1068 × 1869‌
    * 但此法较繁，适合用计算器；若手算，可先估算数量级：
    * 1.068 ≈ 1.07，1.869 ≈ 1.87，乘积 ≈ ‌2.00‌（如方法一）
  + 小数位共 ‌3 + 3 = 6 位‌，故结果为 ‌1.996 左右

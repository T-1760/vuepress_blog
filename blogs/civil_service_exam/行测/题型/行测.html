Tang_1997 2024/10/27 Administrative Aptitude Test行政能力测试题型

# 题型

# 一、判断推理

  • 考点（6 种）：位置规律、样式规律、属性规律、特殊规律、数量规律、空间重构
  • 快速定位某个考点：识别图形特征

# 1.1、图形推理

  • 1、位置类（特征：元素构成相同）
    1. 平移
      • 方向：直线（上下、左右、斜对角），曲线（顺时针、逆时针）
      • 步数：常量、变量（递增、减）
      • 宫格型黑块
        1. 个别黑块可重合（题干和选项大部分元素组成相同，个别图少 1 个黑块）
        2. 16 宫格，中间块数量相同，考虑区分内外层
        3. 走直线：中间黑块数量不同，考虑上下左右（循环、反弹）平移。
    2. 旋转、翻转（水平、垂直）
      • 方向：顺时针、逆时针
      • 角度： 30°、45°、90°、180°
  • 2、样式类（特征：元素组成相似）
    1. 加减同异
      • 特征：相同线条重复出现

    2. 黑白运算
      • 特征：图形轮廓和分割区域相同，内部颜色不同
      • 区分：黑块数量相同（优先：位置类-平移）、黑块数量不同（优先：样式类-黑白运算）

      • 先样式还是位置？
  • 3、属性规律（特征：元素组成不同，不相似）
    1. 对称性
      • 对称类型
        1. 轴对称：“等腰”元素
        2. 中心对称：180°自转还原（例：N、Z、S变形图、平行四边形、相同元素反着放）
        3. 轴 + 中心对称：存在相互垂直的对称轴
      • 对称轴数量和方向
        • 对称轴数量题目特征：三足鼎立（等边三角形）
      • 图形的对称轴与自身点、线、面的关系
      • 2-3 个面挨在一起，分开看对称轴关系
    2. 曲直性
      • 特征：出现明显的圆、弧等曲线图

      • 全直线
      • 全曲线
      • 曲线 + 直线
    3. 开闭性
      • 特征：出现生活化或粗线条图形

      • 全封闭
      • 全开放
      • 半开半闭
  • 4、特殊规律
    1. 图形间关系
      • 特征：多个封闭图形连在一起
      • 相离
      • 相交
      • 2+个面相连，优先看对称，再看公共边

    2. 功能元素
      • 特征：出现黑点、白点、剪头等小元素

      • 点: 直直、曲曲、曲直交点
      • 线: 直线/曲线、最长线/最短线
      • 角: 锐角/直角/钝角、最大角/最小角
      • 面: 单独面/相交面、最大面/最大面、形状、属性（对称、曲直）
  • 5、数量规律
    • 特征
      1. 元素组成不同，且无属性（对称、曲直、开闭）规律
      2. 数量特征明显

    • 点
      • 点数量特征：线条交叉明显（树杈），相切（点）较多，曲直线交点
    • 线
      • 直线特征图：多边形、单一直线
      • 曲线特征图：曲线图形（圆、弧、单一曲线）
      • 笔画数【重点】：端点也是奇点

        1. 一笔画（奇点数量为：0 或 2）；
        2. 多笔画（= 奇点数 / 2；奇点数量一定是偶数）
        3. 笔画数常见特征图：日（变形图）、星、田（变形图）、圆（相交/想切）、（多）端点。

    • 角
      • 角数量
        1. 直接特征图：十字交叉、T形、直角三角形、直角（故意规避）改造图
        2. 锐角特征图：折线、扇形、锐角（故意规避）改造图
    • 面【重点】
      • 面数量：白色的封闭区域

      • 数面：1、图形被分割、封闭面明显；2、生活化图形、粗线条图形

      • 面的细化考法：

        1. 所有面的形状
        2. 相同的面数量（“双胞胎”、“多胞胎”）
        3. 最大面/最小面的形状、属性（对称、曲直）、与外框的关系
    • 素
      • 特征：多个独立小图形
      • 素数量
        1. 优先考虑元素种类和数量（分类：颜色不同，一般认为是两种；大小不同，一般为一种）
        2. 选不出唯一答案，考虑找相同
      • 部分数
        1. 连在一起就是一部分
        2. 生活化、粗线条图形

  • 6、空间重构（解题技巧：所有方法都是排除错误选项的）
    • 方法一：相对面

      1. 同行或同列间隔一个面
      2. Z字形两端（紧邻 Z 字中线的面）
    • 方法二：

      • 相邻面——公共边
        1. 平面图中构成直角的两条边是同一条边

        2. 一列/行连着 4 个面,两头的两条边是同一条边

      • 相邻面（折叠前后相邻关系不变）
        1. 相对位置法（图形指向性明显）

        2. 公共点（相邻三个面的公共点是唯一的）

        3. 画边法

# 1.2、类比推理

  • 1.2.1、语义关系
    • 近义关系、反义关系
      1. 常见易错成语积累
      2. 有限看简单、熟悉的
      3. 不熟悉则“字面意思”猜
      4. 遇到难题，只看一个词想其近义/反义
      • 进行二级辨析：感情色彩：褒义、贬义、中性（若一级关系（近反义关系）无法选出唯一答案）

    • 比喻象征义
      1. 月亮：玉盘
      2. 松鹤：长寿
  • 1.2.2、逻辑关系
    • 全同关系

      1. 老鼠：耗子
      2. 西红柿：番茄
    • 并列关系

      1. 矛盾关系（没有第三种情况）

        例：对称：非对称。生：死。阴：阳。男：女。白天：黑夜；

      2. 反对关系（有第三种情况）

        例：红色：白色。亲情：友情。夏装：冬装。

    • 包容关系

      1. 种属关系： A 是 B 的一种

        例：白菜：蔬菜 （能独立用“是”造句子的即种属关系，白菜是蔬菜）

      2. 组成关系：A 是 B的一个组成部分

        例：镜片：眼镜

    • 交叉关系

      • 特征：从不同角度描述同一类实物
      • 技巧：（4种情况是均需成立）
        1. 有的 A 是 B，有的 A 不是 B
        2. 有的 B 是 A，有的 B 不是 A
    • 对应关系

      1. 原材料和工艺（工艺常考二级辨析：物理、化学）

        例：葡萄：酿造：葡萄酒

        • 工艺二级辨析（区分标准：有无新物质生成）
          1. 物理变化工艺：印刷、捆扎、打磨、雕琢、剪裁、织造等
          2. 化学变化工艺：燃烧、氧化、发酵、酿造、冶炼等
      2. 功能（一般为名词 + 动词；常考二级辨析：主要、次要功能）

        例：灯：照明：装饰

      3. 属性（一般为名词 + 形容词；常考二级辨析：必然、或然属性）

        例：盐：咸； 花：红

      4. 时间顺序（一般为动词 + 动词；常考二级辨析：主题能否一致，（肇事者）违章：（交警）罚款）

        例：恋爱：结婚：生子

      5. 因果关系（常考二级辨析：原因自然/人工、结果消极/积极）

        例：炎热：中暑； 努力：成功

        • 因果区分时间顺序可用“导致”造句
  • 1.2.3、语法关系
    • 技巧：造句子
      1. 主谓关系

        例：我：喜欢

      2. 动宾关系

        例：喜欢：你

        • 动词与动宾区分

          例：唱歌（动宾）、歌唱（动词）

      3. 主宾关系

        例：我：你

  • 1.2.4、拆分思维

    • 方式目的（前后两词一般是 动词/动宾 结构）关系
      • 技巧：“为了”造句，通常认为造成
      • 词语积累
        1. 刻舟：求剑
        2. 按图：索骥
        3. 削足：适履
        4. 杀鸡：取卵
        5. 杀鸡：儆猴
        6. 掩耳：盗铃
        7. 守株：待兔
        8. 凿壁：偷光
        9. 缘木：求鱼
        10. 画饼：充饥
        11. 饮鸩：止渴
        12. 望梅：止渴
    • 因果关系
      • 技巧：通常自然造成
      • 词语积累
        1. 人逢喜事: 精神爽
        2. 城门失火: 殃及池鱼
        3. 众人拾柴: 火焰高
        4. 多行不义: 必自毙
        5. 水落石出
        6. 水涨船高
        7. 春暖花开
        8. 风吹草动
        9. 天寒地冻
        10. 物腐虫生
        11. 鸟尽弓藏
        12. 唇亡齿寒
        13. 理屈词穷
        14. 水滴石穿
    • 拆分常见考法
      1. 语义关系
        • 生死存亡 南征北战
      2. 并列关系
        • 飞禽走兽 笔墨纸砚
      3. 因果关系
        • 春暖花开 唇亡齿寒
      4. 方式目的
        • 刻舟求剑 顺藤摸瓜
      5. 偏正关系（偏即修饰语：形容词/副词。正即中心语：名词/动词。一般可加“的”或“地”‌）
        • 青山绿水 唇红齿白
      6. 语法关系
        • 愚公移山 忧国忧民（动宾关系）

# 1.3、定义判断

  • 概念：每题给出一个概念的定义，然后分别列出四种情况，严格依据定义，选出一个最（不）符合该定义的答案选项
  • 解题思路：
    1. 看提问 —— 看清“属于 / 符合”、“不属于 / 不符合”
    2. 看题干 —— 识别有效信息：找准关键词句
    3. 看选项 —— 纠结时、选项对比择优
  • 1.3.1、考点一：读得准
    1. 关键词（主体、客体）
      • 主客体不符合的选项一定不符合定义
      • 每题不一定都有主体和客体，但出现了主客体要重点看
      • 出现范围越小越明确的主客体，尤其重要
      • 常考主客体
        • 行政机关：各级政府（国务院...街道办 / 乡镇政府、公安等）
        • 权力机关：全国人大、地方人大
        • 司法机关：法院、检察院
        • 事业单位：学校、医院、科研所、广播新闻出版等
        • 社会组织：商会（浙商会）、协会（消费者协会）
      • 大概率题型：涉及到多个主客体
    2. 句式（引导的内容重点看）
      • 常见引导关键词
        • 方式：通过/利用...
        • 目的：以达到...
        • 原因：因为/由于...
        • 结果：导致/从而/使得...
        • 前提：当...时/在...之前/后
      • 大概率题型：结果出现积极、消极
    3. 解释说明
      • 常见关键词：即、包括、也就是说、以下情形...
  • 1.3.2、考点二：读得快
    1. 优先看到定义所在的那句话
    2. 多个定义问哪个看哪个，纠结时，再看其他定义
  • 1.3.3、考点三：小技巧
    • 拆词（定义词本身即关键词）
      1. 定义词本身通俗易懂，优先关注
      2. 选项纠结时，以拆词为重要破题点

# 1.4、逻辑推理

  • 翻译推理
    • 特征：
      1. 题干和选项中存在明显的逻辑关联词
      2. 提问方式：可以推 / 不能推出
    • 1.4.1、前推后 充分翻译：

      如果/就/都/一定

      • 如果...，那么...
      • 若...，则...
      • 只要...，就...
      • 所有...，都...
      • 凡是...，都...
      • 为了...，一定/必须...
      • ...是...的充分条件
    • 1.4.2、后推前 必要翻译：
      • 只有...，才...
      • 不...，不...
      • 除非...，否则...不...【重点】
        1. 除非 A 否则不 B => B -> A
        2. 除非 A 否则 B => -B -> A
      • ...是...的基础/假设/前提/关键 【重点】
      • ...是...的必要/必不可少的/不可缺少的条件 【重点】

        技巧：谁必不可少，谁在箭头后

        1. 食物是人类生存必不可少的。 => 生存 -> 食物
        2. 人类生存，食物是必不可少的。 => 生存 -> 食物
        3. 建大厦的基础是修好地基。 => 建 -> 地基
        4. 想成功，不懈的努力是前提。 => 成功 -> 努力
    • 推理规则：逆否等价
      • （前推后）符号表示：A -> B = -B -> -A
      • （后推前）符号表示：B -> A = -A -> -B
        1. A -> B, B -> C 递推 A -> B -> C 或 -C -> -B -> -A
        2. A -> B, -A -> C 递推 -C -> A -> B 或 -B -> -A -> C
        3. A -> B, C -> -B 递推 A -> B -> -C 或 C -> -B -> -A
        4. A -> B, A -> C 递推无法联合
      • 文字表示：肯前必肯后，否后必否前。否前、肯后不必然（不确定、可能、可能不）
    • 1.4.3、且和或：
      • 且关系翻译：
        1. 和
        2. 既...，又...
        3. 不仅...，而且...
        4. ...，但是...
      • 或关系翻译：
        1. 或者
        2. 或者...，或者...
        3. 至少有一个
        • 推理规则：或关系否一推一（“或”关系为真时，否定一项可推到另一项为真）
    • 推理规则：德·摩根定律（且或交换）
      1. -(A 且 B) = -A 或 -B
      2. -(A 或 B) = -A 且 -B
  • 排列（排序）组合
    • 特征：
      1. 两组及以上对象
      2. 对象之间的关系
    • 方法：
      • （题干确定）排除法：读一句，排除一句（读题排选项）
      • （题干不确定）代入法：假设选项正确，代入题干验证是否符合题意
        1. 题干条件：确定优先排除法，不确定尝试代入法

        2. 特殊问法（如："补充/添加以下哪项可推出"、"可能"、"不可能"）考虑代入法
    • 推理法
      1. 推理起点：确定信息和最大信息（题干条件中出现次数最多的词）
      2. 假设法：二选一或无确定信息和确定信息
    • 3-2-1 题型

  • 真假推理
    • 题型特征：
      1. 题干给出多个条件
      2. 提问为：只有一真、只有一假、几真几假等
    • 找关系（一真一假）
      • 矛盾关系：非此即彼的关系（必有一真、必有一假）。

        1. A 与 -A
        2. 所有都是 与 有的不是。 所有都不是 与 有的是
        3. A -> B 与 A且-B
        4. A且B 与 -A或-B。A或B 与 -A且-B

          推理规则：德·摩根定律（且或交换） -(A且B) = -A或-B。-(A或B) = -A且-B

      • 反对关系：除已知的两方面之外，还存在其他情况。

        1. 有的是 与 有的不是 （两个有的，必有一真，可以同真）
        2. 所有都是 与 所有都不是 （两个所有，必有一假，可以同假）
      • 【秒杀技巧】：欺软怕硬（有的反说，所有顺说）
        1. 两个“有的”口诀：找点名那句，反着它说，人称变所有

          1、“有的同学都是党员” 2、“有的同学都不是党员” 3、“A 是党员”【反说】=> “所有都不是党员”

        2. 两个“所有”口诀：找点名那句，顺着它说，人称变所有

          1、“所有同学都是党员” 2、“所有同学都不是党员” 3、“A 和 B 是党员”【顺说】=> “所有都党员”

    • 找其余（找不到矛盾、反对关系时）
      1. 假设法
      2. 代入法（问可能，找不到矛盾、反对关系时）
      3. A -> B = -(A且-B) = -A或B

        由【A -> B 与 A且-B】是矛盾关系推导

    • 两真两假
      • 矛盾关系
        1. 所有 与 有的
        2. A或B 与 A （同理: A或B 与 B）

          A 或 B => 有的

      • 【秒杀技巧】：两真两假【有的、或】为真话

        【秒杀技巧】：两真两假【两个有的】为真话

      • 做假设
  • 逻辑论证
    • 论证基础
      • 【论据】 =论证（过程）> 【论点】

      • 【论点】典型提示词
        1. 所以
        2. 结论是
        3. 这表明/说明/意味着
        4. 由此推出
        5. 因此、据此认为
      • 【论据】典型提示词
        1. 由于
        2. 因为
        3. 鉴于
        4. 根据
      • 【论据】常见形式
        1. 原因
        2. 数据事例实验
        3. 调查内容
      • 找论点论据
        1. 首尾句原则

        2. 结合提问方式——问啥找啥

        3. 下定义、提问题、说现象、 “但”之前的语句都可略读或不读

    • 加强（赞同）论证
      • 加强类常见提问方式
        1. 如果以下各项为真，最能 加强/支持/赞同/证明 上述论断的是？
        2. 以下哪项为真，是上述论断成立的前提/假设/必要条件
        3. 如果以下各项为真，最不能加强上述论断的是？

          不能加强 ≠不等于≠ 削弱

      • 加强——补充论据

        当只有**论点（或论据与论点话题一致）**时，则优先考虑 补充论据

        1. 解释原因：说明论点成立的原因
        2. 举例支持：证明论点成立的例子
        • 正确答案往往同是会包含论点关键词或关键词的同义替换

      • 加强——搭桥（力度最强, 搭桥/论证——论据可以推出论点的过程）

        当论点与论据话题不一致时，需要加强【论证】，则优先考虑 搭桥.

        1. 提问方式为前提、假设、必要条件、论证时，优先考虑搭桥
        2. 选项特征：同时包含论点和论据中的关键词，并肯定论点和论据间的关系
        3. 解题思路：找论点 => 找论据 => 对比选项（去同存异）
        4. 力度比较：整体 > 部分，绝对 > 可能

      • 加强——必要条件（力度较强）

        当选项为论点成立的必要条件时

        1. 提问方式为前提、假、必要条件，且无搭桥选项
        2. 论点为 方式+目的（常考做法可行或有效）

      • 加强——针对选项
        1. 主体/话题不一致选项，不选
        2. 不明确的选项，不选
        3. 类比的选项（例：两者类似 ）一般，不选
        4. 警惕副作用的选项
        5. 警惕选项中的限定词
        6. 力度：搭桥/必要条件 > 能解析原因 > 举例子（补充论据）
    • 削弱（反对）论证
      • 削弱类常见提问方式
        1. 如果以下各项为真，最能质疑/反驳/削弱/反对上述论断的是？
        2. 如果以下各项为真，最不能质疑上述论断的是？
      • 削弱——否定论点（力度最强，【常考】）

        当文段只有**论点（或论据与论点话题一致）**时，则优先考虑 否定论点

        1. 选项特征：与论点表述的意思相反

        2. 解题步骤：找论点 => 预设（削弱）答案 => 对比选项

      • 削弱——拆桥（力度仅次削弱论点）
        • 拆桥：论点与论据之间没有必然关系

        • 选项特征：包含论点与论据中的关键词，并否定论点和论据之间的必然关系。

        • 何时拆桥
          1. 没有否论点的选项
          2. 论点、论据话题不一致
          3. 提问方式为“削弱论证”时，优先考虑拆桥
        • 拆桥不同形式：（例如：今天特别热，因为今天出太阳了）

          拆桥：出太阳（论据）≠ 天气热（论点）

          1. 出太阳推不出天气热
          2. 出不出太阳跟热不热没关系
          3. 有时候出太阳也不热
          4. 出太阳不是影响气温升高的唯一因素。
      • 削弱——否定论据

        • 题型特征
          1. 题干中有“双方互怼”，经常采用否定论据来削弱
          2. 题干有论据（且找不到 否论点 和 拆桥）
        • 选项特征：与论据表述意思相反
      • 削弱——因果倒置和他因削弱
        • 因果论证：论点包含因果关系
          1. ...是...的原因
          2. ...导致/使得/有助于...
          3. ...增加/降低/加强/减轻...，这是由于...
        • 因果倒置（等同否论点，选项削弱优选）：原因和结果说反

          论点： A 是 B 的原因。 因果倒置削弱：B 是 A 的原因

          1. 落后倒置挨打 => 挨打倒置落后
          2. 喝奶茶让我胖了 => 胖了才喝奶茶
        • 他因削弱（其他干扰因素）：承认结果，同一主体、同时存在两种及以上可能的原因

          若论点是其中一种原因，则可用另一种原因进行削弱（特点：同一主体、同一时间、不同原因）

          1. 我做了个实验，结果证明：节食是我瘦了下来 => 他因削弱：除了节食，你每天还有去健身房做减肥操。

# 统计术语

  • 现期量、基期量、增长量、增长率

    • 现期（也称末期，时间大）量 与 基期（也称初期，时间小）量之间相对概念，
    • 增长量：(\Delta = 现期 - 基期)

      现期与基期之间的加减号判断技巧：多减少加（多：上升/提高；少：降低/回落）

    • 增长率/增速/增幅：r = $ \frac {\Delta}{基期} × 100% $
    • 基期 = $ \frac {现期}{1+r} $

      |r|绝对值 ≤ 5% 时，基期 = 现期 - (现期 × r)

  • 同比、环比

    • 同比：同比看年，今年与去年的同一时期比
    • 环比：环比看尾，与最小单位（“年”“月”“日”）的上一个单位相比
    时间点 同比 环比
    2026 年 8 月 2025 年 8 月 2026 年 8 月
    2026 年上半年 2025 年上半年 2025 年下半年
    2026 年第一季度（Q1） 2025 年第一季度（Q1） 2025 年第四季度（Q4）

  • 比重、倍数、平均数

    • 比重 = $ \frac {部分}{整体} × 100% $ = $ \frac {“占”前}{“占”后} × 100%$

      比重单位默认 %

    • 倍数 = $ \frac {“是”前}{“是”后} $

      XXX 是 XXX 的多少倍

    • 平均数
      1. 平均每： = $ \frac {后单位}{前单位} $

        平均每小时（前单位）多少公里（后单位）$ \frac {公里}{小时} $

      2. 单位：= $ \frac {后单位}{前单位} $

        单位面积（前单位）的产值（后单位）$ \frac {总产值}{总面积} $ 单位面积（前单位）产量（后单位）是多少公斤/公顷 $ \frac {总产量}{总面积} $

      3. 人均/月均： = $ \frac {后单位}{前单位} $

        人（前单位）均的收入（后单位） $ \frac {收入}{人数} $

  • 百分数、百分点

    • 百分数：用 % 表示（常用在增长率 或 比重）
    • 百分点：是两个百分数的变化，用减法计算，用数来表示

  • 其他

    • 翻番：翻 n 番 = $2^n$ 倍
    • （进出口）贸易总额 = 进口额 + 出口额
    • 顺差：出口 > 进口

      顺差值（即：净出口） = 出口（金额） - 进口（金额）

    • 逆差：出口 < 进口
    • 美国自(从)中国进口= 中国出口到美国
    • 成 = 10%
    • 五年计划：奇 60 偶 15(尾数)
      • 十五五： 2026 - 2030

        十五 => 奇数，2026(尾数) => 6, 2030(尾数) => 0

      • 十四五： 2021 - 2025

        十四 => 偶数，2021(尾数) => 1, 2025(尾数) => 5

    • （人或货物）周转量 = 人或货物数 × 平均值

    • XXX （日期）末：表示从该完整日期之前的时间段
    • XXX （日期）累计：表示从年初到该日期的时间段

      2026 年 6 月份累计 = 2026年上半年； 2026年 2 月份 = 2026年 1 到 2月份

# 速算技巧

  • 除法 —— AB式

    国考联考速算程度： 前两位数字 通常可锁定答案选项

    • 截位直除法：
      • 分母 1、2 开头，（四舍五入）保留 三位数字
      • 分母 3及以上 开头，（四舍五入）保留 两位数字
      • 分子取 三位数字
  • 算位法、乘法

    通常适用于选项之间出现 $10^n$ 倍，必须考虑单位、%、小数点

    • 补 0 法：
      • 分子整数位大于分母整数位，结果前补 0

        $\frac {628923.8}{93.8}$ 分子整数部分比分母多 4 位，故此结果应为至少四位数即 1000，再运算后约等于 6704.9

      • 分子整数位小于分母整数位，结果前补 0（带小数点）

        $\frac {37.5}{62923.8}$ 分子需要补 4 个 0 才能大于分母，故此结果应为 0.000_ _，再进行运算后约等于 0.00059

  • 除法 —— 错位加减法

    选项之间存在 0.1 或 0.01 的极小差值时，或将就硬算

    1. 分子分母均取前三位数，不用四舍五入。
    2. 将分母增加/减去（基于分母）某个比例值转换为可容易的分母，分子也同理增加/减去（基于分子）同等比例值，在进行结果运算
  • 乘法（将乘法转为除法）
    • 特殊分数 + 取整

      原理：分数的分母 与 百分数 互乘等于 100

      • $\frac {1}{2}$ = 50 %
      • $\frac {1}{3}$ = 33 %
      • $\frac {1}{4}$ = 25 %
      • $\frac {1}{5}$ = 20 %
      • $\frac {1}{6}$ = 16.7 %
      • $\frac {1}{7}$ = 14.3 %
      • $\frac {1}{8}$ = 12.5 %
      • $\frac {1}{9}$ = 11.1 %
      • $\frac {1}{10}$ = 10 %
      • $\frac {1}{11}$ = 9.1 %
      • $\frac {1}{12}$ = 8.3 %
      • $\frac {1}{13}$ = 7.7 %
      • $\frac {1}{14}$ = 7.1 %
      • $\frac {1}{15}$ = 6.7 %
      • $\frac {1}{16}$ = 6.25 %
      • $\frac {1}{17}$ = 5.9 %
      • $\frac {1}{18}$ = 5.6 %
      • $\frac {1}{19}$ = 5.3 %
      • $\frac {1}{20}$ = 5 %
    • 两个百分数乘法，将其中一个转为分数再乘运算

      例：23.5% × 15.2% ≈ 23.5% × $\frac {1}{7}$ ≈ $\frac {23.5}{7}$% = 3.6%

# 3.1、中心理解题【重点】

选项与题干材料同义转述/替换（主体一致、逻辑一致）

  • 题型特征
    1. 意在说明/强调
# 关联词
  • 转折文段
    • 识别关联词：虽然...，但是...
      • 虽然 => 虽说、固然、诚然、尽管
      • 但是 => 可是、然而、却、不过

        弱转折（但是）=> 则、其实、事实上、实际上、相反、殊不知

    • 应用
      1. 转折之后是重点
      2. 转折前后倾向相反，内容相对
      3. 消极倾向表问题，有问题即可能有对策
  • 因果文段
    • 识别关联词
      • 原因：因为、由于...
      • 所以：因此、因而、导致、造成、致使、使得...
      • 指代词（对前文总结）：这、此、该、从这个角度看...
      • 总结词：总之、由此观之、可以说...
    • 应用
      1. 结论是重点，常在尾句
      2. 因果同是出现的选项 优于 只有结论的选项
      3. 观点 + 解释说明材料
        • 正确答案形式:
          1. 结论的原因/背景/缘由
          2. 解释/说明/分析 + 结论
          3. 为什么/为何/所以 + 结论
  • 对策文段（可能以转折、因果文段呈现）
    • 识别关联词
      1. 只有...，才...
      2. 应该、应当、务必、必须、需要、亟需、亟待、离不开
      3. A 是 B 的基础/保证/保障/关键/前提/必要条件
      4. 以/通过...方式/渠道/措施/途径/手段
      5. 呼吁、倡导、提倡、提醒、建议...
    • 应用
      1. “只有”之后，“才”之前的必要条件是重点
      2. 必要条件常用来引导对策，对策是重点
      3. 没有对策关联词，找解决问题的句子*
  • 反面论证（常位于证明观点之后，用于再次加强观点）
    • 识别关键词：否定词 + 后果（偏消极）
      • 否定词：否则、不然、如果/倘若/假使/一旦 + 不/没有...、就/则/那么...
    • 应用
      1. “否则”、“不然”之前找重点
      2. "如果 + 否定性论述" 前若有对策，则对策是重点
      3. "如果 + 否定性论述" 前若无对策，则其反推即对策
      4. 如果不 A，则不 B => 只有 A，才 B
  • 优选对策项
    1. 文中只提问呗不解决，选项中优选对策，对策针对问题和主题词
    2. 优选对策词形式： 亟待、亟需、刻不容缓、迫在眉睫、不容迟滞
    3. 验证对策是否正确，可以有对策反推问题
    4. 对策不正确或无效，选问题
    • 优选对策项 = 问题 + 对策引导词
      • 环境污染问题严重 => 环境污染亟需治理
      • 历史文化遗产保护不力 => 需要加强历史文化遗产保护
      • 野生动物生存环境遭到破坏 => 呼吁保护野生动物生存环境
      • 农村基础设施建设尚不完善 => 农村基础设施建设有待完善
  • 并列文段
    • 识别关联词
      1. 一方面...，另一方面..。此外；另外；与此同时；
      2. 分号；相同句式；
      3. 列举事例；另起话题；
    • 应用
      1. 并列加和，全面概括来（同一主体，不同方面）
      2. 提取共性特征；（不同主体，同一共性）
      3. 排除无中生有项与片面项
  • 递进文段
    • 识别关联词
      1. 首先、其次、再次、最后；
      2. 古代、近代、现代；
      3. 第一步、第二步；
      4. 甚至
    • 应用
      1. 主要论述对象 + 主要事件
      2. 全面概括
      3. 排除无中生有项与片面项
# 行文脉络（通常有结论，俗称”总“）
  1. "总"句：论点/对策（重点）
  2. "分"句：用来证明观点、分析问题、引出话题的句子（非重点）
  3. 谨防选项：1、偷换概念。2、两/多个主体。3. 无中生有

  • 总-分结构
    • 结构：提出观点 - 解释说明/举例论证/并列分述
    • “总”句标识
      1. 专家/学者认为、我觉得/认为

        引用观点：权威观点 => 作者观点 非权威观点：（某些）有人/传统/群体观点

      2. ...显示/表明；...指出...
    • “分”句之举例论述
      • 识别标识
        1. 比如、例如、XXX是一个例证、以...为例
        2. 地名、人名、时间；引用观点；数据
      • 应用
        1. 例子证明谁，谁是重点
        2. 例子是形象化理解观点的手段，本身不重要
        3. 只针对举例的选项为干扰选项
    • “分”句之解释说明
      • 识别标识
        1. 因为、由于、原因是...、理由是...
      • 应用
        1. 对谁做解释说明，谁是重点
        2. 解释说明是为了证明观点，本身不重要
        3. 关于解释说明的选项通常不选
  • 分-总结构
    • 结构：解释说明/举例论证/背景铺垫 - 得出结论

      提出问题（分析问题）-解决问题

    • “总”句标识
      1. 这、因此/所以、对策句、换句话说/也就是说
    • “分”句之背景铺垫
      • 识别标识
        1. 宏观形式：随着、在背景下、近年来、实际上、目前
        2. 概念铺垫：XXX是...（下定义）
      • 应用
        1. 重点常在最后
        2. 背景本身不重要
        3. 关于背景的选项通常不选
  • 总-分-总结构
    • 结构：提出观点 - 举例论证/解释说明-重申结论

      首尾是重点，反复强调观点

  • 分-总-分结构
    • 结构：

      首尾不重要，观点/对策最重要

      1. 提出问题 - 解决问题-对策效果/具体措施
      2. 背景铺垫 - 提出观点-解释说明/举例论证/反面论证

# 3.2、片段阅读【弱项短板】

先看问法，再看材料

  • 标题添加题
    • 题型特征： 1.“最适合做这段文字标题的是：”
    • 题型思路

      点明主旨、突显主题词

      1. 议论性文段：主体色彩（作者观点、态度）
      2. 说明性文段：科普、客观、事物（说明对象 + 特征）
      3. 记叙性文段：讲故事（背后道理启示）

      4. 新闻性文段：（凝练 + 新闻事件）
    • 选项
      1. 紧扣主题，无主题慎选。
      2. 全面完整，片面化不选。
      3. 形象生动，不醒目慎选。
  • 细节判断题
    • 题型特征：
      1. “下列说法中（不）正确的一项是：”
      2. “下列说法（不）符合文意的一项：”
      3. “根据文意（不）可以得出：”
    • 题型思路：先观察选项，再对应原文
    • 正确选项：
      1. 相对性表述：可能、也许、或、往往、通常
      2. 中间量表述：特定、某些、一些
      3. 选项符合文段中心观点
    • 干扰选项之偷换范围、程度、时态
      1. 范围扩大：所有、一切、都、大部分、大多数
      2. 范围缩小：仅仅、唯一、只有、小部分、少数
      3. 程度加重：最、更、很、特别、十分、语气过于绝对
      4. 已然状态：已经、已、曾、了、过
      5. 进行状态：正、正在、现在、在...中
      6. 未然状态：将、要、不久、很快、未来
    • 干扰选项之偷换逻辑
      1. 因果关系：导致、致使、使得、造成
      2. 条件关系：只有...才、只要...就、必要条件、基础、关键、前提
    • 干扰选项之曲解文意
      • “选项中含有否定表述”
    • 干扰选项之偷换概念
      • 注意选项中的主宾语
    • 干扰选项之无中生有
      1. 凭空出现名词
      2. 以“是”作谓语
      3. 两者间强加关系
        • A 延缓/推动了 B;
        • A 越... ,B 越...;
        • A 比/较 B（更）...;
  • 下文推断题

    上文尾句推导下文（承上启下）

    • 题型特征：

# 四、数量关系

# 4.1 方程思维（应用、和差倍比）

  • 甲班的人数比乙班的人数多了 40 人，表示

    假设乙为 x，则 甲为 x + 40

  • 今年毕业生人数和去年比是 7:5，表示

    已知 $\frac {今年}{去年}$ = $\frac {7}{5}$，则可假设今年毕业人数为 7x, 去年为 5x

  • 甲的销售额比乙多了 3/5，表示

    已知 甲 = 乙 × (1 + $\frac {3}{5}$) = 乙 × $\frac {8}{5}$，则可假设乙为 5x, 甲为 8x 秒杀：比谁即分母，则乙为 5x, 速推出甲为 8x

  • 乙的销售额比甲少了 3/5，表示

    已知 乙 = 甲 × (1 - $\frac {3}{5}$) = 甲 × $\frac {2}{5}$，则可假设甲为 5x, 乙为 2x 秒杀：比谁即分母，则甲为 5x, 速推出乙为 2x

  • 甲增加 3 本，乙增加到原来的 3 倍，丙减少了原来的 1/3，则三人的书一样多，表示

    假设（一样多）中间量分完后书量为 X，则原本甲为 X - 3，乙为 X × $\frac {1}{3}$，丙为 X × 3

  • 若甲给乙 8 本，则乙比甲所剩的书多 20%，表示

    已知分完后 乙 = 甲 × (1 + $\frac {1}{5}$) = 甲 × $\frac {6}{5}$, 则可假设分完后乙为 6x，甲为 5x，而原本乙则为 6x - 8, 甲则为 5x + 8

  • 如果每辆车坐 20 人，还剩下 2 名员工，表示

    已知 总人为= 车数 × 20 + 2，则可假设车数为 X，总人数为 20 × X + 2

    设小不设大：车数、人数

  • 某班如果按 7 男 5 女搭配分组，则只剩下 8 名男生，表示

    假设组数为 X, 总人数 = X ×（7 + 5），男人数 = 7 × X + 8，女人数 = 5 × X

    设小不设大：组数、人数

  • 某企业 3 月节电量是 1月的 1.2倍、2月的 1.5倍，表示

    已知 三月 = 一月 × $\frac {6}{5}$，则可假设一月为 5x，三月为 6x, 则二月为 6/1.5 = 4x

# 4.8 排列组合（概率）问题

  • 关键词：“多少种不同...”
  • 作答步骤
    1. 枚举
    2. 分类分步
      • 分类用 + 加法累计： 类1 + 类2 + 类3 + ...
      • 分步用 × 乘法累计： 第一步 × 第二步 × 第一步 × ...
      1. 例 0、1、2、3可以组成多少种三位数不同的偶数？

      题干可知：三位数、百十个 ，偶数个位只能 0 或 2 分类

      • 当个位为 0 时，则（第一步）百位有 3 种可选择，（第二步）十位有 2 种可选（百位已选走了 1 个数）
      • 当个位为 2 时，则（第一步）百位有 2 种可选择（三位数首位不鞥是 0），十位有 2 种可选（百位已选走了 1 个数）
      • 类0尾 + 类2尾 = 3 × 2 × 1 + 2 × 2 × 1 = 6 + 4 = 10
    3. 排列组合
      • C 组合（无次序）
        1. 例从 3 人中选出 2人，有 ${C_3^2}$ = $\frac {3×2}{2×1}$ = 3 情况 ${C_{10}^4}$ = $\frac {10×9×8×7}{4×3×2×1} $
        2. 例从 3 男 2 女，选出 1 男 1 女，有多少种情况？
        • 先从 3男选出 1男， ${C_3^1}$
        • 再从 2女选出 1女， ${C_3^1}$
        • 步选1男 × 步选1女 = ${C_3^1}$ × ${C_3^1}$ = 3 × 2
        • C 组合互补特性：${C_5^2}$ = ${C_5^3}$; ${C_5^1}$ = ${C_5^4}$; ${C_5^0}$ = ${C_5^5}$ = 1
      • A 排列（重次序）
        1. 例从 3 人中选出 2人进行排序，有 ${C_3^2}$ × ${A_2^2}$ = ${A_3^2}$ = 3×2 = 6 情况 ${A_3^2}$ = ${C_3^2}$（先从 3 人选出 2 人）× ${A_2^2}$（再将 2 人进行排序） ${A_{10}^4}$ = ${C_{10} ^ 4}$（先从 10 人选出 4 人）× ${A_4^4}（再将 4 人进行排序 ${A_4^4} = 4×3×2×1）= 10×9×8×7 = 5040
        2. 例从 3 男 2 女，选出 1 男 1 女进行排序，有多少种情况？
        • 先从 3男选出 1男， ${C_3^1}$
        • 再从 2女选出 1女， ${C_3^1}$
        • 最后将1男1女进行排序， ${A_2^2}$
        • 步选1男 × 步选1女 × 步排序2人 = ${C_3^1}$ × ${C_3^1}$ × ${A_2^2}$ = 3 × 2 × (2×1) = 12
  • 案例
    • 逆向思维
      • 满足情况 = 总情况 - 不满足情况

    • 捆绑插空法
      • 相连/都在一起（捆绑法）：(多个看成一个)先外再内
      • 不相连/都不在一起（插空法）：现排其他，再插空
      1. 例 3男4女站一排，女生必须都在一起，请问多少种情况？

      捆绑：4女看成 1女（内部顺序情况 ${A_4^4}$），现在外部情况为 3男1女站一排 ${A_4^4}$。捆绑情况 = ${A_4^4}$ × ${A_4^4}$

      1. 例 3男4女站一排，男生必须都不在一起，请问多少种情况？

      插空：4女先排列 ${A_4^4}$ 情况，4女之间最多留下 5 个空位给3男排列 ${A_5^3}$ 情况。插空情况 = ${A_4^4}$ × ${A_5^3}$

    • 错位排列

      不常考

      • 错位排列：所有元素都不在原始的位置

        例：1（第一位）2（第二位）3 （第三位）。错位排列 2 种：231、312

      • N个元素错位排列情况公式： （前N-2个元素情况数 + 前N-1个元素情况数）× (N - 1)

        一个元素 0 种情，两个元素 1 种情况，三个元素 2 种情况。四个元素 9 种情况，五个元素 44 种情况，六个元素 (9+44)×(6-1)= 265 种情况

    • 环形排列
      • 环形排列技巧：固定一人，剩下人数随机排序所有情况

        N 个人环形排列情况 = ${A_{N-1}^{N-1}}$

        4人麻将，座次情况 ${A_3^3}$ = 3×2×1; 10人环形排序，座次情况 ${A_9^9}$ = 9×8×7×6×5×4×3×2×1

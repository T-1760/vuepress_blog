# 资料分析

# 年均增长率

  • 二项式
    • [r = \frac{\frac{现}{基} - 1}{n}]
  • 万能公式 （r < 10% ） (opens new window)
    • [r = \frac{\frac{现}{基} - \frac{基}{现}}{2n}]

# 一、统计术语

# 1.1、基期 & 现期

  • 基期：相对于今年来说，去年的就是基期
  • 现期：相对于去年来说，今年的就是现期

# 1.2、基期量 & 现期量

  • 基期量：相对于今年来说，去年的量就是基期量
  • 现期量：相对于去年来说，今年的量就是基期量

# 1.4、增长量 & 增长率

  • 增长量：现期量和基期量的差值，就是增长量
  • 增长率：增长量与基期量的比值，就是增长率

# 1.5、倍数 & 比重 & 平均数

  • 倍数：A 是 B 的多少倍：A 为 B 的多少倍，等于增长率加 1
    • 辨析：A 比 B 增长了 500%，那么就是 A 比 B 增长（多）5 倍, A 是 B 的 6 倍
  • 比重：
    • A 占 B 的比重，A 占 B 为多少；都等于 A/B
    • A 占 B 的比重比 C 的比重为：A/B - C/B
  • 平均数：在一组数据中所有数据之和再除以数据的个数

# 1.6、同比 & 环比

  • 同比：同比看年，今年与去年同期比
  • 环比：环比看尾，“年”“月”“日”等

# 1.7、顺差 & 逆差

  • 顺差：也称出超，出口大于进口
  • 逆差：也称入超，出口小于进口

# 1.8、百分数 & 百分点

  • 百分数：用 % 表示
  • 百分点：用数来表示，是两个百分数的变化，用减法计算

# 1.9、其他

  • 成数：两成，即 20 %
  • 翻番：翻一番是 2 倍，翻两番是 4 倍，翻 n 番是 2n 倍
  • GDP:一国所有常住单位一定期内生产的全部最终产品和服务价值总和

# 二、基期（量） & 现期（量）

# 2.1、基期

  • 基期 = 现期 - 增长量 = $\frac{现期}{1 + r_{增长率}}$ = $\frac{增长量}{r_{增长率}}$

    当 | r | ≤ 5% 时

    $\frac{A_{现期}}{1 + r_{增长率}}$ => $A_{现期} × (1 - r_{增长率})$ $\frac{A_{现期}}{1 - r_{增长率}}$ => $A_{现期} × (1 + r_{增长率})$

  • 基期和差 = $\frac{A_现}{1 + a_{增长率}} ± \frac{B_现}{1 + b_{增长率}}$
  • 间隔基期 = $\frac{现期}{1 + r_{间隔增长率}}$

# 2.2、现期

  • 现期 = 基期 + $n_{年份差}$ × 增长量 = 基期 × $(1 + r_{增长率})^{n_{年份差}}$

    n = 1 可忽略，现期 = 基期 + 增长量 = 基期 × (1 + $r_{增长率}$)

  • 间隔现期 = 基期 × (1 + $r_{间隔增长率}$)
  • ❓现期追赶问题
    1. 小追大，能追上；问几年，找差距，补差距。
    2. 大追小，追不上；问差距，N年差距 = 现在差距 + N × 增长量差距

# 三、增长量 & 增长率

  • 增长量：现期（即：现在） 比 基期（即：过去） 变化了多少（具体量携单位）
  • 增长率：现期（即：现在） 比 基期（即：过去） 变化了百分之多少（%）

# 3.1、增长量

  • 一般增长量 = 现期 - 基期 = 基期 × $r_{增长率}$ = $\frac{现期}{1 + r_{增长率}} × r_{增长率}$
    1. 当 r ＜ 0 时（减少量估算），$\frac{现期}{1 + r_{增长率}} × r_{增长率}$ => $\frac{现期}{\frac{1}{r_{增长率}} - 1}$
    2. 当 r ＞ 0 时（增加量估算），$\frac{现期}{1 + r_{增长率}} × r_{增长率}$ => $\frac{现期}{\frac{1}{r_{增长率}} + 1}$
    3. 当 | r | ≤ 5% 时（可估算），基期 × $r_{增长率}$ => 现期 × $r_{增长率}$
  • 年均增长量 = $\frac{现期 - 基期}{n_{年份差}}$

    2020年~2025年, 则 $n_{年份差}$ = 5年

  • 增长量比较大小
    • 口诀：大大则大；一大一小比倍数（以“倍数大”为准）

# 3.2、增长率（增速）

给了百分点：高减低加。例：今年10% 比去年增加了5%，则去年 = 10% - 5% = 5%

  • 一般增长率 = $\frac{增长量}{基期}$ = $\frac{增长量}{现期 - 增长量}$ = $\frac{现期 - 基期}{基期}$ = $\frac{现期}{基期} - 1$

    • 常不求具体值，只作比较增长率的大小（可简化比较：$\frac{现期}{基期}$ )
      1. 当 $\frac{现期}{基期} ≥ 2^+$明显，可简化比较：$\frac{现期}{基期}$
      2. 当 $\frac{现期}{基期} = 1^+$不明显，则具体比较：$\frac{增长量}{基期}$

  • 年均增长率 r

    • 公式：$(1 + r_{年均增长率})^{n_{年份差}}$ = $\frac{现期}{基期}$
      • $r_{年均增长率}$ = $\sqrt[n_{年份差}]{\frac{现期}{基期}}$ - 1
        1. 当 r ≤ 10%，估算：$ r_{年均增长率} ≤ \frac{r_总}{n_{年份差}}$
        2. 当 r > 10%，计算：$(1 + r_{年均增长率})^{n_{年份差}}$ = $\frac{现期}{基期}$
    • 比较大小：可简化比较：$\frac{现期}{基期}$ 或 $\frac{增长量}{基期}$

  • 间隔增长率（隔年增长率）

    • $r_{间隔增长率}$ = $r_1 + r_2 + r_1 × r_2$
      • $r_2$ = $\frac{r_{间隔增长率} - r_1}{1 + r_1}$

      2019 年某产品产量为 120，2020 年同比增长了 20%，2021 年同比增长了 30%，请问 2021 年相比 2019 年增长了多少?

      • 解法一：常规解法，

      2020 年产量 = 120 × 1.2 = 144; 2021 年产量 = 144 × 1.3 = 187.2； 21 年相比 19 年增长了：（187.2 - 120）/ 120 = 56%

      • 解法二：间隔增长率 = r1 + r2 + r1 × r2 = 20% + 30% + 20% * 30% = 56%，
    • 间隔基期 = $\frac{现期}{1 + r_{间隔增长率}}$
    • 间隔现期 = 基期 × (1 + $r_{间隔增长率}$)

  • 乘积增长率

    • 形式：$A_量 = B × C$
      1. 部分 = 份数 × 整体
      2. 金额 = 单价 × 数量
      3. 产量 = 单产 × 面积
    • $r_A = r_B + r_C + r_B × r_C$

  • 混合增长率

    • 公式：整体 = 部分1 + 部分2
      • $r_1 < r_混 < r_2$ （口诀：混合居中不正中，偏向基数较大的一方，常用现期近似替代基期计算）
      • 线段法：距离与量成反比

        量：常用现期，但当 |r| ≥ 20% 时，必用基期

  • 累计增长率

    • 口诀：只要累计不滑坡，当月就比累计多

# 四、平均数类公式

  • 平均数 = $\frac{总数}{总份数}$

# 4.1、现期平均数 & 基期平均数

  • 现期平均数 = $\frac{a_1 + a_2 + ··· + a_B}{B}$ = $\frac{A_{现期总量}}{B_{现期总份数}}$
  • 基期平均数 = $\frac{基期总量}{基期总份数}$ = $\frac{A_{现期总量}}{B_{现期总份数}} × \frac{1 + b_{总份数增长率}}{1 + a_{总量增长率}}$

# 4.3、平均数增长量

题型识别为：“两个时间 + 平均数 + 增加/减少具体量(上升/下降多少个百分点)”

  • 平均数增长量 = 现期平均数 - 基期平均数 = $\frac{A_{现期总量}}{B_{现期总份数}}$ × $\frac{a_{总量增长率} - b_{总份数增长率} }{1 + a_{总量增长率} }$（公式单位：具体量）

    两期平均数比较

    • 当 a > b 时，现期平均数 > 基期平均数（即：上升）
    • 当 a = b 时，现期平均数 = 基期平均数（即：不变）
    • 当 a < b 时，现期平均数 < 基期平均数（即：下降）

# 4.4、平均数增长率⚠️

题型识别为：“两个时间 + 平均数 + 增加/减少 + 百分数”

  • $r_{平均数增长率}$ = $\frac{现期平均数 - 基期平均数}{基期平均数}$ = $\frac{a_{总量增长率} - b_{总份数增长率}}{1 + b_{总份数增长率}}$

    ⚠️注意： $\frac{a - b}{1 + b}$ （该公式是资析唯一分母有 b 的）公式中的分母是 1 + b，

  • 间隔平均数增长率

    先间隔，再平均

    • $r_{间隔平均数增长率}$ = $\frac{间隔现期平均数 - 间隔基期平均数}{间隔基期平均数}$ = $\frac{a_{间隔总量增长率} - b_{间隔总份数增长率}}{1 + b_{间隔总份数增长率}}$

# 五、比重类公式

  • 比重 = $\frac{部分（分量）}{整体（总量）}$

    利润率：资料分析和数量关系公式分母不同

    资料分析：$\frac{利润}{收入}$ 数量关系：$\frac{利润}{成本}$

  • 产销比 = $\frac{销量（后上）}{产量（前下）}$
  • 增长贡献率 = $\frac{部分增长量}{整体增长量}$

# 5.1、现期比重 & 基期比重

  • 现期比重 = $\frac{A_{现期分量}}{B_{现期总量}}$
  • 基期比重 = $\frac{基期分量}{基期总量}$ = $\frac{A_{现期分量}}{B_{现期总量}}$ × $\frac{1 + b_{总量增长率}}{1 + a_{分量增长率}}$

# 5.2、两期比重差

  • 两期比重差 = 现期比重 - 基期比重 = $\frac{A_{现期分量}}{B_{现期总量}}$ × $\frac{a_{分量增长率} - b_{总量增长率}}{1 + a_{分量增长率}}$（公式单位：百分点）＜ | a - b |

    其值判正负：选比 |a - b| 绝对值小的

    • a > b，比重上升（现期比重 > 基期比重）
    • a < b，比重下降（现期比重 < 基期比重）
    • a = b，比重持平（现期比重 = 基期比重）

# 六、倍数和翻番类公式

  • A 是 B 的多少倍？=> $\frac{A}{B}$
  • A 比 B 多多少倍？=> $\frac{A}{B} - 1$

# 6.1、现期倍数 & 基期倍数

  • 现期倍数 = $\frac{A_{现期量}}{B_{现期量}}$
  • 基期倍数 = $\frac{A_{基期量}}{B_{基期量}}$ = $\frac{\frac{A_{基期量}}{1 + a_{增长率}}}{\frac{B_{基期量}}{1 - b_{增长率}}}$ = $\frac{A_{基期量}}{B_{基期量}}$ × $\frac{a_{增长率} - b_{增长率}}{1 + a_{增长率}}$

# 6.2、翻番

  • 翻 N 番 = $2^N$

# 技巧策略

# 放缩估算法 (opens new window)

放缩估算法是资料分析中常用的速算技巧，通过‌放大或缩小数值‌简化计算，核心是保证估算精度满足需求。以下是不同场景下的典型运用：

  • 一、放缩估算法与直除法结合

    • 在分数计算中，常通过‌放缩分母（或分子）‌简化除法运算，利用直除法快速得出结果。
    • ‌示例‌：计算 $30738 \div 1929$

      由于 $1929$ 靠近 $2000$，将分母‌放大‌为 $2000$，即 $30738 \div 1929 \approx 30738 \div 2000$。
      直除法计算 $30738 \div 2000$，可快速估算结果约为 $15$。

  • 二、放缩估算法与左移两位估算法结合

    • 当计算“某数占总数的比例”（求量是 X %）时，通过‌取除数的1%‌简化除法，再结合“省略小数点后数字”的放缩，实现快速估算。
    • ‌示例‌：求 $675.8$ 占 $33211$ 的比例（即 $675.8 \div 33211$）

      1、取 $33211$ 的 $1% = 332.11$，用 $332.11$ 代替 $33211$ 计算。
      2、进一步将 $332.11$‌缩小‌为 $332$（省略小数点后数字），则 $675.8 \div 332.11 \approx 675.8 \div 332$。
      3、直除法计算 $675.8 \div 332 = 2.035 \approx 2 $，结果即为所求比例的百分数部分（结果就是 X %里面的 X）。

  • 三、加法的放缩估算法

    • 通过‌放大或缩小加数‌，快速确定和的范围，常用于“估算和的上下界”。
    • ‌加数放大‌：将每个加数‌放大‌后求和，和的值会‌大于原和‌，用于确定“和的上限”。

      示例：$8054 + 5992 + 1555 + 905$

      放大后：$9000 + 6000 + 2000 + 1000 = 18000$
      结论：原和 $< 18000$。

    • ‌加数缩小‌：将每个加数‌缩小‌后求和，和的值会‌小于原和‌，用于确定“和的下限”。

      示例：$8054 + 5992 + 1555 + 905$

      缩小后：$8000 + 6000 + 1500 + 900 = 16400$
      结论：原和 $> 16400$。

  • 放缩估算法的核心是‌在精度允许范围内简化计算‌，需根据题目选项差异、数据特性灵活选择放缩方向（放大/缩小）与程度，平衡“计算效率”与“估算精度”。

# 速算

估算尽量 1% 误差

# 1.068 × 0.267‌

  • 方法一：忽略小数点，整数相乘后补小数‌

    适合笔算或心算能力强时使用

    • 忽略小数点：1068 × 267
    • 先估算：1000 × 267 = 267,000；68 × 267 ≈ 70 × 267 = 18,690 → 减去 2×267≈534 → ≈18,156
    • 总和 ≈ 267,000 + 18,156 = ‌285,156‌
    • 原数共有 ‌6 位小数‌（1.068 有 3 位，0.267 有 3 位），所以结果为 ‌0.285156‌
  • 方法二：相近计算
    • 1.06 × 0.27 = ‌0.2862‌（保留四位小数）‌
    • 1.068 比 1.06 多 0.008，0.267 比 0.27 少 0.003
    • 可粗略估计：增加 0.008×0.27≈0.00216，减少 1.06×0.003≈0.00318 → 净减约 0.001
    • 得 ≈ 0.2862 - 0.001 = ‌0.2852‌，与精确值一致

# 1.068 × 1.869‌

  • 方法一：近似为整数 + 调整小数位‌
    • 将 1.068 ≈ ‌1.07‌，1.869 ≈ ‌1.87‌
    • 先计算 ‌1.07 × 1.87‌
    • 拆解：1.07 × (1.8 + 0.07) = 1.07×1.8 + 1.07×0.07
      • 1.07×1.8 = (1 + 0.07)×1.8 = 1.8 + 0.126 = ‌1.926‌
      • 1.07×0.07 = ‌0.0749‌
      • 合计 ≈ ‌1.926 + 0.0749 = 2.0009 ≈ 2.00‌
    • 原式因略小于近似值，最终结果约为 ‌1.998～2.00‌
  • ‌方法二：利用乘法分配律拆分‌
    • 1.068 × 1.869 = 1.068 × (1 + 0.8 + 0.06 + 0.009)
    • = 1.068×1 + 1.068×0.8 + 1.068×0.06 + 1.068×0.009
    • = 1.068 + 0.8544 + 0.06408 + 0.009612
    • 逐步相加：
      • 1.068 + 0.8544 = ‌1.9224‌
      • 0.06408 = ‌1.98648‌
      • 0.009612 ≈ ‌1.996092‌
    • 结果 ≈ ‌1.996‌
  • ‌方法三：直接竖式估算（推荐用于考试）‌
    • 忽略小数点，计算 ‌1068 × 1869‌
      • 但此法较繁，适合用计算器；若手算，可先估算数量级：
      • 1.068 ≈ 1.07，1.869 ≈ 1.87，乘积 ≈ ‌2.00‌（如方法一）
    • 小数位共 ‌3 + 3 = 6 位‌，故结果为 ‌1.996 左右

# 1.07 × 1.07

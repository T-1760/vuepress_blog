## 言语理解与表达
### 关键词 / 信号词 / 关联词 / 标志词
- 递进（重点：在后）
  > 口诀：递进强调后，程度更重。
  + **更、甚至、尤其、特别、况且**
  + **不仅...而且/也/还...**
  + **不但...还...**
- 并列（同等重要 / 前后近义）
  > 口诀：并列要全面，片面直接排。
  > **并列词内容不用看，只看前后一句**。
  >> **总起句**。并列内容A。并列词，并列内容B（,**总结句**）。
  + **同时、同样、还、也、和、与、及、以及、“;分号”、",逗号"、“、顿号”**
  + **而且、并且、此外、另外、再者**
  + **一方面...另一方面...、**
  + **首先...其次...最后...**
  + **既...又...**
  + 反义并列：
    * **相反、反之**
    * **不是...而是...**
    * **是...不是...**
    * **要...不能...**
    * **多一些...少一些...**
- 转折（重点：在后）
  > 口诀：转折一出，前面作废，答案在后
  + **但、但是、而、然而、反而、不过、却、唯有、可是**
  + **其实、实际上、事实上**
  + **虽然...但是...**
  + **尽管...但是...**
- 因果（重点：在结果）
  > 口诀：原因不重要，结论是答案
  + 结论标志词：
    1. **所以、因此、因而、故、故而、从而、却而、导致、造成、使得、结果是**
    2. **于是、可见、看来、由于、由此可见、总之、综上所述**
    3. **在这种情况下、可以说、换而言之**
  + **因为...所以...**
  + **由于...因此...**
  + **既然...就...**
- 条件（重点：在对策 / 做法）：
  > 口诀：条件是做法，做法多是答案。
  + **只要...就...**
  + **只有...才/方能...**（必要条件是重点）
  + **除非...否则...**
  + **无论...都...**
  + **如果...就...**
  + **假如...那么...**
  + **要是...就...**
- 总结 & 时空
  + 总结（常跟中心句）
    * **归根结底**
    * 表归纳总结：**总之、总而言之、综上所述、概括来说**
    * 表推论结论：**由此观之、由此可见、有鉴于此、可见、因此、正因如此、正因为、所以、故而、进而**
      > **据此认为、这些数据背后**（非典型总结词）
    * 表强调重申：**可以说、换言之、本质上、关键在于**
  + 时空
    * **当前、近年来、近段时间、这些年、这段时间**
    * **未来**
- 对策（答案高频区）
  > 口诀：对策最值钱，主旨优选它。
  + 正面提对策标志词
    > 例：“你需要好好学习，这样才能成功‘上岸’，走向人生巅峰。”
    * **为其、务必、建议**
    * **应、应该、应当、要、需要、必须**
    * **通过/采取...手段/途径/方式/方法/渠道，才能...**
    * **亟需、亟待、前提、基础、保障**
    * **负有...的义务、...的必由之路、...的法门之一、势在必行、要领在于...**
  + 反面提对策标志词
    > 例：“如果你不好好学习，就没法‘上岸’，只能谷底惆怅”
    * **如果/倘若/一旦...（做法），...（不好的结果）**
      > 前面的做法反过来，即对策
- 意义
  + **才能、从而、让**
- 解释说明
  + **即、就是、可谓、无异于、无疑是、“: 冒号”、"——破折号"**
  + **如、比如、例如**
- 少看/不看（可忽略紧跟的句子）
  + **比如、例如、...就是例证**
  + **数据资料、引入铺垫、多角度论述**
  + **即**
  + **而不是**
  + **通常 / 经常 / 一般 / 往往（来说/而言/认为/情况下）、自古以来**
- 指代词
  + **这、那、此、其**
- 概念性的关系
  1. 正向的推动作用（A↑ => B↑）
    + 推动类‌：**推动、促进、带动、助力、驱动、激发、强化**
    + 提升类‌：**提升、提高、增强、优化、升级**
  2. 负向的抑制/阻碍作用（A↑ => B↓）
    + 转折标志词‌（引出对立或否定）：‌**但是‌、‌然而‌、‌却‌、‌不过‌、‌可是‌、‌反而**
    + 负面因果词‌：‌**阻碍‌、‌制约‌、‌抑制‌、‌导致‌（负面语境）、‌造成‌（负面后果）**
    + 否定词+结果‌：‌**未能‌、‌未实现‌、‌未达到**
  3. 无关的关系（A 与 B 无关）
### 结构
  - 背景 → 成绩 → 意义 → 问题 → 危害 → 对策
    > 越靠后重要，即：**对策 > 问题 > 成绩**
    >> 对策类：目标分清、主体（名词）、客体（名词）、动作、筛除意义。
    + 常见结构
      1. 引出话题+【然而】提出问题 + 【所以】解决问题
      2. 话题引入+【重大课题】提出对策 + 解释说明
### 各题型技巧
- 答题顺序：片段阅读 → 语句表达 → 逻辑填空
- 通用提速铁律
  1. 一遍读题，不回读
    > **读题时直接圈重点，不反复看**。
  2. 不纠结！
    > **一题超过 45 秒直接选，不恋战**。
  3. 用排除法，不用确认法
    > 先排错，再对比，比 “找对” 快一倍。
#### 片段阅读
1. 先看问题，再看文段
  + 主旨/意图：**找中心句、首尾句、转折后**
  + 细节题：**圈关键词，直接回文定位，不通读**
2. 抓 “关键词” 秒定答案（答案基本在后面）
  > 口诀：转折后是重点，对策多是正确项
  + 转折、因果、对策、递进常见的关键词
3. 排除法（直接排除）
  + 绝对化：*一定、所有、全部、唯一、根本*
  + 无中生有、片面、偷换概念、过度推断
  + 只讲例子 / 背景 / 原因，没观点的
##### 中心理解题
  - 题型特征
    + 题干出现：**"主要 / 旨在 / 重在 / 意在 / 想要说明（论述、强调） / 主旨 / 主题 / 观点 / 概括"**
  - 对策（高频考点）
    + **解决问题的对策是重点**。
    + **正面提对策**和**反面提对策**，均可以提示文段的中心
    + 只有...才/方能...（必要条件是重点）
      > 变形（缺失”只有“）：**...才/方能...**
    + 文段结构：
      1. 有对策
        * 对策在开头：对策+解释说明
        * 对策在中间：提出问题+解决问题+解释说明（意义效果）
        * 对策在结尾：提出问题+分析问题+解决问题
      2. 无对策: 提出问题 + 分析问题（原因、危害等）
        * 选项中有针对性对策，能解决文段提出的问题。否则无意义（选项若是问题重述，果断排除）
        * 选项中无针对性对策（注：对策选项不万能），选择概括问题选项。
##### 标题填入题
  - 题型特征
    + 题干出现：“最适合做这段文字标题的是...”
##### 标题填入题
  > （选是选非）审题，因费时间，故多耐心+细心+精心（中心、细节不分家，警惕无中生有）
  - 题型特征
    + 题干出现：
      1. “以下对文段理解（正确/错误/不正确）的是...”
      2. “（不）符合这段话意思的是...”
      2. “上文（没有）提到了...”
      2. “这段文字（无法/可以）推出...”
  - 警惕题目选项陷阱
    1. 无中生有：文中没有，选项偏说有
    2. 偷换概念：替换、混搭
    3. 偷换逻辑：强加因果，因果倒置、并列偷换
    4. 与文意相悖
  - “正确 / 相符的”答题特征：优先选择**相对标志词**选项（“正相错绝”）
    + 可能、也许、或许、大概、一般、尽量、往往、容易、...之一
  - “错误 / 不相符的”答题特征：优先选择**绝对标志词**选项
    + 一定、全部、完全、所有、永远、均、任何、取代、主导、唯一、只要...，就... 、 无论...，都...
    + A 高于（优于）B；利大于弊；A 比 B 更...
  - “这段文字能够（无法/没有）解释下列哪一项.”，优先选择如下情况
    1. **为何**（为什么）
    2. **如何**（怎么做）
    3. **有何**、何种、从哪里来（是什么）
##### 语句理解题
  - 题型特征
    + 题干出现：“某某某”指的/含义/意思是...
  - 定位原文、结文理解
    + 词句出现“:”、“——”、“即”、“也就是说”等解释说明提示信息。
#### 逻辑填空
1. 先看语境，不直接背词
  + 找**解释、并列、相反、递进**
  + 看**感情色彩、程度轻重、搭配对象**
2. 一秒锁空技巧
  + 并列 / 近义：找**近义词**
  + 转折：找**反义词**
  + 有指代词 *“这、那、此”*：**答案在指代词前后**
3.  固定搭配秒选
  >不会就选最常用、最规范的。
  - 动词 + 名词（必背搭配）
    1. 政策 / 治理类
      + 加强**监管 / 建设 / 领导 / 宣传 / 力度**⭐
      + 强化**意识 / 责任 / 措施 / 管理**
      + 完善**制度 / 体系 / 机制 / 法律**⭐
      + 改善**生活、环境、条件、民生**⭐
      + 健全**法规 / 标准 / 体系**
      + 落实**政策 / 责任 / 任务 / 要求**
      + 执行**规定 / 命令 / 方案**
      + 推进**改革 / 发展 / 建设 / 工作**
      + 实施**战略 / 规划 / 项目 / 工程**
      + 统筹**发展 / 资源 / 城乡 / 全局**
      + 优化**环境 / 结构 / 服务 / 流程**
    2. 发展 / 经济类
      + 推动**发展 / 转型 / 升级 / 合作**
      + 促进**增长 / 交流 / 和谐 / 就业**
      + 激发**活力 / 动力 / 潜能 / 热情**
      + 释放**潜力 / 活力 / 红利**
      + 提升**效率 / 水平 / 质量 / 能力**⭐
      + 提高**素质 / 标准 / 收入 / 效率**⭐
      + 增强**实力 / 信心 / 竞争力**⭐
      + 实现**目标 / 突破 / 共赢 / 现代化**
      + 突破**瓶颈 / 局限 / 封锁**
      + 克服**困难 / 障碍 / 阻力**
      + 筑牢**根基 / 防线 / 屏障**
      + 破除**壁垒 / 障碍 / 谣言 / 迷信**
    3. 思想 / 文化类
      + 树立**理想 / 信念 / 形象 / 意识**
      + 坚定**信念 / 立场 / 信心**
      + 秉承**理念 / 原则 / 宗旨 / 传统**
      + 弘扬**精神 / 文化 / 美德**
      + 传承**文化 / 基因 / 技艺**
      + 凝聚**共识 / 力量 / 人心 / 合力 / 精神**
      + 营造**氛围 / 环境 / 风气**
      + 培育**人才 / 精神 / 价值观**
    4. 问题 / 解决类
      + 解决**问题 / 矛盾 / 难题**
      + 化解**矛盾 / 风险 / 危机**
      + 应对**挑战 / 危机 / 变化**
      + 防范**风险 / 隐患**
      + 遏制**蔓延 / 趋势 / 势头**
      + 扭转**局面 / 趋势**
      + 规避**风险 / 陷阱**
  - 形容词 + 名词（高频搭配）
    + 严峻**形势 / 挑战 / 考验**
    + 严格**要求 / 监管 / 遵守**
    + 严肃**处理 / 态度**
    + 深刻**认识 / 变革 / 影响**
    + 深厚**底蕴 / 感情 / 基础**
    + 迫切**需要 / 需求**
    + 宝贵**经验 / 财富 / 时间**
    + 广泛**关注 / 参与 / 影响**
    + 充分**发挥 / 体现 / 保障**
    + 有效**措施 / 途径 / 方法**
  - 副词 + 动词（常考）
    + 切实**加强 / 保障 / 减轻**
    + 逐步**完善 / 推进 / 提高**
    + 大力**支持 / 发展 / 弘扬**
    + 积极**参与 / 推进 / 探索**
    + 主动**作为 / 服务 / 对接**
    + 深入**贯彻 / 研究 / 推进**
    + 陷入**困境 / 沉思 / 低谷 / 僵局 / 危机 / 误区**
    + 广泛**征求 / 宣传 / 开展**    
#### 语句表达
##### 语句排序题
  + 先看首句：下定义、背景 → 适合首句
    > 下定义：...就是/是指
  + 指代词、关联词后半段→不做首句
    > 指代词：这、那、他、其、该、此、这些、他们等
  + 找捆绑：话题一致、指代词、关联词
  + 尾句特征
    1. 因此、所以、看来、这...（引导的总结性尾句）
    2. 对策
  + 常见逻辑顺序
    1. 观点 + 解释说明
    2. 提问 + 回答
    3. 问题 + 对策
    4. 时间顺序、行动顺序等
##### 语句填空题
  - 题型特征
    + 题干出现：“填入画横线部分最恰当的一（句/项）是”
  - 横线（话题一致）
    + 分句：注重句内衔接
    + 整句：注重句子间的关联
  - 开头：总起全文、话题引入、概括侯文
  - 中间：承上启下
  - 结尾：总结全文、提出对策
### 底层逻辑-写作模型
> **阅读——对作者意图的反推**
- 误解：无差别的精读分析（35题？35分钟，1 题 1分钟）**先快后对**
  > **不要过度强调理解的精准性**
  1. 对结构未做判定
  2. 对句意未做收敛本质的概
- 言语 & 申论的步骤
  1. 结构（三线法则）：直线**递进**、分线**并列**、折现**转折**
    + 直线递进：**观点前后统一、中心常重在头或尾**
    + 分线并列：**概括**多分（支平行）线的（共性观）点保持一致性、兼容性，否则片面
    + 折现转折：**重点转折词后**，前面不看/少看
  2. 概括：抓住**核心理念**，理解**概念间关系**
    + 概念性的关系
      1. 正向的推动作用（A↑ => B↑）
      2. 负向的抑制/阻碍作用（A↑ => B↓）
      3. 无关的关系（A 与 B 无关）
#### 1. 基本语法（主谓宾定状补）
#### 2. 关联词（递进、并列、转折、总结）
> 总结：对中心句的引词 （优先级：总结词 > 转折词）
#### 3. 修辞手法（对偶、排比、双关、比喻、拟人）
#### 4. 中心主旨对全文的约束作用（核心观点，作者立场）
  > 作者立场：支持（褒义词多）/反对（贬义词多）/中立客观（规范词多）
  >> 观点词：**认为、强调、指出、表明**
#### 5. 结构的衔接性⭐⭐⭐
> 必要性：通过正反两个方面去论证的
- 顺序：背景——成绩——意义——问题——危害——对策——必要性（重要性依次递增）
  + 对策与必要性的优先级
    1. 行为已完成：解释（必要性）重要
        > 例：我昨天睡了4个小时，因为家人昨天生病住院了（重要）。
    1. 行为未发生：对策重要
        > 例：我每天要按时睡觉（重要），因为我需要好好学习，不然印象学习效率。
#### 6. 论证方式：说理论证、举例论证、数据论证
    + 数据论证：常考于排序捆绑，数据前面紧挨着一定是一个观点（此观点与数据本身构成了捆绑）
### 各题型板块和写作模型的关系
#### 逻辑填空
  - 基本语法（搭配问题）
  - 关联词（反义、近义）
  - 修辞手法
  - 中心主旨对全文的约束作用⭐
#### 中心主旨（标题）
  - 关联词
  - 中心主旨对全文的约束作用
  - 结构的衔接性
#### 细节判断
  - 基础语法（主谓宾）
      + 是否对主语、宾语做范围扩大缩小，偷换概念
      + 谓语：表达主语、宾语之间的关系（正向推进、反向阻碍、无关系）作用
#### 语句填入
  - 结构的衔接性
    + （背景——成绩——意义——问题——危害——对策——必要性）抽扣出一句话，对其进行（注意**承上启下**）衔接
#### 语句排序（重点：捆绑）
  - 关联词
  - 修辞手法
  - 结构的衔接性
### 中心主旨五原则
- 优先级：中心句原则 > 概念原则 > 关联词原则 > 结论原则 > 时空原则
#### 1. 中心句原则
  + 设问句：问题的答案（即：中心）
    > 多个问题，后面问题比前面问题重要（时空原则）
  + 总结句：“因此//从根本上讲”
#### 2. 概念原则
  + 主题词必存在，话题词最好存在
  + 主题词的概念（偷换、扩大、缩小）变动
#### 3. 关联词原则
  + 总结词 > 转折词
#### 4. 结构原则
  + 背景 → 成绩 → 意义 → 问题 → 危害 → 对策（越靠后重要，即：对策 > 问题 > 成绩）
#### 5. 时空原则
  + 优先级：现在 > 过去; 国内 > 国外; 段后 > 段前

# 一、图形推理

  • 图形元素组成
    • 相同，考查位置规律
    • 相似，考查样式规律
    • 不同，考查*（属性 / 数量 / 其他特殊）*规律
  • 常规思路看不出时，可全局视角，相邻两个图之间的规律

# 1、位置规律

  • 特性特征：元素组成相同

# 1.1、平移

  • 方向

    宫格题内圈元素：

    相同时，优先考虑（顺/逆）时针 不同时，考虑直线平移

    • 直线：上下左右、斜对角
    • 圆圈：顺时针、逆时针
  • 步数
    • 恒定
    • 递增 / 递减

# 1.2、旋转 & 翻转

  • 旋转
    • 方向：顺时针、逆时针
    • 角度：30°、45°、60°、90°、180°等角度
  • 翻转
    • 对称轴：某条直线为
    • （顺/逆）时针法：相同图形内部元素之间的方向

      同一起点、同一路径、同一终点

# 2、样式规律

  • 特性特征：元素组成相似

# 2.1、加减同异

  • 相加：两幅图（线条/元素）拼合成一幅新图
  • 相减：两幅图相同（线条/元素）抵消后成一幅新图
  • 求同：两幅图相同位置（线条/元素）保留后成一幅新图
  • 求异：两幅图相同位置（线条/元素）不保留后成一幅新图

# 2.2、黑白运算

  • 图形间轮廓相同，但内在颜色或图案不同
    • 各图黑块数量
      • 相同：优先位置规律
      • 不同：优先黑白运算

        如：黑 + 黑 = 黑/白、白 + 白 = 黑/白、 黑 + 白 = 黑/白、 白 + 黑 = 黑/白

# 2.3、遍历

  • 元素，缺啥补啥，保持次数和位置相同

# 3、属性规律 & 数量规律 & 其他特殊规律

常在分组分类题考查

  • 特性特征：元素组成不同、不相似

# 3.1、属性规律

三种属性规律：对称、曲直、开闭

  • 对称性
    • 类型
      1. 轴对称：有 1或多条对称轴 的图形。

        如：字母 A、C、Y

      2. 中心对称：自身旋转 180° 后仍与自身相同 的图形。

        如：字母 N、S、Z

      3. 既轴又中心对称：具有 2 条相互垂直的对称轴的图形

        如：字母 H、X

    • 细化结合结合扩展考查（当选项图形都是对称图形时）
      1. 对称轴数量、方向
      2. 对称轴与自身图形中点、线、面的关系
      3. 拼合多个图形的对称轴之间的关系（如：平行、垂直、相交）
  • 曲直性

    出现圆、弧等曲线的图形

    1. 曲：只由曲线构成的图形
    2. 直：只由直线构成的图形
    3. 曲 + 直：由曲线和直线构成的图形
  • 开闭性

    出现生活化、粗线条的图形

    1. 开放：不包含封闭空间的图形（露出点的线条）

      如：字母 C、F

    2. 开放：仅包含封闭空间的图形

      如：字母 B、D

    3. 半开半闭：既包含开放又包含封闭的图形

      如：字母 A、R

# 3.2、数量规律

特征：图形元素组成不同、且无明显属性规律

五点数量规律：点、线、面、素、角

  • 点
    • （曲、直）线条的交点、切点数量

      数量较多时，结合扩展考查：交点、切点、曲直交点、框（内/上/外）交点

  • 线
    • 直线 & 曲线
      • 数直线：单一直线或多边形图
      • 数曲线：圆、弧的曲线图
      • 结合扩展考查：
        1. 曲直线 加减运算结果规律;
        2. 横竖线 加减运算结果规律;
        3. 外框封闭图内部线交点干扰，数外框线;
        4. 平行线条：相同形状的三角形叠加时
    • 数笔画

      连通图的笔画数 = 奇点数 ➗ 2

      奇点：若以一点为起点，延伸出的线条数为奇数，则该点为奇点。反之线条数为偶数，则该点为偶点 奇点包括端点（1 条线）

      • 一笔画：奇点数为 0 或 2 （奇点数 ➗ 2 = 0 或 1）

        多笔画：奇点数 > 2，(奇点数 ➗ 2 = N 笔画)

      • 题型特征：
        1. 日（变形图）、田（变形图）、圆（相交/想切）、五角星、（多）端点。
        2. 当多幅图中包含多端点，且并非考查点数量规律时，优先考虑笔画数
  • 面
    • 特征：图形明显分割，封闭区域明显，生活化，粗线条图形且有明显留白区域时
    • 考查
      1. 所有面的数量 / 形状
      2. 相同面的数量 / 形状
      3. 最大面 / 最小面 的 形状 / 属性 / 外框的关系
  • 素

    即元素，细分为三种情况：个数、种类数、部分数*（连在一起算作一部分）

    • 优先考查：
      1. 个数 & 种类数：多个独立的小元素构成
        • 黑白块/球：线条穿越的元素个数。
        • 黑白块/球：线条穿越的元素分割图规律。
      2. 部分数：生活化图形（LOGO）、黑色粗线条图形
    • 结合扩展考查：
      • 加减运算结果规律：无数量规律时，可进一步，对不同种类的个数运算;
      • 元素换算：公式：第一幅图 + 第三幅图 = 2 倍的第二幅图
  • 角

    图形内部包含的（0° - 180°）角，锐角、直角、钝角

    • 特征：图形出现扇形、改造图（图形不完整、缺角、漏角、遮盖角）、折线图、多个直角（包含 ＋、T 的图形）、

# 3.3、特殊规律

特征

优先功能元素：每幅图出现点、箭头等小元素时 优先图形间关系：每幅图出现两个或多个封闭图形连在一起时

  • 功能元素

    功能元素：黑点、小白圆、箭头等，常用于标记（角、线、面）位置。

    角：最大、最小、发射线个数 线：最长、最短、 面：重合、独立

  • 图形间关系
    • 外离：图形间无公共部分
    • 相交：图形间有公共部分
      1. 相较于点（“一线牵”也算、链式/放射式）
      2. 相较于边（条数、长/短、曲/直、整体/部分）
      3. 相较于面（形状、面积大小、属性）

# 4、高频特征图——黑白块 10种考法

  1. 平移、相邻比较
  2. 黑白运算
  3. 黑白块对称性
  4. 黑白块个数：黑、白数量有规律
  5. 黑白块部分数：黑、白明显“分堆”
  6. 黑白块笔画数：黑、白明显连线
  7. 黑白块面积：大面积黑、白，分割相对规整
  8. 黑白块形状的种类数：黑、白形状丰富
  9. 黑白块图形间关系：黑块、白块（外离\相交于点线面）
  10. 黑白块连线间关系：分别出现两个黑、白块

# 5、空间类

  • 空间重构（六面体）

    向内翻折、常用排除法

    • 相对面
      1. 同行或同列间隔一个面
    1. Z字形两端（紧邻 Z 字中线的面，非紧靠不是）
    • 相邻面
      • （两面）公共边
        1. 构成直角两边（是同一条边）
        2. 一（列/行）连着 4 个面，两端的两边（是同一条边）
        3. （3 + 1 =）4 面构成“L”形，同方向的两边（是同一条边）
      • （三面）公共点
    • 画线法

      万能大法：同一面、同一起点、同一方向

      • 找一个特殊面，定一个唯一点，顺/逆时针描边标（1234）号，结合选项排除
  • 立体拼合（残缺立体）

    原则：凹凸一致

  • 立体截面图
    • 弧线截面：立体存在曲面
    • 标准六面体的三角形截面：无直角
  • 三视图
    • 主视、俯视、左视图
  • 多面体折叠

    向内翻折、常用排除法

    • 底面边数 = 侧面面数
    • 拼合的相邻边等长

# 二、定义判断

要领：看清提问、抓准信息、比较选项

看清提问：属于 / 不属于、聚焦提问的定义（多个定义） 抓准信息：抓住定义有效信息（重点词句标记），避免全读、来回重复读 比较选项：题干较难懂 / 选项纠结，择优比较：必然符合、可能符合、必然不符合

# 2.1、读的准

迅速定位有效信息，略读 / 跳读无效信息。

有效信息（画圈标记）四类高频经典关键词：1、主客体，大前提；2、方式 + 目的；3、原因 + 结果；4、修饰词

# 1、主客体，大前提

主客体间有明确的范围界定时，可结合选项，择劣排除。 存在大前提的引导词且描述内容具体明确时画圈（可能就此设考点），可结合选项，择劣排除。

  • 主体：一个动作 / 事件的发起者 / 执行者。
  • 客体：一个动作 / 行为指向的对象。
  • 大前提：定义中特别限定的一些必不可少的条件。
    • 引导词：”当...时“、”在...（过程）中“、**”...后“**等

# 2、方式 + 目的

  • 方式引导词
    • 以（按照 / 通过 / 采用 / 利用 / 依据）...的（方式 / 方法 / 办法 / 手段）等
  • 目的引导词
    • 以...的（目的 / 目标），（达到 / 实现）...的（目的 / 目标 / 结果 / 效果）、为了... 等

# 3、原因 + 结果

  • 原因引导词
    • 因为、由于等
  • 结果引导词
    • 所以、因而、因此、带来、引发、导致、使得等结论词汇

# 4、修饰词

  • 以 “的” 引导词
  • 重点关注定义中数量、相同 / 不同、主动 / 被动、新的 / 旧的

# 2.2、读得快

# 阅读方法

  1. 定义所在句优先看
    • 若定义句能够清晰表述含义，其他文段略读；若纠结选项时，才回看其他内容
  2. 补充说明重点看

    定义句隐晦难懂、纸箱不明时，紧跟补充标志词重点看

    • 补充说明内容标志词
      1. 即、也就是说、意思是、包括
      2. 具体表现、分类说明
      3. *（）括号、——破折号、：冒号
  3. 多个定义问谁看谁，纠结再找差别

# 三、类比推理

  • 题型
    • A : B
    • A : B : C
    • A 对于 （） 相当于 （） 对于 B
  • 词语间的关系
    1. 语义关系
    2. 逻辑关系
    3. 语法关系

# 3.1、语义关系

  • 近义关系

    常考成语、多积累

  • 反义关系

    常考成语、多积累

  • 比喻义象征义
    • 借助某物的形象。以表现某种抽象的概念、思想、情感。

      例：玫瑰：爱情。

# 3.2、逻辑关系

常识积累

  • 全同关系
    • 词语间表达含义完全相同的关系。

      例：土豆：马铃薯、番茄：西红柿、湖北：鄂

  • 并列关系
    • 词语间概念处于同一个级别上，用义彼此不包含的关系

      例：苹果：西瓜、狮子：老虎

      1. 矛盾关系：非 A 即 B，没有第三种情况。

        例：男：女、生：死、曲：直、开：关、动：静

      2. 反对关系：除了 A 和 B，还有第三种情况。

        例：黑色：白色（红色、绿色、黄色...）

  • 包容关系
    • 词语间概念上一个范围小，一个范围大，大完全包含小的关系

      例：国家：省份、班级：学生、男人：人 技巧：“是”造句，区分 种属和组成

      1. 种属关系：A 是 B 的一种。

        例：乐器：吉他（吉他是乐器）

      2. 组成关系：A 是 B 的一部分。

        例：琴弦：吉他

  • 交叉关系

    技巧：”有的“造句

    • 词语间概念上有重叠的地方，但不重合的关系

      既有的 A 是 B，有的 A 不是 B，又有的 B 是 A，有的 B 不是 A

      青年和演员 有的青年是演员，有的青年不是演员 有的演员是青年，有的演员不是青年

    • 注意：并列是概念间没有重叠，交叉是概念间有部分重叠
  • 对应关系
    • 一定范围事件包含的各词语要素之间构成的相互（包含：原材料、工艺、功能、属性、时序、因果、方式目的等多重）对应。
    1. 原材料、工艺、成品

      例：黄桃：罐头、玉石：打磨：手镯

    2. 功能

      例：手机：点餐、汽车：运输

    3. 属性

      例：酒精：挥发性、山楂：酸

    4. 时序

      例：起飞：着陆、考试：阅卷

    5. 因果

      例：淋雨：感冒、信息泄露：财产损失

    6. 方式目的

      例：扶贫：脱贫、贴窗花：迎新年

# 3.3、语法关系

语法关系：主谓、动宾、主宾、偏正关系

  • 主谓关系
    • 词语间一个（主语）名词在句前、一个（谓语）动词在句后

      例：学生：练习

  • 动宾关系
    • 词语间一个动词在句前、一个（宾语）名词在句后

      例：消除：矛盾

  • 主宾关系
    • 词语间两个都是名词（分别为对应主语和客语），通过一个动词连接造句

      例：士兵：敌情

      学徒：技术（学徒学习技术） 学生：知识（学生学习知识）

  • 偏正关系

    由“的 / 地”连接。

    • 词语间一个是修饰词、一个是被修饰词，常由“的 / 地”连接。

      例：勤劳：工人、激烈：竞争

    • 结构
      1. 形容词 + 名词

        例：美丽：人

      2. 副词 + 名词

        例：快速：走

# 四、逻辑判断

七类题型：翻译推理、削弱题型、加强题型、组合排列、真假推理、原因解释（国省少考，粤常考）、日常结论（选考）。

# 1、翻译推理 ⭐⭐⭐⭐⭐

  • 题型特征
    • “可以 / 无法推出”

# 常规翻译

先翻译，后推理

  • 翻译规则
    1. 前 -> 后（关联词）
      • 如果 / 假如 / 一旦 / 若...，那么 / 就...
      • 只要...，就...

        例：只要功夫深、铁杵磨成针 => 功夫深 -> 铁杵磨成针

      • 所有 / 凡是 / 任何 / 每个...，都...

        例：凡是有生活的地方就会有幸福。=> 生活 -> 幸福

      • ...是...的充分条件
      • ...就 / 则 / 都 / 一定...

        例：有付出就会有回报 => 付出 -> 回报

    2. 后 -> 前

      必要条件放在 -> 箭头后

      • 只有...，才...

        例：只有认真学习，才会有好的成绩。=> 好成绩 -> 认真学习

      • 不...，不...

        例：不到长城非好汉 => 好汉 -> 到长城

      • ...才...
      • 除非...，否则不...

        例：除非认识错误，否则不能改正错误 => 改正错误 -> 认识错误

      • ...是...的必要条件 / 先决条件 / 基础 / 前提 / 必不可少的条件

        例：良法是善治之前提。=> 善治 -> 良法

  • 推理规则
    1. 逆否等价

      肯前必肯后，否后必否前。否前、肯后不必然

      • ① -> ② => -② -> -①

        例：北京人一定是中国人 （=> 北京人 —> 中国人）以下哪句成立？

        [ × ] 中国人一定都是北京人（=> 中国人 -> 北京人） [ × ] 不是北京人一定不是中国人（=> -北京人 -> -中国人） [ ✓ ] 不是中国人一定不是北京人 （=> -中国人 -> -北京人）

    2. 传递规则

      两条件相同位置元素，无法传递推理

      • ① -> ②，② -> ③ => ① -> ③

      例：凡是北京人都是中国人，只要是中国人就有身份证

      北京人 -> 中国人，中国人 -> 有身份证 => 北京人 -> 有身份证

  • 翻译注意点
    1. 必要条件：谁必不可少，谁在箭头后
    2. 除非...否则...：否后推前

      ..., 除非... = 除非...否则...

      例：航班延误 4 个小时需要赔付给乘客，除非有不可抗力的因素出现 => 除非有不可抗力的因素出现，否则航班延误 4 个小时需要赔付给乘客 -延误 4 个小时需要赔付给乘客 -> 有不可抗力的因素出现

      • 除非...否则不...：后推前
  • 且、或关系
    • 且关系：表示由“和”连接的所有对象均成立（都必为真）
      • 关联词
        1. 并列关系：并且 / 且 / 和 / 都 / 既...又...
        2. 递进关系：甚至 / 而且 / 还...
        3. 转折关系：但是 / 然而 / 却...
        4. 标点：“,逗号”、“、顿号”、“; 分号”
      • 推理规则： ① 且 ② -> ①，① 且 ② -> ②

        小明聪明且有耐心 => 小明聪明, 小明聪明且有耐心=> 小明有耐心

    • 或关系：表示由“或”连接的所有对象至少有一个成立（必有一个真）
      • 关联词
        1. ...或（者）...
        2. 或者...或者...
        3. ...和...至少（多）有一个
      • 推理规则：
        1. 否一推一：当 ① 或 ② 成立时 => -① -> ②，-② -> ①
        2. ① 和 ② 至少（多）有一个 => -① 或 -②
        3. 二选一：要么...①，要么...② => -① => ②，-② => ①，① => -②，② => -①
        4. 德·摩根定理：
          1. -（① 且 ②）= -① 或 -②
          2. -（① 或 ②）= -① 且 -②

# 集合翻译

# “所有 / 全部”
  • 翻译规则：前推后
  • 关键词
    • 所有 / 全部 / 任何 / 凡是
    • ...都...
  • 推理规则：逆否等价

    例：所有 ① 都是 ② => ① -> ② 逆否等价 -② -> -① 例：所有 ① 都不是 ② => ① -> -② 逆否等价 ② -> -①

# “有的”
  • 表示至少有一个

    3种可能性：1、只一个满足 2、有一部分满足 3、全部满足

    “中国有的人很勤奋” => 1、中国只有一个人很勤奋 2、中国有一部分人很勤奋 3、中国全部的人都是很勤奋

  • 关键词
    • 有 / 有些 / 一些 / 某些
    • 有一些...
  • 翻译规则

    “有的”必放在“->”箭头前

    1. 有的 ① 是 ② => ① -> ②

      肯定等价交换：② -> ①

    2. 有的 ① 不是 ② => ① -> -②

      否定不可等价： ① 无法推出 -①

  • 推理规则
    1. 不适逆否等价：”有的/可能“ 不适用 逆否等价

      “有的 ① 是 ②” 无法推出 “有的 ① 不是 ②” “有的 ① 不是 ②” 无法推出 “有的 ② 不是 ①”

      “可能” 无法推出 “可能不” “可能不” 无法推出 “可能”

    2. （肯定）交换等价：有的 ① 是 ② = 有的 ② 是 ①

      例：有的马是动物，有的动物是马

    3. 所有的 ① 都是 ② => 有的 ① 是 ②，有的 ② 是 ①

      所有的马是动物，有的马是动物，有的动物是马

# “并非”
  • 表示否定后面所有内容

    例：并非明天会下雨 => -明天会下雨 -> 明天不会下雨

  • 关键词
    • 并非
    • 否
    • 不
    • ...是错的
  • 推理规则

    ”并非“出现，后全部否定，谓语动词最后否

    • !”必然/一定“ -> ”可能“ （“不必然” = “未必”）

      例：明天未必地震/明天不必然地震/明天不一定地震 = 明天可能不地震

      “不”出现，必然 -> 可能，地震（谓语动词） -> 不地震

    • ”所有“、”有的“互反
      • !”有的“ -> ”所有“

      例：并非有的火山不处在活动期 = 所有火山都处在活动期

      “并非”出现，有的 -> 所有，不处在（谓语动词） -> 处在

      • !”所有“ -> ”有的“

      例：并非所有人都是公务员 = 有的人不是公务员

      “并非”出现，所有 -> 有的，都（即：“所有”） -> 有的，是 -> 不是

    • ”且“、”或“互反
      • !”且“ -> ”或“
      • !”或“ -> ”且“

      例：并非他不懂物理又不懂化学 = 他懂物理或懂化学

      “并非”出现，又（即：且） -> 或，不懂（谓语动词） -> 懂 德·摩根定律：-（① 或 ②）= -① 且 -②

# 推理形式

  • 题型特征
    • “与题干 逻辑结构/ 推理结构 / 推理形式 / 论证机构 / 逻辑错误 最为相似”
  • 解题思路
    • 前提逻辑一致，句式相同最优选。适当忽略推理是否正确，只考虑题干保持一致。

# 2、论证综述

  • 论证三要素：
    • 论证：用论据来证明论点的逻辑过程和方式

      论据：真实的、合乎常理的理由 论点：某个论断的真实性或虚假性

    1. 论点
    2. 论据
    3. 论点与论据之间的联系

    例：“我家孩子是有艺术天赋的，既能唱又能跳，还会画画呢！”

    论点：“我家孩子有艺术天赋” 论据：“既能唱又能跳，还会画画呢！” 关系：“唱、跳、画画” 与 “有艺术天赋” 两者具备相关性（而无相关性 “因为地球是圆的，所以孩子有艺术天赋”）

  • 论证阅读技巧

    可略读：背景介绍、下定义

    背景介绍、下定义一般与论点成立（论据也）无关，建议略读（后期不理解，再返回阅读）

    背景介绍：随着 / 目前 / 近年来...、在...形势/背景下 下定义：...是指...

    1. 论点定位
      • 典型提示词
        • 因此 / 表明 / 认为 / 显然 / 意味着 / 显示出 / 由此可知 / 由此推出 / 我们相信 / 得出结论
      • 常见位置
        • 首尾句
        • 若文段结构先给出一个事实，再去探寻此事实产生的原因（此原因 = 论点）

          例：在一次考古发掘中，考古人员在一座唐代古墓中发现多片先秦时期的陶片。对此，专家解释说，由于雨水冲刷等原因，这些先秦陶片后来被冲至唐代的墓穴中。

          结构：先给出事实（先秦时期的陶片在唐代古墓中），再解释该事实的原因（雨水冲刷等） 论据：无

    2. 论据定位
      • 典型提示词
        • 因为
      • 常见位置
        • 数据、举例等内容一般作为论据出现
  • 加强 和 削弱
    • 论证若成立，需满足
      1. 论点和论据具备真实性
      2. 论点和论据之间存在联系

        联系越紧密、越直接，论证成立概率越大

    • 加强论证：支持整个论证的成立
      1. 证明论点 或 论据的真实性
      2. 强化论点或论据之间的联系
    • 削弱论证：破坏整个论证的成立
      1. 指出论点 或 论据的错误
      2. 弱化论点或论据之间的联系
    • 案例：粉笔的老师们爱教研，因此，粉笔的老师们一定都很漂亮

      论点：粉笔的老师们漂亮 论据：粉笔的老师们爱教研

      • A、某位粉笔老师长相比较普通，并不出众。

        【属于削弱】：用一个反例来指出论点的错误。

      • B、粉笔平均每天会进行 5 场教研会，每场时长为 2 小时。

        【属于加强】：用具体数据来 证明论据的真实性。

      • C、很漂亮和爱教研根本就是两码事。

        【属于削弱】：否定论点和论据之间的联系。

      • D、教研的人体内会差生一种激素，而这种激素对美容有极大帮助。

        【属于加强】：解释证明了论据（“爱教研”）和论点（“很漂亮”）之间的联系之间的内在联系。

      • E、有些粉笔的老师们喜欢旅行，经常外出旅游。

        【无关项，非加强非削弱】：“喜欢旅行，常旅游”与论点（“很漂亮”）、论据（“爱教研”）均无关。

      • F、目前还没有数据能够证明粉笔老师爱教研。

        【不明确项，非加强非削弱】：具有迷惑性，“无法证明老师爱教研” 无法推出 "老师不爱教研"

        在 逻辑学中被称为“诉诸无知”。（**“无法证明”、“不能确认”**等属于典型的不明确选项。）

# （加强 / 削弱）选非题

  • 题干出现 “不能加强 / 支持 / 假设 / 前提” 时，优选削弱项 > 其次无关项

    故此，只需找出三个加强项，剩下则为不能加强项

  • 题干出现 “不能削弱 / 质疑 / 反驳 / 否定” 时：优选加强项 > 其次无关项

    故此，只需找出三个削弱项，剩下则为不能削弱项

# 3、削弱题型 ⭐⭐⭐⭐⭐

  • 题型特征：
    • 题干 “削弱 / 质疑 / 反驳 / 否定” 关键词
    • 对比择优
      • 削弱论点 / 拆桥 > 削弱论据
      • 因果倒置 > 他因削弱
    • 常见设错/干扰项：无关项、不明确项
  • 削弱论点（削弱度⭐⭐⭐）
    • 必然性削弱 > 可能性削弱
  • 拆桥（削弱度⭐⭐⭐）

    拆桥涉及论点和论据，故比削弱强于单纯削弱论据

    • 破坏论点和论据之间的关系。
    1. 论点和论据中出现两个不明显相关的概念。（论点与论据话题不一致时，指出二者不相关）

      例：粉笔老师爱教研，因此粉笔老师很漂亮。

      【拆桥削弱】：“爱教研和很漂亮是两码事。”

    2. 论点和论据中分别出现了一个整体的概念和一个部分的概念。（部分不能代表整体, “整体”强于“部分”）

      例：粉笔张老师长相普通，因此粉笔老师的颜值都不高。

      【拆桥削弱】：“张老师的颜值并不能代表粉笔老师的整体颜值。”

    3. 论据是调查或实验数据，（调查或实验数据不具有代表性）
      • 当论点关于比例，论据只涉及论点中比例分子（或分母）时，优先考虑补充分母（或分子）来进行拆桥削弱（或搭桥加强）
  • 削弱论据（削弱度⭐）

    例：喝酸奶可以促进肠胃消化，所以建议大家多喝酸奶。

    论点：建议大家多喝酸奶。 论据：喝酸奶可以促进肠胃消化。

    • 两种形式
      1. 论据有错误

        酸奶并不具有促进肠胃消化的作用。

      2. 论据无用（削弱论据可行性）

        酸奶很难被人体吸收。

    • 应用场景
      • 题干出现支持方、反对方所述关系相反时
      • 题干找不到削弱论点和拆桥项, 且存在论据时
  • 削弱因果论证：因果倒置（削弱度⭐⭐⭐）、 他因削弱（削弱度⭐）
    • 题干特征
      1. 论点包含因果关系。
      2. 论据到提出论点的论证过程隐含因果关系。
      3. 常见句式
        • ...（不）是...的原因 / 因素
        • ...导致 / 使得 / 造成...
        • ...有助于...
        • ...有效增加（减少）...
    • 因果倒置：原因和结果顺序颠倒。（本质削弱论点）

      例：技术缺陷导致产生部分残次品。

      【因果倒置】：“部分残次品的产生导致了技术缺陷”。

    • 他因削弱：选项新原因 必须与 题干旧原因“同时存在”才能起到他因削弱作用。反之，则为无关项

      “同时存在”：新原因和旧原因形成了合力。（新原因选项削弱的是题干旧原因的唯一性和重要性。） 例：多饮用含咖啡因的饮料的人，会导致身体健康状况远不如那些不饮用咖啡因的人。

      【他因削弱】：“常饮用含咖啡因的饮料的人有暴饮暴食的习惯” （新原因“暴饮暴食” 削弱了 旧原因“多饮咖啡因饮料”） 【无关项】：“久坐也会影响人的身体健康状况” (未能体现“多饮含咖啡因饮料的人也久坐了”)

# 4、加强题型 ⭐⭐⭐⭐⭐

  • 题型特征：

    • 题干 “加强 / 支持 / 假设 / 前提” 关键词
    • 对比择优
      • 搭桥 = 必要条件 > 解释原因 > 举例
    • 常见设错/干扰项：无关项、不明确项

  • 搭桥（加强度⭐⭐⭐）

    加强论点（力度并不强）：1、重复论点（拍马屁）2、举例加强（除非枚举，否则均为个例）

    • 建立（强化）论点和论据之间的关系。
    • ⚡秒题技巧：同时出现论点和论据中不同概念的选项
    1. 论点和论据中出现两个不明显相关的概念。（论点与论据话题不一致时，指出二者相关）

      例：粉笔老师爱教研，因此粉笔老师很漂亮。

      【搭桥加强】：“教研可以让人变漂亮。”

    2. 论点和论据中分别出现了一个整体的概念和一个部分的概念。（部分能代表整体）

      例：中国经济发展势头良好，因此全球经济一片繁荣。

      【搭桥加强】：“中国经济是全球经济的晴雨表。”

    3. 当提问方式是前提、假设、必要条件、加强论证时，常考查搭桥加强
    • 搭桥特殊场景：出现多个逻辑关联词。（先翻译，在根据逻辑关系搭桥）
      1. 论据 ① -> ②，（则搭桥 ② -> ③），论点 ① -> ③

        例：小刘是学生会成员，因此他是三年级学生。

        论据：①小刘 -> ②学生会 论点：①小刘 -> ③三年级 论点和论据不一致【搭桥加强】：“选入学生会的学生都是三年级学生。”（②学生会 -> ③三年级）

      2. 论据 ① -> ②，（则搭桥 ③ -> ①），论点 ③ -> ②

        例：凡是热爱读书的人，都更容易取得成功。因此，只要掌握迎战未来的关键能力，就会更容易取得成功。

        论据：①热爱读书 -> ②成功 论点：③关键能力 -> ②成功 论点和论据不一致【搭桥加强】：“掌握关键能力的人都热爱读书。”（③关键能力 -> ①热爱读书）

  • 必要条件（加强度⭐⭐）

    没它不行：如果这个条件不成立，那么结论也一定不成立。（搭桥是最典型的必要条件）

    • 题型特征：
      • 提问方式 **“加强 / 假设 / 必要条件 / 加强论证”**关键词时
      1. 优先搭桥
      2. 若无搭桥选项，考虑“论点或论据可实现，可被利用”意思的选项

        例：喝酸奶有助于肠胃消化，故建议大家多喝酸奶。

        想论证成立，“酸奶能被身体吸收”就属于“建议大家多喝酸奶”的必要条件。 【必要条件】：“酸奶能被身体吸收” （说明喝酸奶是可行且有效的）

      3. 若论据为两组对立实验，则必要条件为两组实验对象“起点一致”（即：两组实验只能有唯一的不同点或相同点）。

        例：两组实验，第一组允许午休 1 小时，第二组不允许午休。最后发现第一组比第二组考试成绩高。由此可见，午休能提高学习成绩。

        除开是否午休因素外，若两组还有其他因素区别（第一组有复习，第二组没有复习），则其他因素（是否复习）也会影响实验结果，属于他因削弱。 【必要条件】除午休外，两组同学的其他基本情况都相同。（起点一致）

      4. 若论点是比例，论据只涉及其中一项，那么需要补充另一项。

        例：火车事故多发生在南部地区，因此在北部地区坐火车更安全。

        事故率 = 事故量 / 运营量。若事故量南部 100起、北部 60起。运营量南部 1000起、北部 300起。则存在事故率 “南部 < 北部”可能。而论点：事故率“南部 > 北部” 【必要条件】：“北部的火车运营量比南部多得多。”（补充了分母“运营量”）

  • 补充论据（加强度⭐）

    题干中只有论点或论点和论据话题一致时（优先考虑补充论据）。

    • 两种形式
      1. 解释原因：解释论点成立的原因。
      2. 举例：举例子证明论点成立。
    • 特殊场景
      • 论据中有因有果时，加强方式为
        1. 解释因果关系成立原因
        2. 对比举例：无因无果

# 5、组合排列 ⭐⭐⭐⭐⭐

  • 题型特征
    • 题干给出一组对象（甲、乙、丙等）和相关信息（年龄、身高、体重等），要求把对象和信息进行匹配。
  • 解题方法
    • 排除法、代入法
      • 排除法：有已知条件。
        1. 题干条件确定，根据这些条件能够直接排除选项
      • 代入法：选择条件。
        1. 题干条件不确定（真假未知）或 提问方式为“可能 / 不可能 / 补充哪项可得出某结论”时
    • 推理起点：确定信息、最大信息法、假设法
    • 辅助解题工具：列表、符号（＞、＜、＝等）
      • ⚡秒题技巧：每人各说一句带有两个定义的话，提问每句只对一半定义，则只需找未重复的那个定义为真（唯一为真）。
    • 材料题（国、执法、苏、沪常考）

# 6、真假推理

  • 题型特征
    • 题干出现多个命题，但其真假未知。通过判断命题真假情况，使结论成立。
  • 解题方法：先找（矛盾、反对）关系，反之再题干假设、选项带入
    • 矛盾关系：一真一假，不能同真同假
      • 遇到矛盾关系泽绕过，看其余

        题干条件只一真 且在矛盾中，其余则为 假 题干条件只一假 且在矛盾中，其余则为 真

      1. A 与 -A

        例：“是乙拿的白球” 与 “不是乙拿的白球”

      2. “所有 A 是 B” 与 “有的 A 不是 B”

        例：“所有学生都是男的” 与 “有的学生不是男的”

      3. “所有 A 不是 B” 与 “有的 A 是 B”

        例：“所有学生不是男的” 与 “有的学生是男的”

      4. “A -> B” 与 “A 且 -B”

        例：“如果晴天，就去公园”（晴天 -> 去公园） 与 “晴天，但没去公园”（晴天 且 -去公园）

      5. “A 或 B” 与 “-A 且 -B”

        例：“选择 甲或乙” 与 “不选择甲 且 不选择乙”（“不选择 甲和乙”）

      6. “A 且 B” 与 “-A 或 -B”

        例：“选择 甲和乙” 与 “不选择甲 或 不选择乙”

      • ⚡秒题技巧：
        1. 谁是冠军（只有一人真话）：提及谁是冠军则为其累计，次数少为冠军。
        2. 2人真话，2人假话：四句话中**有“至少”和“有的”**的人说真话
    • 反对关系：
      • （没有矛盾找反对）遇到反对关系泽绕过，看其余

        题干条件只一真，找“有的（不）”，其余则为 假 题干条件只一假，找“所有都（不）”，其余则为 真

      1. “有的 A 是 B” 与 “有的 A 不是 B”，必有一真

        例：“有的花是红的” 与 “有的花不是红的”，必有一真

      2. “所有 A 都是 B” 与 “所有 A 都不是 B”，必有一假

        例：“所有学生都及格了” 与 “所有学生都没及格”，必有一假

      • 案例：

        A：“公司有人有证书。”; B：“公司有人没有证书。”; C：“公司小王没有证书。”。只有一人真话。

        A 与 B 反对关系，则 C 为假可推 "公司小王有证书。" => A 真话 => B 假话（矛盾命题推出“公司所有人都有证书。”）

    • 题干假设、选项带入（找不到矛盾关系和反对关系）
      • 题干假设：先假设题干某个条件为真，与其他条件是否矛盾。（若矛盾，即假设条件错误，推出正确结论）
      • 选项带入：先依次将选项带入命题判断真假，然后对比题干条件，最后择优取舍。

# 7、日常结论

  • 题型特征
    • 提问方式 “可以推出 / 无法推出”等，且题干类言语的表述，无明显逻辑关联词。
  • 解题方法
    • 三不选
      1. 存在逻辑错误的选项一定不选。

        例：题干 A 导致 B，若选项 B 导致 A （或是 A 且 B ）都不选。

      2. 无中生有的选项一定不选。（题干根本没有提到的事，选项出现则不选）
      3. 偷换概念的选项一定不选。（题干的主体是“人”，选项将主体替换为“其他事物”则不选）
    • 三慎选
      1. 比较关系： 比 / 越来愈 / 更...。
      2. 绝对关系：一定、必须、肯定、所有、只要...就...；只有...才...
      3. 程度词：最 / 很...、极大、主要等
    • 一优选
      1. （选项接近，都存在瑕疵时）可能性表述最优。

        可能性表述词：可能、有的 / 有些 、 未必等

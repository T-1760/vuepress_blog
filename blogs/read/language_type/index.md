## 动态语言 & 静态语言 
  - 动态类型语言（Dynamically Typed Language）是一种**运行期间才做数据类型检查**的语言
    + 声明变量无需指明该变量的类型。可以在运行时，通过赋予不同的值得到不同的类型（编程语言根据赋值进行猜测或推断出类型）。
    + 动态类型语言：`JavaScript`、`PHP`、`Python`、`Ruby`等
  - 静态类型语言（Statically Typed Language）是一种**编译期间做检查数据类型**的语言
    + 编译时需要声明变量的数据类型（分配好内存空间）。不可以在运行时改变变量的类型。
    + 静态类型语音： `C`、`C++`、`Java`、`C#`、`Go`等
  - 【动静状态】区分核心：什么时候知道某个变量是哪种类型
    + 静态类型语言：在**编译期**就确定变量类型
    + 动态类型语言：在**运行期**才确定变量类型

## 编译型和解释型
### 编译型
  - Compile 编译： 有一个负责对源代码翻译的程序（即：Compiler 编译器），进行转换生成相对应的可执行代码的过程
  - 写的程序代码都包含在一个源文件中，通常编译之后就会直接生成一个可执行文件，
    + 对于比较复杂的项目，为了方便管理，通常把代码分散在各个源文件中，作为不同的模块来组织。这时编译各个源文件时就会生成对应的 Object file 目标文件（内容基本上已经是可执行代码），而不是直接生成一个可执行文件
    + Linker 链接程序会将所有源文件编译成半成品的目标文件（把目标文件连接装配起来）打包成一个可执行文件
    + 链接程序不仅可以链接各种资源（目标文件，图标文件等）
 
### 解释型
  - 在程序运行的前一刻，还只有源程序而没有可执行程序；而程序每执行到源程序的某一条指令，则会有一个解释程序的外壳程序将源代码转换成二进制代码以供执行，
    + 总言之就是不断地解释、执行、解释、执行循环往复。故此解释型程序是离不开解释程序的
    + 解释型程序省却了编译的步骤，修改调试也非常方便，编辑完毕之后即可立即运行，
      * 避免像编译型程序一样每次进行小小改动都要等待漫长的 Compiling…Linking 编译链接过程
### 编译型 和 解释型应用场景
 - 编译型语言由于程序执行速度快，同等条件下对系统要求较低
    + 常用于开发操作系统、大型应用程序、数据库系统等 
    + `C`、`C++`、`Pascal/Object Pascal`（Delphi）等
  - 解释型语言
    + 常用于网页脚本、服务器脚本及辅助开发接口（对速度要求不高、对不同系统平台间的兼容性有一定要求的程序）
    + `Java`、`JavaScript`、`VBScript`、`Perl`、`Python`等
  - 两者融合
    + 随着设计技术与硬件的不断发展，编译型与解释型两种方式的界限正在不断变得模糊
    + 若今一批新兴的语言都有把两者折衷起来的趋势，
      * 例：`Java` 语言虽然比较接近解释型语言的特征，但在执行之前已经预先进行一次预编译，生成的代码是介于机器码和 `Java` 源代码之间的中介代码，运行的时候则由 JVM（Java的虚拟机平台，可视为解释器）解释执行。它既保留了源代码的高抽象、可移植的特点，又已经完成了对源代码的大部分预编译工作，所以执行起来比“纯解释型”程序要快许多。

## 强类型语言 & 弱类型语言
  - 强类型语言是一种**强制类型定义**的语言
    + 一旦某一个变量被定义类型，如果不经过强制转换，则它永远就是该数据类型
    + 强类型语言：`Java`、`C#`、`Python`、`C++`、`Ruby`、`Golang`、`Rust`等
  - 弱类型语言是一种**弱类型定义**的语言
    + 某一个变量被定义类型，该变量可以根据环境变化自动进行转换，不需要经过显性强制转换
    + 弱类型语言：`C`、`C++`、`javascript`、`vb`、`PHP`等
  - 【强弱类型】区分核心：不同类型的变量是否允许隐式转化
    + 强类型语言：倾向于**不对变量**的类型做隐式转换
    + 弱类型语言：倾向于**对变量**的类型做隐式转换

## 切勿混用【强弱类型】与【动静类型】
  - 【静态语言】并不意味着【强类型】，【动态语言】也不意味着【弱类型】，
    + 一种编程语言的类型系统可以是 静态、动态和强类型、弱类型的任意组合
      * 静态语言 + 强类型；`C`、`C++`、`Java`
      * 动态语言 + 弱类型；`JavaScript`、`PHP`
      * 动态语言 + 强类型：`Python`

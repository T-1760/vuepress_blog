## NodeJS 模块系统
  - Node.js 有两个模块系统： CommonJS 模块和 ECMAScript 模块。
    + CommonJS 模块是为 Node.js 打包 JavaScript 代码的原始方式
    + ECMAScript 模块是用于打包 JavaScript 代码的官方标准格式

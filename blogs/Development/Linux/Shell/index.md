## 前言
  - 通常操作系统可以分成 **kernel 核心**和 **Shell 外壳**两部分
  - Shell 是一种命令行解释器，用于用户与操作系统进行交互和执行命令的接口。
    + Shell 位于操作系统的外层，
    +  ``bash`` 是 Linux 操作系统中的默认（Shell）命令行解释器
      * bash 比 cmd 功能更强大
    +  `cmd` 是 Windows 操作系统中的默认（Shell）命令行解释器
      * `windows power shell` 是 Windows 操作系统强大的 Shell 
  - Windows 操作系统中，桌面（即：explorer.exe 资源管理器）是**图形 shell**，而终端 cmd.exe 则是**命令行 shell**。
    + cmd 是 Command shell 的简写
  - Shell 基本分两大类：
    + 图形界面 Shell（GUI Shell, Graphical User Interface Shell）
      * Windows Explorer，
      * Linux Shell 包括 X window manager （`BlackBox` 和 `FluxBox`），功能更强大的 `CDE`、`GNOME`、`KDE`、`XFCE` 等。
    + 命令行式 Shell（CLI Shell, Command Line Interface Shell）
      * Bourne Shell（`sh`）
      * C Shell（`csh`）
      * Korn Shell（`ksh`）
      * Bourne Again Shell（`bash`）
      * Z Shell（`zsh`）
### 环境变量
  - 环境变量：由 Shell 定义和赋初值的 Shell 变量。
    + Shell 用环境变量来确定查找路径、注册目录、终端类型、终端名称、用户名等。
    + 所有环境变量都是全局变量，并可以由用户重新设置，
  - Shell 常用的环境变量
    + `EDITOR`、`FCEDIT`：`bash`、`fc`命令的默认编辑器	
    + `HISTFILE`：用于储存历史命令的文件	
    + `HISTSIZE`：历史命令列表的大小	
    + `HOME`：当前用户的用户目录	
    + `OLDPWD`：前一个工作目录	
    + `PATH`：bash寻找可执行文件的搜索路径
    + `PS1`：命令行的一级提示符
    + `PS2`：命令行的二级提示符
    + `PWD`：当前工作目录
    + `SECONDS`：当前 Shell 开始后所流逝的秒数

    
### 命令行式 Shell 常见类型
  - `sh` 是 Unix 上的标准 Shell，也是其他 Shell 的开发基础。它在编程方面优秀，但在用户交互方面不如其他Shell。
  - `bash` 是 **Linux 系统中的默认 Shell**。它保持了对 `sh` 的兼容性，同时继承了 `csh` 和 `ksh` 的优点。目前最流行的 Shell。
  - `csh` 其语法类似 C 语言。它提供了一些 `sh` 不能处理的用户交互特性（命令补全、命令别名、历史命令替换）。但它与 `sh` 不兼容。
  - `ksh` 集合了 `csh` 和 `sh` 的优点，并且与 `sh` 完全兼容。它的效率很高，其命令交互界面和编程交互界面都很好。
  - `zsh` 是 Linux 最大的 Shell 之一，共有 84 个内部命令。它兼容 `bash`，并且提供了更多的功能和扩展。（POSIX Shell、macOS 中使用 `zsh` ）

  | 全称 | 简称 | 创始人 | 备注 |
  |:--|:--|:--|:--|
  | Bourne Shell       | `sh`   | Unix 上的标准 Shell    | AT&T 公司的 Steve Bourne 开发 |
  | Bourne Again Shell | `bash` | Linux 标准默认的 shell | GNU 组织开发 |

  | Z Shell            | `zsh`  | Linux 功能强大的 shell | 由 Paul Falstad 完成 |

## Shell 特殊字符
  - Shell 特殊字符可分为：特殊变量，替换符，转义字符，字符串符（引号），功能符，运算符。
### 特殊变量
  | 符号 | 作用 | 备注 |
  |:--|:--|:--|:--|
  |	`$0` | 当前脚本的名称 | |
  |	`$#` | 传递给脚本或函数的参数个数	| |
  |	`$*` | 传递给脚本或函数的所有参数	| |
  |	`$@` | 传递给脚本或函数的所有参数 | `"$@"`与 `"$*"` 稍有不同 |	
  |	`$?` | 上个命令的退出状态，或函数的返回值 | |
  |	`$$` | 当前 Shell 进程 ID。| 对于 Shell 脚本，即这些脚本所在的进程 ID |	
  |	`$n` | 传递给脚本或函数的参数。`n` 是一个数字，表示第几个参数 | 第 `N` 个参数是`$N`|
  | `*`  | 作为匹配文件名扩展的一个通配符，能自动匹配给定目录下的每一个文件 |
  | `~`  | 与环境变量 `$HOME` 一样，默认表示当前用户的家目录 | 例：`echo ~` 查看家目录 |
  | `--` | 与 `~` 相同，表示当前用户的家目录 | 例：`cd - -`回到家目录，但不能 `echo --`输出|
  | `~+` | 当前工作目录。和环境变量 `$PWD` 一样 |	`echo ~+` 查看当前目录 |
  | `~-` | 前一个工作目录。和内部变量 `$OLDPWD` 一致 |	例：`echo ~-` 查看前一个工作目录 |
  | `-`	 | 与 `~-`相同，表示前一个工作目录 | 例：`cd -`回到前一个工作目录，但不能`echo -`输出|
  | `.`	 | 表示当前目录	  | 例：`ls .` 查看当前目录内容 |
  | `..` | 表示上一层目录	| 例：`ls ..` 查看上一层目录内容 |
  
  - `$@` 与 `$*` 的区别
    + 不被 `""` 包裹时，`$@` 和 `$*` 都表示脚本或函数传入的参数，都以 `$1 $2 … $n` 形式输出所有参数。
    + `"$*"`会将所有的参数作为一个整体，以 `"$1 $2 … $n"` 形式输出所有参数。
    + `"$@"` 和 `$@` 一样，还是会将各个参数分开，以 `$1 $2 … $n` 形式输出所有参数。
  ```shell
    function print(){
        echo "param num:"$#
        for i in "$*"
        do
            echo param:$i
        done

        for i in "$@"
        do
            echo param:$i
        done
        echo "all param:"$*
        echo "all param:"$@
        echo param1:$1
        echo param2:$2

        return 12
    }

    print "lvlv0" "lvlv1"
    echo $?

    # 输出结果
    param num:2
    param:lvlv0 lvlv1
    param:lvlv0
    param:lvlv1
    all param:lvlv0 lvlv1
    all param:lvlv0 lvlv1
    param1:lvlv0
    param2:lvlv1
    12
  ```

### 替换符
 - 替换符分为**命令替换符**和**变量替换符**。
#### 命令替换符
  | 特殊符号 | 作用 | 备注 |
  |:--|:--|:--|
  | `$()` |命令替换符，用于执行命令，替换命令的输出结果	`echo $(date)` |
  | \`\`  | 一对反引号，作用与 `$()` 相同 echo \`date\` |

#### 变量替换符
  - 注：下表中 pattern 模式不符合正则表达式的规则
  | 符号 | 作用 | 备注 |
  |:--|:--|:--|
  | `$` | `$` 置于变量前用于取变量的值 | `echo $PATH` 打印环境变量 `PATH` 的值 |
  | `${}` | `{}`中放置变量，用于读取变量的值 | `echo ${PATH} path` 访问 `PATH` 变量，而非常变量 `PATHpath` 变量 |
  | `${:-}` | `${var:-word}` 表示若 `var` 变量为空或 `unset` 已被删除，则返回 `word` 但不改变 `var` 的值 |	|
  | `${:+}` | `${var:+word}` 表示若 `var`变量被定义，则返回 `word` 但不改变 `var` 的值 | |
  | `${:=}` | `${var:=word}` 表示若 `var`变量为空或 `unset` 已被删除，则返回 `word`并将 `var` 值设置为 `word` |	 |
  | `${:?}` | `${var:?message}` 表示若 `var` 变量为空或 `unset` 已被删除，则将 `message` 消息送到标准错误输出 | 可用来检测 `var` 变量是否可以被正常赋值 <br> 若此替换出现在 Shell 脚本中，则脚本将停止运行 |
  | `${#}` | `${#var}` 获取 `var` 变量的长度 | `string="abcd"; echo ${#string}` // `4` |
  | `${:}` | 字符串提取 | `${var:n}` 表示若 `n` 为正数，从 `0` 开始，表示在 `var` 变量中提取第n个字符到末尾的所有字符 <br> 若 `n` 为负数，字符串从后往前提取 `n` 个字符，使用时在冒号后面加空格或一个算术表达式或整个 num 加上括号 <br> 如 `${var: -2}` 表示提取字符串最后两个字符。	`a="abcde";echo ${a:1-4}`// `"cde"` |
  | `${::}`	| 字符串提取。用法 `${var:n:len}` | `string="hello";echo ${string:1:3}` // `"ell"`|
  | `{,}` |	`${v1,v2,vN}` 顺序扩展用于文件列表的扩展 | `echo {a,b}.txt`// `a.txt b.txt` |
  | `{..}` | `${v1..vN}` 顺序扩展用于文件列表的扩展 |	`echo {a..d}.txt`// `a.txt b.txt c.txt d.txt` |
  | `${#}` | 模式匹配截断不改变原变量。`${var#pattern}`表示在 `var` 中查找给定的模式, 把 `var` 中的内容去掉**左边最短**的匹配模式 | `var="testcase"; echo ${var#*s}`// `"tcase"`|
  | `${##}` | 模式匹配截断不改变原变量。`${var##pattern}`表示在 `var` 中查找给定的模式, 把 `var` 中的内容去掉**左边最长**的匹配模式 | `var="testcase"; echo ${var##*s}`// `"e"` |
  | `${%}` | 模式匹配截断不改变原变量。`${var%pattern}`表示在 `var` 中查找给定的模式 把 `var` 中的内容去掉**右边最短**的匹配模式 |	`var="testcase"; echo ${var%s*e}`//`"testca"`|
  | `${%%}` | 模式匹配截断不改变原变量。`${var%%pattern}`表示在 `var` 中查找给定的模式，把 `var` 中的内容去掉**右边最长**的匹配模式 |	`var="testcase"; echo ${var%%s*e}` // `"te"` |
  | `${/ /}` | 模式匹配替换不改变原变量。`${var/pattern/pattern}`表示将 `var` 字符串的**第一个匹配**的模式，替换为另一个模式 | 	`var="/home/centos"; echo ${var/o/h}`// `"/hhme/centos"`
  | `${// /}` | 模式匹配替换不改变原变量。`${var//pattern/pattern}`表示将 `var` 字符串中的**所有能匹配**的模式，替换为另一个模式 | 	`var="/home/centos"; echo ${var//o/h}` // `"/hhme/cenths"`|
  |	`$[]`	| 整数扩展，在 `[]` 中执行整数表达式并返回结果 | `a=3; b=7; echo $[$a+$b]` //`10`|

### 功能符
  - 功能符号可分为**语法功能符**和**命令功能符**
#### 语法功能符
  | 符号 | 作用 | 备注 |
  |:--|:--|:--|
  | `#`	| 用于 Shell 首行指定执行脚本的解释器，非首行用于单行注释 |	脚本首行 `#!/bin/bash` 指明 Bash 脚本解释器。|

  | `&`	| 若命令后面跟上一个 `&` 符号，此命令将在后台运行 |	使用格式：`command&` |
  | `/`	| 作为路径的分隔符，路径中仅有一个斜杆表示根目录，以`/` 开头的路径表示从根目录开始的路径 <br> 在作为运算符的时候，表示除法符号 | |
  | `()` | 用于命令组。括号中的命令将会新开一个子shell顺序执行，所以括号中的变量不能够被脚本余下的部分使用。括号中用 `;` 隔开多个命令。<br> 用于初始化数组。例：`array=(a b c d)` |	
  | `{}`	| 代码块标识符，用于函数定义时表明函数体 |	|
  | `<<<`	| 用于将后面的内容作为前面命令的标准输入 | `grep a <<< "$VAR"`在 var 变量值里查找 `a`字符 |
  | `>|`  | 功能同 `>` 但即便设置 `noclobber` 属性（表明已存在文件不能被重定向输出覆盖）时也会强制复盖 file 文件 |	
  | `<>` | 标准输入与输出重定向运算符 |	`exec 6<>filename` 通过 `exec` 命令，以读写方式将文件描述符 `6` 绑定到指定文件 |

#### 命令功能符
  - `.`	
    + 相当于 bash 内建 source 命令
    ```shell
      #!/bin/bash;
      . data-file#包含data-file;
    ```
    + 作为文件名的一部分，在文件名的开头，表示该文件为隐藏文件
      * `ls` 一般不显示出来（`ls -a` 显示）;
    + 作为目录名，
      * `.` 代表当前目录
      * `..` 代表上层目录（当前目录的父目录）。
      * 注：两个以上的 `.` 不出现，除非用（单/双）引号包围作为点号字符本身；
    + 正则表达式中，`.` 表示任意一个字符。	
  - `:`是 Shell 的空命令，什么也不做，但返回 `true`。用法比较多
    + 可做 `while` 死循环的条件；
    + 占位符，可用于 `if` 某一分支不作为时；
    + 域分隔符，如：环境变量 `PATH`、`passwd` 中，冒号作为域分隔符的存在；
    + 清空文件。因为冒号不向标准输出打印任何内容，所以可以用来清空文件，如 `:>file`
    + 配合 `${:=}` 给未定义或为空的变量赋值，例：`: ${abc:=1234};echo $abc` 输出 `1234`

### 运算符
  - Shell 运算符较多可分为
    + 算数运算符
    + 关系运算符
    + 逻辑运算符
    + 字符串运算符
    + 文件运算符

#### 算术运算符
  | 符号 | 作用 | 备注 |
  |:--|:--|:--|
  |	`+`	| 加法	| `a=10;b=20;expr $a + $b` 结果为 `30` |
  |	`-`	| 减法	| `expr $a - $b` 结果为 `-10` |
  |	`*`	| 乘法	| `expr $a * $b` 结果为 `200` |
  |	`/`	| 除法	| `expr $b / $a` 结果为 `2`   |
  |	`%`	| 取余	| `expr $b % $a` 结果为 `0`   |
  |	`=`	| 赋值	| `a=$b` 将 `b` 变量值赋给 `a` |
  | `(())` | 用于替代 `expr` 算术命令 |	`for((i=0;i<10;++i))`、`if(($a==$b));then ... fi` 无需添加空格，更符合 C 的编程语法 |
  | `**`| 算术运算中表示求幂运算 |	
  -  `,`
    + 用在连接一连串的数学表达式中，这串数学表达式均被求值，但只有最后一个求值结果被返回  
      ```shell
        #!/bin/bash
        t1=$((a=5+1, b=7+2))
        echo t1=$t1, a=$a, b=$b

        # 输出
        t1=9, a=6, b=9      
      ```
    + 用于参数替代中，表示首字母小写，如果是两个逗号，则表示全部小写，此特性在 bash v4 版本及以上有效
      ```shell
        a="ATest"
        echo ${a,}
        echo ${a,,}

        # 输出
        aTest
        atest        
      ```

  |:--|:--|:--|
  | `[]` | 用于判断条件是否成立	 | `[ $a == $b ]` 注意添加 4 个空格 |
  | `[[]]` | 对 `[]` 的扩展，可使用 `<`、`>`、`&&`、`||` 等运算符 | `[[ $a>$b ]]` 只需左右边缘添加两个空格。使用 `==` 与 `!=` 时，仍需要 4 个空格 |
  | `-eq` | 检测两个数是否相等，相等返回 `true`	| `[ $a -eq $b ]` 返回 `true` |
  | `==`  | 检测两个数是否相等，同 `-eq` 功能   |	`[ $a == $b ]`  返回 `true` |
  | `-ne` | 检测两个数是否相等，不等返回 `true` |	`[ $a -ne $b ]` 返回 `true` |
  | `!=`  | 同 `-ne` 功能 | `[ $a != $b ]` 返回 `true` |
  | `-gt`	| 检测左边是否大于右边的，成立返回 `true` |	`[ $a -gt $b ]` 返回 `false` |
  | `-lt`	| 检测左边是否小于右边的，成立返回 `true` |	`[ $a -lt $b ]` 返回 `true` |
  | `-ge`	| 检测左边是否大于等于右边的，成立返回 `true` | `[ $a -ge $b ]` 返回 `false` |
  | `-le`	| 检测左边是否小于等于右边的，成立返回 `true` | `[ $a -le $b ]` 返回 `true` |
  - 运算符 `[]` 与 `[[]]` 的区别
    + `[]` 实际上是 Bash 中 `test` 命令的简写，即 `[ expression ]` 等于 `test expression`
    + `[[ expression ]]` 是 Bash 中真正的条件判断语句，其语法更符合编程习惯，推荐使用。
  - Shell 中没有 `<=` 小于等于与 `>=` 大于等于关系运算符，只能使用 `-le` 与 `-ge` 替代。

#### 逻辑运算符
  | 符号 | 作用 | 示例 |
  | `!`  | 非运算，表达式取反操作，返回 `true` 或 `false` |	`[ ! false ]` 返回 `true` |
  | `-o` | 或运算，有一个表达式为 `true` 则返回 `true` | `[ $a -lt 20 -o $b -gt 100 ]` 返回 `true` |
  | `-a` | 与运算，两个表达式都为 `true` 则返回 `true` | `[ $a -lt 20 -a $b -gt 100 ]` 返回 `false` |
  | `||` | 或运算符。用于条件判断，搭配 `[[]]` 使用。两个表达式有一个为 `true` 则返回 `true` <br> 用于命令连接：`command1 || command2` 左边的命令返回 `false`（即非 `0` 表示执行失败），右边命令才能够被执行 | `[[ $a < 20 || $a > 19 ]]` 返回 `true` |
  | `&&` | 与运算符，用于条件判断，搭配 `[[]]` 使用。两个表达式都为 `true` 则返回 `true`  <br> 用于命令连接。`command1 && command2` 左边的命令返回 `true`（即 `0` 表示执行成功），右边命令才能够被执行。|	`[[ $a < 20 && $a > 20 ]]` 返回 `false` |

#### 字符串运算符
  | 符号 | 作用 | 示例 |
  | `=`   | 检测两个字符串是否相等，相等返回 `true` | `[ "$a" = "$b" ]` 返回 `false` |
  | `!=`	| 检测两个字符串是否相等，不相等返回 `true` | `[ "$a" != "$b" ]` 返回 `true` |
  | `-z`	| 检测字符串长度是否为 `0`，为 `0` 返回 `true` | `[ -z "$a" ]` 返回 `false` |
  | `-n`	| 检测字符串长度是否为 `0`，不为 `0` 返回 `true` | `[ -n "$a" ]` 返回 `true` |
  | `str`	| 检测字符串是否为空，不为空返回 `true` | `[ "$a" ]` 返回 `true` |
  | `=~`	| 用于匹配正则表达式的，搭配 `[[]]` 使用 | `[[ ! $file =~ check$ ]]` 判断 `$file` 是否是以 `check` 结尾 |
  - `-z` 不仅可以用来判断字符串长度是否为 `0`，还可以用来判断变量是否被申明。
    ```shell
      # 如果变量 var 已申明，返回 false。
      var=""
      if [ -z ${var+x} ]; then
      	echo "var is unset"
      else 
      	echo "var is set to '$var'"
      fi
      
      # 脚本声明了一个 var 空字符串。长度为 0，但是 var 已经申明，所以脚本走到 else 分支。
      # 输出 var is set to ''
    ```
#### 文件运算符
  - Linux 下文件的类型。
    + `-` 普通文件
    + `d` 目录
    + `b` 块设备
    + `c` 字符设备
    + `p` 命名管道
    + `l` 符号链接
    + `s` 套接字
  - 文件运算符用于检测文件的各种属性。
    | 符号 | 作用 | 示例 |
    | `-b` | 文件存在且是块设备文件     | `[ -b /dev/vda1 ]` 返回 `true` |
    | `-c` | 文件存在且是字符设备文件   | `[ -c /dev/stdin ]` 返回 `true` |
    | `-d` | 文件存在且是目录          | `[ -d / ]` 返回 `true` |
    | `-e` | 文件（包括目录）是否存在   | `[ -e / ]` 返回 `true` |
    | `-f` | 文件存在且是普通文件（既非目录，也非设备文件） | `[ -f /etc/passwd]` 返回 `true` |
    | `-g` | 文件存在且设置了 SGID 位   | `[ -g /usr/bin/passwd ]` 返回 `false` |
    | `-G` | 文件存在且属于有效组 ID    | `[ -G /etc/passwd ]` 返回 `true` |
    | `-h` | 文件存在且是软链接。同 `-L` | `[ -h /etc/passwd ]` 返回 `false` |
    | `-k` | 文件存在且设置了粘着位（Sticky Bit） | `[ -k /tmp ]` 返回 `true` |
    | `-L` | 文件存在且是软链接。同 -h  | `[ -L /etc/passwd ]` 返回 `false` |
    | `-O` | 文件存在且属于有效用户ID   | `[ -O /etc/passwd ]` 返回 `true` |
    | `-p` | 文件存在且是具名管道       | `[ -p /etc/passwd ]` 返回 `false` |
    | `-r` | 文件存在且可读             | `[ -r /etc/passwd ]` 返回 `true` |
    | `-s` | 文件存在且不为空           | `[ -s /etc/passwd ]` 返回 `true` |
    | `-S` | 文件存在且是套接字（socket） | `[ -s /etc/passwd ]` 返回 `false` |
    | `-u` | 文件存在且设置了 SUID 位   | `[ -s /usr/bin/passwd ]` 返回 `true` |
    | `-w` | 文件存在且可写     | `[ -w /etc/shadow ]` 返回 `false` |
    | `-x` | 文件存在且可执行   | `[ -x /usr/bin/passwd ]` 返回 `true` |
    | `-ef`	| 两个文件是否为同一个文件。主要看文件设备号与 inode 是否一致 | `[ /usr/bin/passwd -ef /etc/passwd ]` 返回 `false` |
    | `-nt`	| 文件 FILE1 是否比 FILE2（修改时间）新 | `[ /usr/bin/passwd -nt /etc/passwd ]` 返回 `false` |
    | `-ot`	| 文件 FILE1 是否比 FILE2（修改时间）旧 | `[ /usr/bin/passwd -ot /etc/passwd ]` 返回 `true` |

## Shell 脚本的基本语法结构
  - 声明解释器：
    + 每个 Shell 脚本的第一行都应该指定解释器。
    + 在 Unix 系统上，常用的解释器是 bash。因此在脚本的首行添加 `#!/bin/bash` 声明
  - 注释：
    + Shell 脚本中提供对脚本的解释和说明。注释以 `#` 井号开头，
  - 变量：
    + Shell 脚本中使用变量来存储和操作数据。变量名必须以字母或下划线开头，后面可以跟字母、数字或下划线。
    + 变量赋值使用 `=` 等号，如：`variable_name=value`。
    + 使用变量时，需要在变量名前加上 `$` 符号，如：`$variable_name`。
  - 命令执行：
    + 可以在 Shell 脚本中执行各种系统命令。要输入命令即可执行命令。
    + 例，使用 `ls` 命令列出当前目录的文件。
  - 输入输出：
    + Shell 脚本可以从用户处接收输入，并向用户显示输出。使用 read 命令从用户获取输入，并使用 echo 命令将输出发送到标准输出。
  - 条件语句：
    + 条件语句用于根据条件的结果执行不同的代码块。
    + 常用的条件语句有 if 语句（根据条件执行或跳过代码块）和 case 语句（根据不同的模式匹配执行不同的代码块）。
  - 循环：
    + Shell 脚本中的循环用于重复执行一段代码。
    + 常用的循环有 `for` 循环（用于遍历列表或范围）、`while` 循环和 `until` 循环（在判断条件为真假时执行代码块）。
  - 函数：
    + Shell 脚本支持函数定义和调用。使用 `function` 关键字定义函数，调用函数时只需使用函数名即可。
  - 参数传递：
    + 可以在 Shell 脚本中将参数传递给脚本或函数。脚本参数使用特殊变量 `$1`、`$2`等表示，函数参数使用类似的方式。
  - 文件处理：
    + Shell 脚本可以处理文件和目录。可以使用各种命令来读取、写入和操作文件。常用的文件处理命令有`cat`、`grep`、`sed`、`awk`等。
  - 错误处理：
    + Shell 脚本可以捕获和处理错误。可以使用条件语句和命令返回值来检查命令是否成功执行，并采取相应的措施

Shell 脚本语言

Tang_1997 2023/10/18 shell 脚本语言bashcmd

# 前言

  • 通常操作系统可以分成 kernel 核心和 Shell 外壳两部分
  • Shell 是一种命令行解释器，用于用户与操作系统进行交互和执行命令的接口。
    • Shell 位于操作系统的外层，
    • bash 是 Linux 操作系统中的默认（Shell）命令行解释器
    • bash 比 cmd 功能更强大
    • cmd 是 Windows 操作系统中的默认（Shell）命令行解释器
    • windows power shell 是 Windows 操作系统强大的 Shell
  • Windows 操作系统中，桌面（即：explorer.exe 资源管理器）是图形 shell，而终端 cmd.exe 则是命令行 shell。
    • cmd 是 Command shell 的简写
  • Shell 基本分两大类：
    • 图形界面 Shell（GUI Shell, Graphical User Interface Shell）
      • Windows Explorer，
      • Linux Shell 包括 X window manager （BlackBox 和 FluxBox），功能更强大的 CDE、GNOME、KDE、XFCE 等。
    • 命令行式 Shell（CLI Shell, Command Line Interface Shell）
      • Bourne Shell（sh）
      • C Shell（csh）
      • Korn Shell（ksh）
      • Bourne Again Shell（bash）
      • Z Shell（zsh）

# 环境变量

  • 环境变量：由 Shell 定义和赋初值的 Shell 变量。
    • Shell 用环境变量来确定查找路径、注册目录、终端类型、终端名称、用户名等。
    • 所有环境变量都是全局变量，并可以由用户重新设置，
  • Shell 常用的环境变量
    • EDITOR、FCEDIT：bash、fc命令的默认编辑器
    • HISTFILE：用于储存历史命令的文件
    • HISTSIZE：历史命令列表的大小
    • HOME：当前用户的用户目录
    • OLDPWD：前一个工作目录
    • PATH：bash寻找可执行文件的搜索路径
    • PS1：命令行的一级提示符
    • PS2：命令行的二级提示符
    • PWD：当前工作目录
    • SECONDS：当前 Shell 开始后所流逝的秒数

# 命令行式 Shell 常见类型

  • sh 是 Unix 上的标准 Shell，也是其他 Shell 的开发基础。它在编程方面优秀，但在用户交互方面不如其他Shell。
  • bash 是 Linux 系统中的默认 Shell。它保持了对 sh 的兼容性，同时继承了 csh 和 ksh 的优点。目前最流行的 Shell。
  • csh 其语法类似 C 语言。它提供了一些 sh 不能处理的用户交互特性（命令补全、命令别名、历史命令替换）。但它与 sh 不兼容。
  • ksh 集合了 csh 和 sh 的优点，并且与 sh 完全兼容。它的效率很高，其命令交互界面和编程交互界面都很好。
  • zsh 是 Linux 最大的 Shell 之一，共有 84 个内部命令。它兼容 bash，并且提供了更多的功能和扩展。（POSIX Shell、macOS 中使用 zsh ）

# 特殊变量

符号 作用 备注
$0 当前脚本的名称
$# 传递给脚本或函数的参数个数
$* 传递给脚本或函数的所有参数
$@ 传递给脚本或函数的所有参数 "$@"与 "$*" 稍有不同
$? 上个命令的退出状态，或函数的返回值
$$ 当前 Shell 进程 ID。 对于 Shell 脚本，即这些脚本所在的进程 ID
$n 传递给脚本或函数的参数。n 是一个数字，表示第几个参数 第 N 个参数是$N
* 作为匹配文件名扩展的一个通配符，能自动匹配给定目录下的每一个文件
~ 与环境变量 $HOME 一样，默认表示当前用户的家目录 例：echo ~ 查看家目录
-- 与 ~ 相同，表示当前用户的家目录 例：cd - -回到家目录，但不能 echo --输出
~+ 当前工作目录。和环境变量 $PWD 一样 echo ~+ 查看当前目录
~- 前一个工作目录。和内部变量 $OLDPWD 一致 例：echo ~- 查看前一个工作目录
- 与 ~-相同，表示前一个工作目录 例：cd -回到前一个工作目录，但不能echo -输出
. 表示当前目录 例：ls . 查看当前目录内容
.. 表示上一层目录 例：ls .. 查看上一层目录内容
  • $@ 与 $* 的区别
    • 不被 "" 包裹时，$@ 和 $* 都表示脚本或函数传入的参数，都以 $1 $2 … $n 形式输出所有参数。
    • "$*"会将所有的参数作为一个整体，以 "$1 $2 … $n" 形式输出所有参数。
    • "$@" 和 $@ 一样，还是会将各个参数分开，以 $1 $2 … $n 形式输出所有参数。
  function print(){
      echo "param num:"$#
      for i in "$*"
      do
          echo param:$i
      done

      for i in "$@"
      do
          echo param:$i
      done
      echo "all param:"$*
      echo "all param:"$@
      echo param1:$1
      echo param2:$2

      return 12
  }

  print "lvlv0" "lvlv1"
  echo $?

  # 输出结果
  param num:2
  param:lvlv0 lvlv1
  param:lvlv0
  param:lvlv1
  all param:lvlv0 lvlv1
  all param:lvlv0 lvlv1
  param1:lvlv0
  param2:lvlv1
  12

# 语法功能符

符号 作用 备注
# 用于 Shell 首行指定执行脚本的解释器，非首行用于单行注释 脚本首行 #!/bin/bash 指明 Bash 脚本解释器。
; 语句的分隔符。脚本一行写多条语句时，使用 ; 分号分隔
;; 在 case 选项时，作为每个选项的终结符 在 Bash v4+ 版本可使用[;;&]、 [;&]
/ 路径分隔符，路径中仅有一个斜杆表示根目录，以斜杆开头的路径表示从根目录开始的路径
| 管道是类 Unix 系统重要的基础概念。作用是将管道前（左边）命令产生的（stdout）标准输出作为管道后（右边）命令的（stdin）标准输入。对（stderr）标准错误输出无效 less file | wc -l 用于统计文件的行数
> 标准输出重定向符。对（stderr）标准错误输出无效 echo lvlv>file 将标准输出重定向到 file ，若存在则覆盖 file 内容，反之创建
不指定输出的内容 >file 则清空文件
>> 标准输出重定向追加符 echo lvlv 1>>file 将标准输出重定向 file 的最后面，不会覆盖原有 file 内容
>& 输出重定向等同符，作用于文件描述符，即左右两边的操作数是文件描述符 echo lvlv>file 2>&1 标准输出重定向到 file 中，标准错误输出与标准输出重定向一致
&> 标准输出和标准错误输出重定向符 echo lvlv &>file 标准输出和标准错误输出都重定向到文件中，与 echo lvlv 1>file 2>&1 功能相同
< 输入重定向 test.sh < file 脚本 test.sh 需要 read 的地方会从 file 文件读取
<< 名为 Here Document。用法 cmd << text 表示将后继内容重定向到左侧命令的 stdin 中。内容直到与 text 相同的行结束。除非使用引号把输入括起来，此模式将对输入内容进行 Shell 变量替换。 如果使用 <<- 则忽略后面输入行首的 tab，结束行也可以是一对 tab 再加上一个与 text 相同的内容
<& 标准输入重定向等同符，作用于文件描述符，即左右两边的操作数是文件描述符 cmd <& m 将m 文件描述符作为 cmd 的输入，省略了标准输入描述符 1，等价于 cmd 1<&fd
>&- 关闭某个输出文件描述符。 exec >&- 或 exec 0>&-关闭标准输出
<&- 关闭某个输入文件描述符。 exec <&- 或 exec 1<&-关闭标准输入
& 若命令后面跟上一个 & 符号，此命令将在后台运行 使用格式：command&
/ 作为路径的分隔符，路径中仅有一个斜杆表示根目录，以/ 开头的路径表示从根目录开始的路径
在作为运算符的时候，表示除法符号
() 用于命令组。括号中的命令将会新开一个子shell顺序执行，所以括号中的变量不能够被脚本余下的部分使用。括号中用 ; 隔开多个命令。
用于初始化数组。例：array=(a b c d)
{} 代码块标识符，用于函数定义时表明函数体
<<< 用于将后面的内容作为前面命令的标准输入 grep a <<< "$VAR"在 var 变量值里查找 a字符
>| 功能同 > 但即便设置 noclobber 属性（表明已存在文件不能被重定向输出覆盖）时也会强制复盖 file 文件
<> 标准输入与输出重定向运算符 exec 6<>filename 通过 exec 命令，以读写方式将文件描述符 6 绑定到指定文件

** 算术运算中表示求幂运算
  • ,

    #!/bin/bash

# 关系运算符

符号 作用 示例
[] 用于判断条件是否成立 [ $a == $b ] 注意添加 4 个空格
[[]] 对 [] 的扩展，可使用 <、>、&&、|| 等运算符 [[ $a>$b ]] 只需左右边缘添加两个空格。使用 == 与 != 时，仍需要 4 个空格
-eq 检测两个数是否相等，相等返回 true [ $a -eq $b ] 返回 true
== 检测两个数是否相等，同 -eq 功能 [ $a == $b ] 返回 true
-ne 检测两个数是否相等，不等返回 true [ $a -ne $b ] 返回 true
!= 同 -ne 功能 [ $a != $b ] 返回 true
-gt 检测左边是否大于右边的，成立返回 true [ $a -gt $b ] 返回 false
-lt 检测左边是否小于右边的，成立返回 true [ $a -lt $b ] 返回 true
-ge 检测左边是否大于等于右边的，成立返回 true [ $a -ge $b ] 返回 false
-le 检测左边是否小于等于右边的，成立返回 true [ $a -le $b ] 返回 true
  • 运算符 [] 与 [[]] 的区别
    • [] 实际上是 Bash 中 test 命令的简写，即 [ expression ] 等于 test expression
    • [[ expression ]] 是 Bash 中真正的条件判断语句，其语法更符合编程习惯，推荐使用。
  • Shell 中没有 <= 小于等于与 >= 大于等于关系运算符，只能使用 -le 与 -ge 替代。

用于命令连接。command1 && command2 左边的命令返回 true（即 0 表示执行成功），右边命令才能够被执行。| [[ $a < 20 && $a > 20 ]] 返回 false |

# 字符串运算符

| 符号 | 作用 | 示例 | | = | 检测两个字符串是否相等，相等返回 true | [ "$a" = "$b" ] 返回 false | | != | 检测两个字符串是否相等，不相等返回 true | [ "$a" != "$b" ] 返回 true | | -z | 检测字符串长度是否为 0，为 0 返回 true | [ -z "$a" ] 返回 false | | -n | 检测字符串长度是否为 0，不为 0 返回 true | [ -n "$a" ] 返回 true | | str | 检测字符串是否为空，不为空返回 true | [ "$a" ] 返回 true | | =~ | 用于匹配正则表达式的，搭配 [[]] 使用 | [[ ! $file =~ check$ ]] 判断 $file 是否是以 check 结尾 |

  • -z 不仅可以用来判断字符串长度是否为 0，还可以用来判断变量是否被申明。
      # 如果变量 var 已申明，返回 false。
  var=""
  if [ -z ${var+x} ]; then
  	echo "var is unset"
  else 
  	echo "var is set to '$var'"
  fi
  
  # 脚本声明了一个 var 空字符串。长度为 0，但是 var 已经申明，所以脚本走到 else 分支。
  # 输出 var is set to ''

# 文件运算符

  • Linux 下文件的类型。
    • - 普通文件
    • d 目录
    • b 块设备
    • c 字符设备
    • p 命名管道
    • l 符号链接
    • s 套接字
  • 文件运算符用于检测文件的各种属性。 | 符号 | 作用 | 示例 | | -b | 文件存在且是块设备文件 | [ -b /dev/vda1 ] 返回 true | | -c | 文件存在且是字符设备文件 | [ -c /dev/stdin ] 返回 true | | -d | 文件存在且是目录 | [ -d / ] 返回 true | | -e | 文件（包括目录）是否存在 | [ -e / ] 返回 true | | -f | 文件存在且是普通文件（既非目录，也非设备文件） | [ -f /etc/passwd] 返回 true | | -g | 文件存在且设置了 SGID 位 | [ -g /usr/bin/passwd ] 返回 false | | -G | 文件存在且属于有效组 ID | [ -G /etc/passwd ] 返回 true | | -h | 文件存在且是软链接。同 -L | [ -h /etc/passwd ] 返回 false | | -k | 文件存在且设置了粘着位（Sticky Bit） | [ -k /tmp ] 返回 true | | -L | 文件存在且是软链接。同 -h | [ -L /etc/passwd ] 返回 false | | -O | 文件存在且属于有效用户ID | [ -O /etc/passwd ] 返回 true | | -p | 文件存在且是具名管道 | [ -p /etc/passwd ] 返回 false | | -r | 文件存在且可读 | [ -r /etc/passwd ] 返回 true | | -s | 文件存在且不为空 | [ -s /etc/passwd ] 返回 true | | -S | 文件存在且是套接字（socket） | [ -s /etc/passwd ] 返回 false | | -u | 文件存在且设置了 SUID 位 | [ -s /usr/bin/passwd ] 返回 true | | -w | 文件存在且可写 | [ -w /etc/shadow ] 返回 false | | -x | 文件存在且可执行 | [ -x /usr/bin/passwd ] 返回 true | | -ef | 两个文件是否为同一个文件。主要看文件设备号与 inode 是否一致 | [ /usr/bin/passwd -ef /etc/passwd ] 返回 false | | -nt | 文件 FILE1 是否比 FILE2（修改时间）新 | [ /usr/bin/passwd -nt /etc/passwd ] 返回 false | | -ot | 文件 FILE1 是否比 FILE2（修改时间）旧 | [ /usr/bin/passwd -ot /etc/passwd ] 返回 true |

# Shell 脚本的基本语法结构

  • 声明解释器：
    • 每个 Shell 脚本的第一行都应该指定解释器。
    • 在 Unix 系统上，常用的解释器是 bash。因此在脚本的首行添加 #!/bin/bash 声明
  • 注释：
    • Shell 脚本中提供对脚本的解释和说明。注释以 # 井号开头，
  • 变量：
    • Shell 脚本中使用变量来存储和操作数据。变量名必须以字母或下划线开头，后面可以跟字母、数字或下划线。
    • 变量赋值使用 = 等号，如：variable_name=value。
    • 使用变量时，需要在变量名前加上 $ 符号，如：$variable_name。
  • 命令执行：
    • 可以在 Shell 脚本中执行各种系统命令。要输入命令即可执行命令。
    • 例，使用 ls 命令列出当前目录的文件。
  • 输入输出：
    • Shell 脚本可以从用户处接收输入，并向用户显示输出。使用 read 命令从用户获取输入，并使用 echo 命令将输出发送到标准输出。
  • 条件语句：
    • 条件语句用于根据条件的结果执行不同的代码块。
    • 常用的条件语句有 if 语句（根据条件执行或跳过代码块）和 case 语句（根据不同的模式匹配执行不同的代码块）。
  • 循环：
    • Shell 脚本中的循环用于重复执行一段代码。
    • 常用的循环有 for 循环（用于遍历列表或范围）、while 循环和 until 循环（在判断条件为真假时执行代码块）。
  • 函数：
    • Shell 脚本支持函数定义和调用。使用 function 关键字定义函数，调用函数时只需使用函数名即可。
  • 参数传递：
    • 可以在 Shell 脚本中将参数传递给脚本或函数。脚本参数使用特殊变量 $1、$2等表示，函数参数使用类似的方式。
  • 文件处理：
    • Shell 脚本可以处理文件和目录。可以使用各种命令来读取、写入和操作文件。常用的文件处理命令有cat、grep、sed、awk等。
  • 错误处理：
    • Shell 脚本可以捕获和处理错误。可以使用条件语句和命令返回值来检查命令是否成功执行，并采取相应的措施

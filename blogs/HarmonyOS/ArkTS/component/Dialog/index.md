## Dialog 弹窗
  - 弹窗是一种模态窗口，通常用来展示用户当前需要的或用户必须关注的信息或操作。
    + 在弹出框消失之前，用户无法操作其他界面内容。
  - ArkUI 弹窗按照功能分为两类：
    + 确认类：AlertDialog 警告弹窗
    + 选择类：TextPickerDialog 文本选择弹窗、DatePickerDialog 日期滑动选择弹窗、TimePickerDialog 时间滑动选择弹窗。
    + 自定义弹窗

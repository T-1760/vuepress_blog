CSS Valuesandunits 值与单位

Tang_1997 2023/10/18 Values_and_unitsCSS 值与单位

# 前言

  • CSS 数据类型的值基本上是可以互换的

# CSS 中的 数字、长度和百分比

  • CSS 中数值数据类型归类
    数值类型 描述
    <integer> 是一个整数，例：1024 、-55
    <number> 表示一个小数（小数点后面的部分可有可无），例：0.255、128、-1.2
    <dimension> 在 <number> 的基础上附加的单位，例： 45deg、5s 或 10px。
    它是一个伞形类别（包括 <length>、<angle>、<time>、 <resolution> 等类型
    <percentage> 表示与其他值的占比，例：50%。一个元素的长度相对于其父元素的长度

# CSS <integer> 和 <number> 数字类型

  • 有些值接受数字，可不添加任何单位。
    • opacity 不透明度属性值为 [0, 1] 区间范围的数字，表示从完全透明 到 完全不透明的程度。

# CSS <length> 长度类型

  • CSS 中有两种类型的长度：相对长度和绝对长度
    • 少数 CSS 样式属性的长度可以是负数
  • 数字与单位之间不能出现空格。如果长度值为 0，则可以省略单位

# 绝对长度单位

  • 绝对长度单位：通常被认为总是相同的大小，与其他任何东西都没有关系
  • 大多数在用于打印时比用于屏幕输出时更有用
    • 在屏幕上，通常不会使用 cm（厘米）。经常使用 px（像素）值， | 单位 | 名称 | 等价换算 | |:--|:--|:--| | cm | 厘米 | 1cm = 37.8px = 25.2/64in | | mm | 毫米 | 1mm = 1/10th 的 1cm | | Q | 四分之一毫米 | 1Q = 1/40th 的 1cm | | in | 英寸 | 1in = 2.54cm = 96px | | pc | 派卡 | 1pc = 1/6th 的 1in | | pt | 点（磅 | 1pt = 1/72th 的 1in | | px | 像素 | 1px = 1/96th 的 1in |
  • 各单位的转换
    • 1毫米 = 2.834761磅
    • 1磅 = 0.352763毫米
    • 1in = 2.54cm = 25.4mm = 72pt = 6pc = 96px;
  • A3 纸是 A4 纸的 2 倍; A4 纸是 A5 纸的 2 倍
    • 96 / 25.4 = 3.78 像素/毫米
    • 25.4 / 96 = 0.26 毫米/像素
    • A4 纸在不同的分辨率屏幕上，呈现的像素尺寸有所差异：
      • 分辨率是 72 像素/英寸时，A4 纸的尺寸的图像的像素是595 × 842;
      • 分辨率是 96 像素/英寸时，A4 纸的尺寸的图像的像素是794 × 1123;
      • 分辨率是 120 像素/英寸时，A4 纸的尺寸的图像的像素是1487 × 2105;
      • 分辨率是 150 像素/英寸时，A4 纸的尺寸的图像的像素是1240 × 1754;
      • 分辨率是 300 像素/英寸时，A4 纸的尺寸的图像的像素是2480 × 3508。
  • PPI（每英寸的像素数量）= $\sqrt{X^2+Y^2} \over 屏幕尺寸$
    • 24 寸显示器的分辨率为：1920 × 1080 = 2073600 像素, 其 PPI 为：91.78
  • 纸张大小（A组纸张长宽比 1: $\sqrt{2}$ ）
    • A3（8开）：420 × 297 （单位：mm）
      • A3：420 × 297 = (420 × 3.78 像素/毫米) × (297 × 3.78 像素/毫米) = 1587.6 × 1122.6 像素
    • A4（16开）：297 × 210 （单位：mm）; 595.3 × 841.8 磅
      • A4：297 × 210 = (297 × 3.78 像素/毫米) × (210 × 3.78 像素/毫米) = 1122.6 × 793.7 像素
    • A5（32开）：210 × 148 （单位：mm）; 419.5 × 595.3 磅
      • A5：210 × 148 = (210 × 3.78 像素/毫米) × (148 × 3.78 像素/毫米) = 793.8 × 559.4 像素
    • A6（64开）：148 × 105 （单位：mm）; 297.7 × 419.6 磅
  • A4 纸纵横比（不考虑边距、眉脚）：
    • 宽：高 = 0.707：1
    • 高：宽 = 1.414：1
  • A4 实际像素比（应考虑页眉、页脚）：
    • 宽：高 = 0.76：1
    • 高：宽 = 1.32：1
  • A4 纸的（国际标准）尺寸是 210mm × 297mm,即 21.0 cm × 29.7 cm, 1 英寸 = 2.54cm,
    • 当分辨率为 72 像素/英寸时，其换算成 28.3 像素/厘米。
      • 转换为像素 (21 × 28.3) × (29.7 × 28.3) = 595 × 842 像素
    • 当分辨率为 120 像素/英寸时，A4 大小为 1487 × 2105 像素 当分辨率为 150 像素/英寸时，A4 大小为 1240 × 1754 像素
    • 当分辨率为 300 像素/英寸时，A4 大小为 2479 × 3508 像素

# 相对长度单位

  • 相对长度单位：通常相对于其他一些值，
    • 比如父元素的字体大小，或视图端口的大小。
    • 好处在于通过一些仔细的规划，可以使文本或其他元素的大小与页面上的其他内容（比例）相对应。 | 单位 | 相对于 | |:--|:--| | em | 在 font-size 属性中使用，是相对于父元素的字体大小，在其他属性（如：width）中使用，是相对于自身的字体大小。| | rem | 根元素（即：<html>）的字体大小 | | ex | 字符 x 的高度，通常为字体尺寸的一半 | | ch | 数字 0 的宽度 | | lh | 元素的行高 | | rlh | 根元素（即：<html>）的行高。用于根元素的 font-size、line-height 属性时，指的是这些属性的初始值 | | vw | 视口宽度的 1% | | vh | 视口高度的 1% | | vmin | 视口较小尺寸的 1%, 1vw 与 1vh 中取较小的 | | vmax | 视口大尺寸的 1%, 1vw 与 1vh 中取较大的 | | vb | 在根元素（即：<html>）的块向上，初始包含块的尺寸的 1% | | vi | 在根元素（即：<html>）的行向上，初始包含块的尺寸的 1% | | svw、svh | 分别为视口较小尺寸的宽度和高度的 1% | | lvw、lvh | 分别为视口大尺寸的宽度和高度的 1% | | dvw、dvh | 分别为动态视口的宽度和高度的 1% |

# CSS <percentage> 百分比值类型

  • 百分比：通常总是相对于其他值设置的。
    • 若将元素的字体大小设置为百分比，那么它将相对于父元素字体大小的百分比。
    • 若将元素的宽度值设置为百分比，那么它将相对于父元素宽度的百分比。
  • 多数 CSS 情况下，<percentage> 百分比与 <length> 长度的处理方法是一样的。但也有些许差别
    • 许多值接受 <length-percentage> 长度或百分比，但也有一些值只接受 <length> 长度

# CSS <color> 颜色

# 十六进制 RGB 值

  • 每个十六进制值由一个 #（散列/磅）符号和 6 个十六进制数字组成，
    • 每个十六进制数字都可以取 0123456789abcdef 的 16 个值其一。
    • 每对值表示一个通道分别为：红色、绿色、蓝色，并允许为每个通道指定 （16 x 16 =）256 个可用值中其一。

# RGB 和 RGBA 的值

  • RGB 值是一个函数（即：rgb()），它有三个参数，表示颜色的红色、绿色和蓝色通道值，
    • 类似十六进制值的方法。RGB 的不同之处，每个通道不是由两个十六进制数字表示的，而由 [0, 255] 区间范围的十进制数字表示的
  • 在旧版本的 CSS 中，rgb() 语法（第四个参数）不支持 alpha 参数，需要使用 rgba() 函数实现。
    • 目前大多数浏览器， rgb() 传递一个 alpha 参数，为了向后兼容旧网站，rgba() 语法仍被支持且具备 rgb() 相同的行为。

# HSL 和 HSLA 的值

  • HSL 颜色模型。hsl() 函数接受色相、饱和度和亮度值，而非红、绿、蓝值。该值用于区分 1670 万种颜色.
    • 色调：颜色的底色。
      • 该值 [0, 360] 区间范围，表示 color wheel 周围的角度。
    • 饱和度：颜色的饱和值
      • 该值 [0, 100%] 区间范围，表示从无颜色（它将显示为灰色阴影）到全色的程度
    • 亮度：颜色的亮渡
      • 该值 [0, 100%] 区间范围，表示从没有光（将完全显示为黑色）到完全亮（完全显示为白色）的程度
  • 在旧版本的 CSS 中，hsl() 语法（第四个参数）不支持 alpha 参数，需要使用 hsla() 函数实现。
    • 目前大多数浏览器，hsl() 传递一个 alpha 参数，为了向后兼容老网站，hsla() 语法仍然被支持且具备 hsl() 相同的行为。

# CSS <image> 数据类型

  • 通过 url() 函数指向的实际图像文件，用于图像为有效值的任何地方。
    • 也可通过使用 background-image 属性值的渐变实现一个图片。

# CSS <position> 位置数据类型

  • 表示一组 2D 坐标，用于定位一个元素，
    • 通过 background-position 定位背景图像。
    • 通过 top、left、bottom、right、center 等关键字，将元素与 2D 框的特定边界对齐，表示框的顶部和左侧边缘偏移量的长度。
  • 典型的位置值由两个值组成
    • 第一个值水平地设置位置
    • 第二个值垂直地设置位置
    • 若只指定一个轴的值，另一个轴将默认为 center。

# CSS 函数值类型

  • rgb()、hsl()：用于计算颜色函数。
  • url()：用于从文件返回图像的值。
  • calc()：用于简单的算术计算。
    • 常用于 CSS 中暂时无法定义明确的数值，并且需要浏览器在运行时计算出的结果。
    • 例： 某元素（根据父容器宽度的 20% 来）计算的宽为 calc(20% + 100px)，因此该值随父元素的宽度而改变。

# CSS 的字符串和标识符

  • CSS 的关键字会被更准确地描述为标识符，这些可以被 CSS 理解的特殊值（无需使用引号，不被当作字符串）。
  • <color> 颜色关键字
    • red
    • black
    • rebeccapurple
    • goldenrod。。

# 如何获取设备 DPI（每英寸像素数）

  • 目前没有一种能够兼容所有浏览器的方法。不同浏览器提供的获取 DPI 的方式各不相同。
    • 在 IE 浏览器中，可用 window.screen 对象提供的 deviceXDPI设备的物理像素属性和 logicalXDPI 逻辑像素比例属性。通过计算比例并乘以默认的 96 dpi，可以得到设备的 DPI 值
    • 大多数现代浏览器中，可用 window.devicePixelRatio 物理像素与逻辑像素之间的比例属性。通过将默认的 96 dpi 乘以这个比例，可以得到设备的 DPI 值。
      function getDeviceDPI() {
    var dpi = 96; // 默认值 96dpi
    if (window.screen && window.screen.deviceXDPI && window.screen.logicalXDPI) {
      dpi = window.screen.deviceXDPI / window.screen.logicalXDPI * dpi;
    } else if (window.devicePixelRatio) {
      dpi = dpi * window.devicePixelRatio;
    }

    return dpi;
  }
  console.log("设备 DPI 值：", getDeviceDPI());

# js 获取 dpi

  • 获取DPI（Dots Per Inch，每英寸点数）的JavaScript代码主要通过获取屏幕的分辨率和屏幕的尺寸来计算得出。以下是几种实现方法：
    • 这些方法获取的DPI为屏幕的DPI，而不是打印机的DPI。
    • 不同浏览器对于 DPI 的支持可能会有所差异，因此建议在`不同浏览器中进行测试以确认兼容性。

# 方法1：利用window对象的devicePixelRatio属性和screen对象的width属性来计算DPI。

```js
  function getDPI() {
    var dpi = (
      window.devicePixelRatio
      * (screen.width / Math.sqrt(Math.pow(screen.width, 2) + Math.pow(screen.height, 2)))
    );

    return dpi;
  }
```

# 方法2：利用CSS media query的dpi（dots per inch）属性来获取DPI。

  function getDPI() {
    var dpi = window.matchMedia('screen and (resolution: ' + window.devicePixelRatio + 'dppx)').matches
      ? window.devicePixelRatio * 96
      : window.devicePixelRatio * 72;

    return dpi;
  }

# 方法3：利用CSS media query的resolution（dpi）属性来获取DPI。

  function getDPI() {
    var dpi = window.matchMedia('screen and (min-resolution: ' + window.devicePixelRatio * 96 + 'dpi)').matches
      ? window.devicePixelRatio * 96
      : window.devicePixelRatio * 72;

    return dpi;
  }

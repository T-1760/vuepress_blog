## `@` 规则
  - `@`规则是一个 CSS 语句，用来指示 CSS 如何运行。
    + 以 `@` 符号（U+0040）开头，后跟一个标识符，并包括直到下一个 `;` 分号（U+003B）的所有内容，或下一个 CSS 块，以先到者为准。
  - 语法：`@identifier (RULE);`
    ```css
      /* 例：通知浏览器使用 UTF-8 字符集 */
      @charset "utf-8";
    ```

## 条件规则组
  - 条件规则组：每条 `@` 规则都有不同的语法，可将一些 `@` 规则归为一个特殊的分类。
    + 这些语句使用相同的语法。它们都可以包括 嵌套语句——规则集（嵌套 `@` 规则）。
    + 表达所指的条件 (类型不同) 总等效于布尔值，若为 true 则语句生效。
    + 例：`@media`、`@supports`

## 嵌套 at 规则
  - 嵌套 at 规则：是嵌套语句的子集，不仅可以作为样式表里的一个语句，也可以用在条件规则组里
    + 各标示符指定每种规则都有不同的语法
      ```css
        @identifier (RULE) {
        }
      ```
  | 标识符 | 含义 |
  |:--|:--|
  | `@charset`   | 定义样式表使用的字符集。|
  | `@import`    | 告诉 CSS 引擎引入一个外部样式表。|
  | `@namespace` | 告诉 CSS 引擎必须考虑 XML 命名空间。|
  | `@media`     | 如果满足媒介查询的条件则条件规则组里的规则生效。|
  | `@supports`  | 如果满足给定条件，则条件规则组里的规则生效。|
  | `@page`      | 描述打印文档时布局的变化。|
  | `@font-face` | 描述将下载的外部的字体。|
  | `@keyframes` | 描述 CSS 动画的中间步骤。|
  | `@layer`     | 声明一个级联层，并在有多个级联层时定义优先顺序。|

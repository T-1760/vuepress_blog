## docs 文档
  - 着重知识的 depth 深度
  - 知识点的笔记、速查表，便于快速掌握、回顾知识点内容
  - 细分知识点的独立性，颗粒化
  - 温馨提示：文档依据个人偏好整理笔记，具体以官方文档为主

## 阅读前要
### 数据类型
  - Any：任意类型 
  - String：字符串类型
  - Number：数值类型
    + integer: 整型
  - Bigint: 大数值类型
  - Boolean：布尔类型
  - null：null 类型
  - undefined：undefined 类型
  - Object：对象类型
    + TypeObject：对象类型
    + Array：数组
    + TypeArray：类数组
    + Function: 函数
    + Iterable：可迭代对象

## 前言
  - ECMA 是 JavaScript 语言的标准化组织机构，
  - ECMA 原先是 European Computer Manufacturers Association 欧洲计算机制造商协会的缩写
  - ECMA 自 2015 年起，每年会推出标准化版本的 JavaScript 其被称作 ECMAScript
    + ECMAScript 2009 简称 ES5
    + ECMAScript 2015 简称 ES6。
    + 以此类推 ECMAScript 2016 => ES7; ECMAScript 2017 => ES8 ... ECMAScript 2024 => ES25;
  - JavaScript 时代变革的 ES6 作为后续版本的代称。（即：ES2015 这个版本是指代 ES2015 及其后每年发布的 ECMAScript 版本的代称）

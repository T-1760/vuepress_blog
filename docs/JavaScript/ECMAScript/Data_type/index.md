## 数据结构
  - 最新的 ECMAScript 标准定义了 8 种数据类型（7 个基本数据类型 + 1 个引用数据类型）：
    1. bigInt：**任意精度的整数** 基本数据类型
    2. boolean：**布尔值** 基本数据类型
    3. symbol：**代表** （独一无二的值）基本数据类型
    4. string：**字符串** 基本数据类型
    5. number：**数字**（整数或浮点数）本数据类型
    6. null：**null** 基本数据类型
    7. undefined：**undefined** （表示变量未赋值时的属性）基本数据类型，
    8. object： **对象**引用数据类型

## 数据类型的转换
  - JavaScript 是一种动态类型语言 (dynamically typed language)。意味在声明变量时可以不必指定数据类型，而数据类型会在代码执行时会根据需要自动转换。

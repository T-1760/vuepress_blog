## 前言
  - JavaScript 由 Brendan Eich 于 1995 年发明，并于 1997 年成为 ECMA 标准。
  - ECMAScript 是该语言的官方名称。
  - 自 2015 年起，ECMAScript 按年命名（ECMAScript 2015）。
  - ECMA 制定 ECMAScript 规范 JavaScript 语言的核心语法
